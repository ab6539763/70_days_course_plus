## 1. 项目背景

智链科技（Zhilian Tech）是一家专注于企业智能化转型的科技公司，现有客户覆盖金融、制造、零售等行业。2026 年 Q2，公司决定投入研发资源，打造自有的 **NexusAgent 灵犀智能体平台**，目标是在 6 个月内完成 MVP 并在 3 家标杆客户处试点。

本次 70 天培训计划，本质上是公司「**以战代训**」的人才培养策略：新入职工程师在培训期间直接参与平台开发，培训结束即转正为项目核心成员。

## 2. 项目愿景

> 让每一个企业都能以最低成本拥有属于自己的智能体团队。

## 3. 项目目标（MVP 阶段）

| 目标 | 衡量标准 |
|------|----------|
| 多租户 Agent 编排 | 支持至少 5 种预置 Agent 模板，可自定义工具链 |
| 企业知识库 RAG | 支持 PDF/Word/Markdown 上传，混合检索 + Rerank |
| 工具市场 | 内置 10+ 工具，支持 MCP 协议扩展 |
| 对话与会话管理 | 多轮对话、会话隔离、历史持久化 |
| 部署与运维 | Docker Compose 一键部署，支持私有化 |

## 4. 项目范围

### 4.1 范围内（In Scope）

- Python 后端（FastAPI）
- React 前端管理控制台
- PostgreSQL 业务数据库
- Redis 缓存与会话
- Milvus 向量数据库
- LangGraph Agent 编排引擎
- Docker 容器化部署

### 4.2 范围外（Out of Scope）— MVP 阶段

- 移动端 App
- 多语言国际化（仅中文）
- 自研大模型（使用 API 接入）
- Kubernetes 集群编排（后期迭代）

## 6. 技术架构原则

1. **模块化单体优先**：MVP 阶段采用模块化单体架构，避免过早微服务化
2. **API 优先**：所有功能先暴露 REST API，再封装 UI
3. **可测试性**：每个模块必须有单元测试，覆盖率目标 70%+
4. **可观测性**：从 Day 1 起接入结构化日志
5. **安全默认**：API Key 不入库明文，敏感配置走环境变量
