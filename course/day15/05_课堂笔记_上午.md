## 09:30 什么是 Token？

### 讲师要点

1. **Token 不是字符**：是模型词表里的离散单元  
2. **BPE 直觉**：高频子词合并，「un」「believ」「able」可能被拆开  
3. **中英差异**：中文常 1 字 1 token；英文一词可能 1–3 tokens  
4. **计费单位**：云厂商按 prompt + completion 分别计价

### 白板公式

```
总费用 ∝ prompt_tokens × 输入单价 + completion_tokens × 输出单价
```

### 学员提问

**Q**：为什么输出比输入贵？  
**A**：生成需要自回归采样，算力消耗更大；且输出长度不可预知。

## 10:45 estimate_tokens 手写

### 规则记忆口诀

> **汉字一字一算，英文四字一词。**

### 代码共读

```python
def _is_cjk(char: str) -> bool:
    code = ord(char)
    return (
        0x4E00 <= code <= 0x9FFF
        or 0x3400 <= code <= 0x4DBF
        or 0x3000 <= code <= 0x303F
    )
```

### 课堂练习

心算 `estimate_tokens("AI 理财")`：

- CJK：理财 = 2
- other：`AI ` = 3 → (3+3)//4 = 1
- 合计：**3 tokens**

## 11:45 MESSAGE_OVERHEAD

每条 `ChatMessage` 额外 +4 tokens，模拟 API messages 数组的格式开销。

```python
def estimate_message_tokens(message: ChatMessage) -> int:
    return MESSAGE_OVERHEAD_TOKENS + estimate_tokens(message.content)
```

两条消息（user + assistant）比单段文本多 **8 tokens** 量级开销。
