## 2. 上下文窗口与 token 上限

| 模型（示例） | 上下文 | 教学提示 |
|-------------|--------|----------|
| deepseek-chat | 128K | 远超 MVP 对话 |
| 早期 GPT-3.5 | 4K–16K | 说明历史裁剪必要性 |

当 `prompt_tokens` 接近上限，API 返回 400；Day 15 可演示 Mock 错误响应（可选）。

---

## 3. 重复 token 统计误区

学员常以为「会话累计 prompt」=「当前上下文长度」。需强调：

- **累计 prompt**：各轮输入之和（历史被重复计费）  
- **当前 prompt**：最后一轮 `usage.prompt_tokens`

`/tokens` 的 `summary` 是累计语义。

## 6. 常见学员误区纠正

1. 「Unicode 字符数 = token」→ 否  
2. 「流式会更省 token」→ 否，只改善体验  
3. 「/clear 清空一切」→ 保留 system  
4. 「本地估算可用来结账」→ 仅 API usage 权威
