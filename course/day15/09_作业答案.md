## 作业一参考答案

```python
from llm.token_counter import estimate_tokens, _is_cjk  # 教学可导入私有函数


def describe_estimate(text: str) -> str:
    if not text:
        return "CJK=0, other=0, tokens=0"
    cjk = sum(1 for c in text if _is_cjk(c))
    other = len(text) - cjk
    tokens = estimate_tokens(text)
    return f"CJK={cjk}, other={other}, tokens={tokens}"
```

| 输入 | 预期 |
|------|------|
| `""` | CJK=0, other=0, tokens=0 |
| `你好` | CJK=2, other=0, tokens=2 |
| `hello` | CJK=0, other=5, tokens=2 |
| `AI你好` | CJK=2, other=2, tokens=3 |

## 作业二参考答案

```python
def cost_for_turn(
    prompt: int,
    completion: int,
    *,
    input_ppm: float = 1.0,
    output_ppm: float = 2.0,
) -> float:
    return prompt / 1_000_000 * input_ppm + completion / 1_000_000 * output_ppm
```

验证：`cost_for_turn(1_000_000, 500_000)` = 1.0 + 1.0 = **2.0** 元。

或使用项目类：

```python
from llm.token_counter import TokenCounter, TokenUsage

counter = TokenCounter()
usage = TokenUsage(prompt_tokens=1_000_000, completion_tokens=500_000)
assert abs(counter.estimate_cost(usage).total - 2.0) < 1e-9
```

## 作业三参考答案

```python
from chat import ChatAssistant
from llm.client import LLMClient
from llm.env import LLMEnvConfig
from models import ModelConfig

_turn = {"n": 0}

def transport(*_):
    _turn["n"] += 1
  n = _turn["n"]
    return {
        "model": "deepseek-chat",
        "choices": [{"message": {"role": "assistant", "content": f"答{n}"}, "finish_reason": "stop"}],
        "usage": {
            "prompt_tokens": 50 + n * 80,
            "completion_tokens": 10 + n * 5,
            "total_tokens": 60 + n * 85,
        },
    }

env = LLMEnvConfig(api_key="x", base_url="https://api.example.com/v1", mock=True)
client = LLMClient(ModelConfig(), env=env, transport=transport)
a = ChatAssistant(client=client, track_tokens=True)
for line in a.run_scripted(["Q1", "Q2", "Q3", "/tokens"]):
    print(line)
```

**说明要点**：第三轮 `prompt_tokens` 更高，因为 `complete(messages)` 发送了 system + 两轮完整历史 + 本轮 user，消息条数与总字符数累积，输入 token 随轮次增加。

## 作业四简答要点

### 1. Token 与字符

Token 是模型词表单元，字符是 Unicode 码位。英文 `hello` 可能 1 token；中文「你好」常 2 tokens。字符数 ≠ token 数。

### 2. prompt vs completion

- `prompt_tokens`：输入侧，含 system、历史、当前 user  
- `completion_tokens`：模型生成的新文本  
- `total_tokens`：二者之和（计费相关）

### 3. /clear 降费用

`/clear` 删除除 system 外的历史，下一轮 `messages` 变短，`prompt_tokens` 下降，输入费用降低。

### 4. 启发式 vs tiktoken

| 启发式利 | 启发式弊 |
|----------|----------|
| 零依赖、易教学 | 偏差大 |
| 快速估算 | 不适合财务对账 |

| tiktoken 利 | tiktoken 弊 |
|-------------|-------------|
| 接近真实 BPE | 需安装、模型相关 |
| 适合生产 | 词表随模型变 |
