## 智链科技 Day 23 作业辅导长文（培训部）

### 作业 A 深度辅导

`api_health_demo.py` 使用 TestClient，输出 JSON 中 `mock_llm: true` 是向业务解释「当前非真实大模型计费」的关键凭证。截图须含完整终端窗口与命令行上下文，便于助教验证环境变量。若学员机器显示 `mock_llm: false`，检查是否在 profile 中 export 了 `NEXUS_LLM_MOCK=0`。周航规定：作业 A 两张截图缺一不可，pytest 须显示 `12 passed` 全文，不接受 crop 掉失败用例的图。

### 作业 B 深度辅导

Network 面板教学是 Day 23 核心技能。学员须选中 `chat` 或 `api/chat` 请求，查看 Request Payload 仅含 `message`（及可选 `session_id`），Response 含四字段。赵岩验收时对照「投资有风险吗」的 `kind` 必须为 `faq`，若仅 reply 含 FAQ 字样而 kind 为 llm，说明 `classify_reply` 回归，应修代码而非改截图。「帮我总结要点」允许 route 或 llm，但 reply 须非空且与问句相关，禁止敷衍「（Mock）」字符串——那是 Mock 模式特征，API 模式出现即切换失败。

### 作业 C 深度辅导

扩展 `classify_reply` 时，保持函数纯函数特性：无全局状态、无 IO。新增 `[系统通知]` 分支应放在 FAQ 之前还是之后？培训部标准答案：放在 FAQ 之前，因系统通知更具体；若 FAQ 规则更宽可能误吞。学员须在 `classify_test.md` 写清边界用例，如 `[系统通知][FAQ` 假想的冲突字符串——优秀作业会讨论优先级策略。

### 作业 D 深度辅导

curl 日志是运维基本功。要求两次 POST 使用相同 `session_id`，证明服务端回传一致；这验证 `SessionManager` 而非 orchestrator 内部历史（历史验证需同 sid 连续问「我刚才说了什么」，属加分）。422 实验应用 `-w '%{http_code}'` 或 `-i` 显示状态行。Swagger 截图须含 `POST /api/chat` 展开区域与 200 响应示例。

### 作业 E 深度辅导

200 字说明须涵盖三点：config 与 mock 分工、apiBase 预留、与 Day 22 差异。引用 `mock.js` 末尾 `useMock` 逻辑真值表者加分。若仅复述「config 控制 Mock」而无真值表，最高良好。鼓励学员亲手在 8000 与 8080 各测一次，写下亲身体验。

### 作业 F 深度辅导

Redis 草图不要求可运行代码，但须含 key 命名如 `nexus:session:{uuid}`、TTL 理由、序列化边界（是否存 orchestrator 全对象——答案应否，仅存 message history JSON）。多 worker 问题须提及「无粘性负载均衡时会话分裂」，体现生产思维。

### 学术诚信再强调

允许讨论 FastAPI 官方文档与课堂笔记；禁止互抄 curl 输出 JSON 中的 reply 全文（因 FAQ 分数因人而异）。若两人 reply 完全一致且时间戳相同，触发查重。智链科技培训部 2026 年已启用作业哈希比对。

## 智链科技 Day 23 晚自习加长辅导（培训部）

### 辅导一：PYTHONPATH 的本质

PYTHONPATH 告诉 Python 去哪些目录找包。`src` 下有 `api`、`chat` 等包。未设置时 `from api.app import create_app` 失败。Windows 学员用 `set PYTHONPATH=src` 或 PowerShell `$env:PYTHONPATH="src"`。周航建议写入 `.env` 并由 direnv 加载，选修。

### 辅导二：pip 与 venv

始终在 venv 内 `pip install -r requirements-api.txt`，避免污染系统 Python。某学员全局安装导致版本冲突，浪费四十分钟。培训部提供 `scripts/bootstrap_day23.sh`（Day 24 入库）。

### 辅导三：浏览器缓存

改 config.js 后浏览器强刷 Ctrl+Shift+R。林晓因缓存以为 useMock 未切换，实则文件已更新。

### 辅导四：FAQ 未命中排查

问句正确但 kind 非 faq：查 Matcher 阈值 0.65；查问句是否与库相似；查是否 Mock LLM 覆盖了直答路径。用 `api_chat_demo.py` 对比 CLI `handle_message` 输出。

### 辅导五：Swagger 使用技巧

Authorize 按钮 Day 23 无；Schemas 底部可展开 ChatRequest；Curl 命令可复制到作业 D。鼓励学员用 Swagger 给非技术同事演示。
