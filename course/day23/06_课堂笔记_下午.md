## 15:30 config.js 与 API 模式

```javascript
global.NexusConfig = {
  useMock: params.get("mock") === "1",
  apiBase: "",
};
```

- FastAPI 托管：`useMock` 默认 false → 走 `sendMessageApi`  
- 纯静态 + `?mock=1`：回退 Mock，方便 UI 专练  

mock.js 逻辑：

```javascript
useMock: !(global.NexusConfig && global.NexusConfig.useMock === false),
```
