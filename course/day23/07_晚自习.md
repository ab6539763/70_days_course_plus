## 19:00–19:30 环境诊所

| 问题 | 解决 |
|------|------|
| `ModuleNotFoundError: api` | `export PYTHONPATH=src` |
| `No module named fastapi` | `pip install -r requirements-api.txt` |
| Address already in use | `lsof -i :8000` 杀进程或换端口 |
| 浏览器仍显示 Mock | 确认由 8000 访问，非 8080；检查 URL 无 `?mock=1` |
