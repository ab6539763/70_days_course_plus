## 案例 3：CORS 踩坑

### 背景

实习生将 frontend 放 CDN，`api` 在 `api.zhilian.com`，浏览器报 CORS 错误。

### 解决

- 短期：app.py 白名单 CDN 域名  
- 长期：nginx 同域反代（与 Day 23 教学一致）  

陈默：「能同源就同源。」

## 案例 4：502 与客服话术

### 背景

LLM 上游超时，API 返回 502，前端显示「API 错误: 502」，用户恐慌。

### 改进

赵岩文案：

- 502 → 「智能服务繁忙，请稍后重试」  
- 500 → 「系统配置异常，请联系管理员」  

前端 catch 分支按 status 映射（Day 24 作业）。

## 案例 7：requirements-api 版本冲突

### 背景

某学员全局安装 fastapi 0.95，与课程 0.110+ 不兼容，Pydantic v2 字段报错。

### 解决

venv 隔离 + `pip install -r requirements-api.txt`。周航将 Python 版本与依赖锁写入 environment.yml。

### 教训

API 课程第一天先检查 `pip show fastapi`。
