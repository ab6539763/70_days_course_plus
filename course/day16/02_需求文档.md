# ZL-NA-REQ-016 需求文档

**需求编号**：ZL-NA-REQ-016  
**需求名称**：流式输出模块（SSE）  
**优先级**：P0  
**Sprint**：Sprint 3 第二日  
**状态**：已交付

---

## 1. 背景

智链科技 NexusAgent 内测反馈显示：阻塞式 `complete` 在长回复场景下用户等待感强烈。OpenAI 兼容 API 支持 `stream=true`，响应以 **Server-Sent Events** 推送 `chat.completion.chunk`。产品要求实现流式客户端，支持 CLI 打字机效果，并为后续 Web SSE 转发预留 transport 抽象。

## 2. 目标用户

- 内测用户（更快看到首字，降低焦虑）
- CLI 开发者（`on_delta` 回调驱动终端输出）
- 测试与 CI（Mock SSE 文件，无外网依赖）

## 3. 功能需求

### FR-001 流式请求体

| 项 | 描述 |
|----|------|
| 函数 | `build_stream_request_body(messages, config)` |
| 行为 | 调用 `build_request_body`，追加 `"stream": True` |
| 约束 | 其余字段与 Day 12 阻塞请求一致 |

### FR-002 SSE 行解析

| 项 | 描述 |
|----|------|
| 函数 | `parse_sse_line(line: str)` |
| 空行/注释 | 以 `:` 开头或空白 → 返回 `None` |
| 数据行 | `data:` 前缀后 JSON 解析 |
| 终止 | `data: [DONE]` → `{"done": True}` |
| 异常 | 非法 JSON → 抛出 `APIError` |

### FR-003 Chunk 解析

| 项 | 描述 |
|----|------|
| 函数 | `parse_stream_chunk(data)` |
| 输出 | `StreamChunk(delta_content, finish_reason, model, raw)` |
| 规则 | `choices[0].delta.content`；`finish_reason` 在末 chunk |
| 衔接 | 与 Day 5 `parse_stream_chunk` 语义一致 |

### FR-004 内容累积

| 项 | 描述 |
|----|------|
| 类 | `StreamAccumulator` |
| 方法 | `feed(chunk)` 追加 delta；`content` 属性返回全文 |
| 用途 | 流结束后构造 `ChatMessage("assistant", content)` |

### FR-005 流式传输层

| 项 | 描述 |
|----|------|
| 默认 | `default_stream_transport`：urllib POST + 逐行读 SSE |
| Mock 文件 | `mock_stream_from_sse_file(path)` 读本地 `.sse` |
| Mock 文本 | `mock_stream_from_text(text)` 逐字符 chunk |
| 类型 | `StreamTransportFunc` 可注入，便于单测 |

### FR-006 StreamingLLMClient

| 项 | 描述 |
|----|------|
| 继承 | `LLMClient` |
| 核心方法 | `stream_complete(messages, on_delta=None)` |
| 回调 | 每收到非空 `delta_content` 调用 `on_delta(delta)` |
| 返回 | `StreamCompletionResult`（message、model、usage、chunk_count） |
| 便捷 | `stream_chat(user_content, system_prompt, on_delta)` |

### FR-007 Token Usage

| 项 | 描述 |
|----|------|
| 来源 | 流中某 chunk 的 `usage` 字段（通常最后一包） |
| 解析 | `TokenUsage.from_usage_dict`（Day 15） |
| 约束 | 无 usage 时各字段为 0，不抛错 |

### FR-008 空内容防护

- 流结束若 `accumulator.content` 为空 → `APIError("流式响应未产生任何 content")`

## 4. 非功能需求

| 编号 | 要求 |
|------|------|
| NFR-001 | 默认 transport 仅用标准库 `urllib` |
| NFR-002 | Mock 模式默认读 `llm/sample_data/stream_mock.sse` |
| NFR-003 | HTTP 错误封装为 `APIError`，含 status_code 与 body |
| NFR-004 | 代码位于 `src/llm/streaming.py`，版本 0.1.0 |
| NFR-005 | 异步实现为扩展预习（`async_stream_demos.py`），非本需求交付 |
