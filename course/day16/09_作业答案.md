## 作业 A 参考答案

```python
"""homework/day16/sse_lab.py"""
from __future__ import annotations

import sys
from pathlib import Path

_ROOT = Path(__file__).resolve().parents[2] / "nexus-agent-platform" / "src"
sys.path.insert(0, str(_ROOT))

from core.paths import get_path
from llm.streaming import iter_sse_events, parse_stream_chunk


def count_content_deltas(sse_text: str) -> int:
    count = 0
    for event in iter_sse_events(sse_text.splitlines()):
        if event.get("done"):
            break
        chunk = parse_stream_chunk(event)
        if chunk.delta_content:
            count += 1
    return count


def reconstruct_text(sse_text: str) -> str:
    parts: list[str] = []
    for event in iter_sse_events(sse_text.splitlines()):
        if event.get("done"):
            break
        chunk = parse_stream_chunk(event)
        if chunk.delta_content:
            parts.append(chunk.delta_content)
    return "".join(parts)


def main() -> None:
    path = get_path("stream_mock_sse")
    text = path.read_text(encoding="utf-8")
    print("deltas:", count_content_deltas(text))
    print("text:", reconstruct_text(text))


if __name__ == "__main__":
    main()
```

**预期**：`deltas: 7`，`text: 你好，我是 NexusAgent 助手。`  
（首包 role-only 不计入 content delta）

## 作业 B 参考答案

```python
"""homework/day16/typewriter_demo.py"""
import os
import sys
import time
from pathlib import Path

os.environ.setdefault("NEXUS_LLM_MOCK", "1")
_SRC = Path(__file__).resolve().parents[2] / "nexus-agent-platform" / "src"
sys.path.insert(0, str(_SRC))

from llm.streaming import StreamingLLMClient
from models import ChatMessage, ModelConfig


def slow_delta(ch: str) -> None:
    print(ch, end="", flush=True)
    time.sleep(0.05)


def main() -> None:
    client = StreamingLLMClient(ModelConfig())
    print("助手: ", end="", flush=True)
    result = client.stream_complete(
        [ChatMessage("user", "你好")],
        on_delta=slow_delta,
    )
    print("\n" + result.usage_summary())


if __name__ == "__main__":
    main()
```

## 作业 C 参考答案要点

| 对比项 | Day 12 complete | Day 16 stream_complete |
|--------|-----------------|------------------------|
| 请求体关键字段 | 无 `stream` 或 `stream: false` | `stream: true` |
| HTTP 读取方式 | `resp.read()` 整块 | `for raw_line in resp` 逐行 |
| 解析入口函数 | `parse_chat_completion(json)` | `parse_sse_line` → `parse_stream_chunk` |
| 用户可见输出时机 | 全文解析后一次返回 | 每个 delta 经 `on_delta` |
| usage 来源 | 响应根对象 `usage` | 流中末 chunk 的 `usage` |

**踩坑示例**：

1. 忘记 `flush=True` 导致打字机失效  
2. 把 `[DONE]` 当 JSON 解析报错  
3. 首包空 content 误判为失败

## 作业 D 思考题要点

### 1. data: [DONE]

- **协议层**：告知客户端流正常结束，无更多 chunk  
- **代码层**：`parse_sse_line` 返回 `{"done": True}`，transport 循环 `break`

### 2. on_delta 勿阻塞

读取循环同步执行；`on_delta` 内慢 IO 会延迟读下一行 SSE，造成**背压**甚至服务端缓冲满。应用层应轻量更新 UI，重活丢队列。

### 3. Day 15 衔接

`TokenUsage.from_usage_dict` 在见到含 `usage` 的 chunk 时更新；计费以最后一包为准，与阻塞模式 API 权威一致。

### 4. Day 17 预习

`template.render(ctx)` → `system_prompt` → `stream_chat(..., system_prompt=..., on_delta=...)`。模板管输入，流式管输出。
