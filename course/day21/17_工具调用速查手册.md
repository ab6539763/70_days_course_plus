## 核心 API

| API | 用途 |
|-----|------|
| `ToolDefinition(...)` | 定义工具 |
| `ToolRegistry.register(tool)` | 注册 |
| `build_nexus_tools(...)` | 四工具工厂 |
| `ToolExecutor(registry).execute(name, args)` | 执行 |
| `ChatOrchestrator(assistant, ...).handle_message(text)` | 编排对话 |
| `OrchestratorConfig(faq_direct_threshold=0.65)` | 策略配置 |
| `parse_tool_arguments(raw)` | 解析 /tool 参数 |

## FAQ 直答阈值速查

| threshold | 典型行为 |
|-----------|----------|
| 0.3 | 激进，更多直答 |
| 0.65 | 默认 |
| 0.99 | 极少直答，几乎全 LLM |

构造示例：

```python
from chat import ChatOrchestrator, OrchestratorConfig
orch = ChatOrchestrator(assistant, faq_matcher=faq,
    config=OrchestratorConfig(faq_direct_threshold=0.5))
```

## 周测知识点速记

1. 中文约 1.5–2 字 / token  
2. SSE 行格式 `data: {json}`  
3. 缺模板变量 → ConfigError  
4. rag 动态检索 → query_context_provider  
5. chunk overlap → 防边界断句  
6. Embedding 优势 → 同义召回  
7. cosine ∈ [-1, 1]  
8. /similar → SimilarQuestionMatcher  
9. use_embedding=True → EmbeddingRetriever  
10. Day 21 → FAQ+RAG+意图+工具编排

## 排错决策树（文字版）

1. pytest 失败 → 读断言行号 → 对照源码  
2. 工具未启用 → 检查 tool_registry 构造  
3. 直答不触发 → 打印 match.score 与 threshold  
4. rag_search 空 → 查 use_embedding 与查询词  
5. 周测不及格 → 10_ 题库重修
