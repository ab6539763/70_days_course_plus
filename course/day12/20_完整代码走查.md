# Day 12 完整代码走查

按调用顺序阅读 `llm/` 包与演示脚本。

---

## 1. llm/env.py

### parse_env_file

- 读 `.env`，忽略注释空行  
- 不覆盖 `os.environ` 已有键  

### load_llm_env

- 组装 `LLMEnvConfig`  
- `mock` 布尔解析  
- 非 mock 且无 key → `ConfigError`  

### chat_completions_url

属性拼接 `/chat/completions`。

```python
return {"role": self.role, "content": self.content}

```

## 3. llm/client.py

### build_request_body

校验 → 合并 config + messages。

### default_transport

```
json.dumps → encode → Request(POST) → urlopen → json.loads
```

异常 → `APIError`。

### mock_transport_from_file

闭包返回读文件函数。

### LLMClient.__init__

选择 transport 的三叉逻辑。

### _headers

Mock：仅 Content-Type  
Live：+ Authorization Bearer

### complete

```python
body = build_request_body(...)
raw = self._transport(url, headers, body)
return parse_chat_completion(raw)
```

### chat

组装 system/user → complete → return message。
