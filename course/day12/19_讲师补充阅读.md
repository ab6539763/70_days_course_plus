# Day 12 讲师补充阅读

---

## 1. OpenAI API 文档导读

建议学员浏览（不必全读）：

- Authentication：Bearer Token  
- Chat Completions：request body / response  
- Error codes：401、429、500

DeepSeek 文档结构与 OpenAI 高度相似，本项目默认 Base URL 指向 DeepSeek。

---

## 2. 十二要素应用（12-Factor）与环境变量

`load_llm_env` 体现：

- **III. Config**：配置在环境中，不硬编码 Key  
- **优先级**：部署环境 export 覆盖 `.env` 开发文件  

---

## 3. 依赖注入与可测试性

Martin Fowler：「依赖注入是将依赖的创建移到使用方外部。」

`transport` 参数使 `LLMClient` 不硬绑定 `urllib`，测试与 Mock 无需 patch 全局。

---

## 4. 失败设计（Fail Fast）

- 配置错误（缺 Key）在 `_headers()` / `load_llm_env` 失败  
- 校验错误在 `build_request_body` 失败  
- 不在收到 200 后才 discover 请求体非法  

---

## 5. urllib 安全注意

- 验证 HTTPS 证书（默认开启）  
- 勿对不可信 URL 使用用户输入拼接（SSRF 风险，Day 25 安全专题）  
- 超时必须设置，避免 hung 连接  

---

## 6. Token 经济学

`usage` 字段：

- `prompt_tokens`：输入计费  
- `completion_tokens`：输出计费  

教学项目 `max_tokens=256` 控制单次上限；生产需配额与告警。

## 7. Day 13 装饰器预习材料

推荐阅读：

- Python Tutorial § 9.6 — Function Decorators  
- `functools.wraps` 保留原函数元数据  

思考作业：`@retry` 应实现为装饰器工厂（带参数 `max_attempts`）。
