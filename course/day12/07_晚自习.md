## 预习 Day 13：装饰器与重试

明日关键词：

```python
def retry(max_attempts=3, backoff=1.0):
    def decorator(func):
        def wrapper(*args, **kwargs):
            ...
        return wrapper
    return decorator
```

思考：装饰器加在 `LLMClient.complete` 还是 `default_transport` 更合适？

**提示**：加在 `complete` 可统一处理 Mock/Live；加在 transport 只重试网络层。
