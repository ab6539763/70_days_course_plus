# ZL-NA-REQ-012：首次 LLM API 调用

**版本**：v0.1.0  
**作者**：陈默 / 周航  
**状态**：已批准  
**创建日期**：2026-07-17

## 1. 概述

在 `llm/` 包实现 HTTP 客户端，使用标准库 `urllib` 调用 OpenAI 兼容的 Chat Completions API（默认 DeepSeek）。支持环境变量配置、Mock 离线模式、可注入 transport 以便测试。

## 2. 范围

### 2.1 包含

| 模块 | 职责 |
|------|------|
| `llm/env.py` | 读取 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`NEXUS_LLM_MOCK` |
| `llm/client.py` | `build_request_body`、`LLMClient`、`default_transport` |
| `llm/response.py` | `parse_chat_completion`、`ChatCompletionResult` |
| `core/exceptions.APIError` | HTTP/JSON/API 业务错误 |
| `src/day12/*_demos.py` | 教学演示 |

### 2.2 不包含

- 流式输出（Day 16）
- 自动重试（Day 13）
- `requests` / `httpx` 第三方库
- `python-dotenv`（手写简易解析器）

## 3. 环境变量

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `DEEPSEEK_API_KEY` | Live 模式必填 | — | Bearer Token |
| `DEEPSEEK_BASE_URL` | 否 | `https://api.deepseek.com/v1` | API 根路径 |
| `NEXUS_LLM_MOCK` | 否 | `0` | `1`/`true`/`yes`/`on` 启用 Mock |

优先级：`os.environ` > 项目根 `.env` 文件。

## 4. 核心 API

### 4.1 build_request_body

```python
def build_request_body(
    messages: list[ChatMessage],
    config: ModelConfig,
) -> dict[str, Any]
```

- 校验所有 `ChatMessage` 与 `ModelConfig`
- 合并 `config.to_api_params()` 与 `messages` 数组
- 输出符合 OpenAI Chat Completions 请求体

### 4.2 LLMClient

```python
class LLMClient:
    def __init__(self, config=None, *, env=None, transport=None, sample_path=None)
    def complete(self, messages: list[ChatMessage]) -> ChatCompletionResult
    def chat(self, user_content: str, *, system_prompt: str | None = None) -> ChatMessage
```

### 4.3 parse_chat_completion

- 输入：API 返回的 `dict`
- 输出：`ChatCompletionResult`（含 `message`、`usage`、 `finish_reason`）
- 错误：抛 `APIError`（非 print）

## 5. Mock 模式

当 `NEXUS_LLM_MOCK=1`：

1. 不发送真实 HTTP 请求
2. 从 `get_path("chat_completion_sample")` 读取 JSON（即 `day05/sample_data/chat_completion.json`）
3. `_headers()` 不要求 `DEEPSEEK_API_KEY`
4. `load_llm_env()` 不因缺 Key 抛错

## 6. 异常契约

| 场景 | 异常类型 |
|------|----------|
| 非 Mock 且无 API Key | `ConfigError` |
| HTTP 4xx/5xx | `APIError`（含 `status_code`、`response_body`） |
| 网络不可达 | `APIError` |
| 响应非 JSON / 缺 choices | `APIError` |
| API 返回 `error` 字段 | `APIError` |

## 7. 测试

`tests/day12/test_llm_client.py` 覆盖：

- `build_request_body` 结构
- Mock `complete()` 端到端
- `parse_env_file` 注释与引号
- 缺 Key 的 `ConfigError`
- 自定义 `transport` 注入

## 8. 验收命令

```bash
python3 -m pytest tests/day12/ -v
```
