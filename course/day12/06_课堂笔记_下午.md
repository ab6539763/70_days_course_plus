## 第五节：default_transport 走读（14:00 - 14:45）

### 代码路径

`llm/client.py` → `default_transport`

```python
data = json.dumps(payload).encode("utf-8")
req = urllib.request.Request(url, data=data, headers=headers, method="POST")
with urllib.request.urlopen(req, timeout=60) as resp:
    raw = resp.read().decode("utf-8")
    return json.loads(raw)
```

### 异常映射

| 捕获 | 转为 |
|------|------|
| `urllib.error.HTTPError` | `APIError` + status_code + response_body |
| `urllib.error.URLError` | `APIError`（网络） |
| `json.JSONDecodeError` | `APIError` |

**原则**：不让 `urllib` 异常泄露到业务层，统一 `APIError` 便于上层处理（Day 13 retry）。
