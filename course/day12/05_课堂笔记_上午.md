## 第二节：HTTP 速成（09:30 - 10:30）

### 核心概念

| 概念 | 说明 |
|------|------|
| URL | 资源地址，如 `https://api.deepseek.com/v1/chat/completions` |
| 方法 | GET 取资源；POST 提交 body（我们今日用 POST） |
| 请求头 | `Content-Type`、`Authorization` |
| 状态码 | 200 成功；401 鉴权失败；429 限流；5xx 服务端错误 |
| Body | JSON 字符串，UTF-8 编码 |

### 演示：`http_demos.py`

```python
req = urllib.request.Request(url, headers={"User-Agent": "NexusAgent/0.1"})
with urllib.request.urlopen(req, timeout=10) as resp:
    data = json.loads(resp.read().decode("utf-8"))
```

要点：

- `Request` 可设 headers、method
- `urlopen` 返回上下文管理器，`read()` 得 bytes
- 离线环境捕获异常，演示不中断（与 LLM 演示不同）

### 与 REST 的关系

Chat Completions 是 **REST 风格**：资源 `/chat/completions`，动词 POST，表述 JSON。

## 第三节：OpenAI 兼容 API（10:45 - 11:30）

### 消息角色

| role | 用途 |
|------|------|
| system | 系统提示，设定助手行为 |
| user | 用户输入 |
| assistant | 模型历史回复（多轮对话时） |

### 演示：`api_demos.py`

```python
body = build_request_body(messages, config)
# {"model": "...", "temperature": 0.3, "max_tokens": 256, "messages": [...]}
```

对照官方文档核对字段名**完全一致**——这是「兼容」的含义。

### ModelConfig 边界

- `temperature`：0.0-2.0，越低越确定
- `max_tokens`：生成上限，控制成本
