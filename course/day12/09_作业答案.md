### 2. HTTP 错误

```python
except urllib.error.HTTPError as exc:
    body = exc.read().decode("utf-8", errors="replace")
    raise APIError(..., status_code=exc.code, response_body=body)
```

保留服务端返回 body，便于排查 401/429 等。

### 3. chat vs complete

`chat()` 组装 messages（可选 system + user），调用 `complete()`，返回 `result.message`（assistant `ChatMessage`）。`complete()` 是核心，接受完整 messages 列表。

## 作业 E 参考实现

```python
def echo_transport(url, headers, payload):
  user = next(
      (m["content"] for m in reversed(payload["messages"]) if m["role"] == "user"),
      "",
  )
  return {
      "model": payload.get("model", "echo"),
      "choices": [{
          "message": {"role": "assistant", "content": f"Echo: {user}"},
          "finish_reason": "stop",
      }],
      "usage": {"prompt_tokens": 1, "completion_tokens": 1, "total_tokens": 2},
  }

client = LLMClient(transport=echo_transport)
msg = client.chat("你好")
print(msg.content)  # Echo: 你好
```
