## 1. rag/vector.py

```python
def cosine_similarity(a, b):
    na, nb = vector_norm(a), vector_norm(b)
    if na == 0.0 or nb == 0.0:
        return 0.0
    return dot_product(a, b) / (na * nb)
```

**要点**：纯函数、无状态；维度检查在 `dot_product` 抛错。

## 2. rag/embedding.py

### EmbeddingVector

```python
def similarity_to(self, other: EmbeddingVector) -> float:
    return cosine_similarity(self.values, other.values)
```

### TfidfEmbeddingModel.fit

- 遍历语料 `expand_tokens(tokenize(text))`
