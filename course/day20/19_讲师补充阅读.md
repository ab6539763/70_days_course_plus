## 2. TF-IDF 作为 Embedding 的辩护

学员常问：「TF-IDF 算 AI 吗？」

**推荐回答**：

> 今日学的是**向量检索范式**：文本→向量→相似度→top_k。TF-IDF 是最小可运行实现，让你在没有 GPU 和 API 的情况下理解全链路。Day 25 换模型，**代码结构不变**。

## 4. FAQ 与 RAG 产品策略

赵岩定的规则（可向学员传达）：

| sim 区间 | 策略 |
|----------|------|
| FAQ ≥ 0.45 | 可直接返回标准答（今日仅 /similar 预览） |
| 0.32–0.45 | 返回 FAQ + 建议人工复核 |
| < 0.32 | 走 RAG + LLM |
| RAG 空 | 兜底「请咨询客服」 |

Day 21 工具调用将部分自动化此规则。

## 6. 常见学员误区讲评

1. **认为 sim 50% = 只有一半相关** — 应解释为排序分数，非概率  
2. **在关键词路径期待同义词** — 对照 `test_keyword_vs_embedding_synonym`  
3. **FAQ 匹配成功就不做 RAG** — 产品策略问题，技术上可并行
