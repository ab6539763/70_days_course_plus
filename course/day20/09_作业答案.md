## 作业 A 参考答案

### 手算 a=[3,4], b=[4,3]

- dot = 3×4 + 4×3 = 24  
- ‖a‖ = √(9+16) = 5，‖b‖ = 5  
- sim = 24 / 25 = **0.96**

```python
from rag import cosine_similarity
assert math.isclose(cosine_similarity([3.0, 4.0], [4.0, 3.0]), 0.96, rel_tol=0.01)
```

### 正交向量

[1,0] 与 [0,1] 点积为 0，故 sim=0。对应 `test_cosine_similarity_orthogonal`。

## 作业 C 参考答案

| 查询 | KW top1 | EMB top1 |
|------|---------|----------|
| 投资回报率是多少 | 未命中 | sim≈40%+ |
| 年化收益率是多少 | score>0 | sim 更高 |

| 内部资料外传 | 命中 | 命中 |
| 区块链挖矿 | 未命中 | 未命中 |

**结论**：向量检索在同义表达上显著优于关键词；无关话题两者均不应强行命中。
