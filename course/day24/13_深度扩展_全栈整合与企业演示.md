# 深度扩展：全栈整合与企业演示

**需求**：ZL-NA-REQ-024

## 1. 整合方法论

智链内部「整合日」清单：

1. **契约冻结**：不再改 POST /api/chat 字段  
2. **双路径验证**：Mock + API 都要能演示  
3. **门禁脚本**：可重复、可 CI、可一行命令  
4. **丑陋路径**：错误、空输入、服务离线  

## 2. Feature Flag 视角

`config.js` 的 `useMock` 本质是 feature flag。生产可扩展为远程配置，教学用 URL 参数即可。
