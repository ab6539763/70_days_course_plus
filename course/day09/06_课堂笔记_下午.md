### 5.2 ModelValidationError

```python
class ModelValidationError(ValueError):
    def __init__(self, message: str, *, model_type: str = "BaseModel"):
        super().__init__(f"[{model_type}] {message}")
```

继承 `ValueError`，可被 `except ValueError` 捕获；消息带类型前缀便于日志。

### 5.3 ensure_valid 与 to_json_ready

```python
def ensure_valid(self) -> None:
    err = self.validate()
    if err:
        raise ModelValidationError(err, model_type=self.model_type)

def to_json_ready(self) -> dict:
    self.ensure_valid()
    return self.to_dict()
```

**持久化前**调用 `to_json_ready()`，杜绝脏数据写入 JSON。

### 5.4 from_dict_safe

```python
@classmethod
def from_dict_safe(cls, data: dict) -> tuple[T | None, str | None]:
    try:
        obj = cls.from_dict(data)
    except (TypeError, ValueError, KeyError) as exc:
        return None, f"反序列化失败：{exc}"
    err = obj.validate()
    if err:
        return None, err
    return obj, None
```

CLI 层友好；API 层（Day 23）可改用 `ensure_valid` 直接 400。

## 第九节：ModelRegistry 多态（16:45 - 17:30）

```python
class ModelRegistry:
    def register(self, model: BaseModel) -> str | None:
        err = model.validate()
        if err:
            return err
        self._items.append(model)
        return None
```

`register` 参数类型注解为 `BaseModel`，可接受任意子类——**多态容器**。

```python
def serialize_models(models: list[BaseModel]) -> list[dict]:
    return [m.to_json_ready() for m in models]
```

### 9.1 为何不用 Union 类型

```python
# 不推荐 — 每加模型要改类型
def register(self, model: ChatMessage | Contact | ModelConfig): ...

# 推荐 — 开闭原则
def register(self, model: BaseModel): ...
```
