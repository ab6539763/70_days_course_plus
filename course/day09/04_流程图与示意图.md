# Day 9 流程图与示意图

## 1. 类继承图

```mermaid
classDiagram
    class BaseModel {
        <<abstract>>
        +validate()* str
        +to_dict()* dict
        +from_dict()* BaseModel
        +is_valid() bool
        +ensure_valid() void
    }
    class ChatMessage {
        +role str
        +content str
        +to_api_message() dict
    }
    class Contact {
        +id int
        +name str
        +format_line() str
    }
    class ModelConfig {
        +model str
        +temperature float
        +to_api_params() dict
    }
    BaseModel <|-- ChatMessage
    BaseModel <|-- Contact
    BaseModel <|-- ModelConfig
```

## 2. validate 调用链

```
用户数据 → from_dict → 实例 → validate()
                ↓ 失败
         from_dict_safe → (None, err)
                ↓ 成功
         ensure_valid → to_json_ready → save_json
```

## 3. 多态注册

```
register(ChatMessage)  ─┐
register(Contact)      ─┼→ list[BaseModel] → export_all()
register(ModelConfig)  ─┘
```
