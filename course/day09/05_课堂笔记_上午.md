**主题**：继承、super、ABC、抽象方法

## 第一节：继承基础（9:00 - 9:45）

### 1.1 语法

```python
class Animal:
    def speak(self) -> str:
        return "..."

class Dog(Animal):
    def speak(self) -> str:
        return "汪汪"
```

`Dog` **继承** `Animal`，获得父类方法，可**覆盖**（override）。

### 1.2 isinstance 与多态

```python
def make_sound(creature: Animal):
    print(creature.speak())

make_sound(Dog())   # 汪汪
make_sound(Cat())   # 喵喵
```

调用方只依赖 `Animal` 接口，实际行为由子类决定——**多态**。

### 1.3 super()

```python
class Employee:
    def __init__(self, name: str):
        self.name = name

class Developer(Employee):
    def __init__(self, name: str, language: str):
        super().__init__(name)
        self.language = language
```

`super()` 调用父类方法，避免重复写 `Employee.__init__(self, name)`。

## 第二节：方法覆盖与扩展（9:45 - 10:30）

### 2.1 覆盖 validate

Day 8 每个类各自实现 `validate`；Day 9 在 `BaseModel` 声明抽象 `validate`，子类**必须**实现。

```python
class ChatMessage(BaseModel):
    def validate(self) -> str | None:
        ...  # 消息特有规则

class Contact(BaseModel):
    def validate(self) -> str | None:
        ...  # 联系人特有规则
```

### 2.2 扩展父类方法

```python
class BaseModel(ABC):
    def is_valid(self) -> bool:
        return self.validate() is None  # 具体方法，子类直接继承
```

子类无需重写 `is_valid`，自动获得。

## 第三节：抽象基类 ABC（10:30 - 11:30）

### 3.1 为何需要抽象类

没有 ABC 时，可能忘记实现 `validate`：

```python
class BrokenMessage(BaseModel):
    pass  # 未实现 validate — 若 BaseModel 非抽象，实例化后 is_valid 崩溃
```

### 3.2 abc 模块

```python
from abc import ABC, abstractmethod

class BaseModel(ABC):
    @abstractmethod
    def validate(self) -> str | None:
        ...

    @abstractmethod
    def to_dict(self) -> dict:
        ...
```

**无法实例化**未实现全部抽象方法的子类：

```python
BaseModel()  # TypeError
```

### 3.3 @classmethod + @abstractmethod

```python
@classmethod
@abstractmethod
def from_dict(cls, data: dict):
    ...
```

子类工厂方法也纳入契约。

## 第四节：类层次与组合（11:30 - 12:00）

### 4.1 NexusAgent 模型树

```
BaseModel (ABC)
├── ChatMessage
├── Contact
└── ModelConfig
```

### 4.2 继承 vs 组合（复习）

- `MessageHistory` **包含** ChatMessage — 组合
- `ChatMessage` **是** BaseModel — 继承

### 4.3 方法解析顺序 MRO

```python
>>> ChatMessage.__mro__
(<class 'models.message.ChatMessage'>,
 <class 'models.llm_base.BaseModel'>,
 <class 'abc.ABC'>,
 <class 'object'>)
```

调用 `msg.is_valid()` 时，Python 沿 MRO 查找，在 `BaseModel` 找到具体实现。

### 4.4 禁止多重业务继承

NexusAgent 规范：**一个领域类只继承一个 BaseModel**。多重继承留作高级选修，避免 MRO 混乱。

## 上午小结

| 概念 | 要点 |
|------|------|
| 继承 | class Child(Parent) |
| 覆盖 | 子类同名方法替换父类 |
