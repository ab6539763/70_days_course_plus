# ZL-NA-REQ-009：BaseModel 抽象类体系

**版本**：v0.1.0  
**作者**：陈默 / 赵岩  
**状态**：已批准  
**依赖**：ZL-NA-REQ-008

## 1. 概述

建立 `models/llm_base.py` 中的 `BaseModel` 抽象基类，统一全平台领域模型的校验与序列化契约；重构既有模型并新增 `ModelConfig`。

## 2. BaseModel 规格

### 2.1 抽象方法（子类必须实现）

| 方法 | 签名 |
|------|------|
| validate | `() -> str \| None` |
| to_dict | `() -> dict` |
| from_dict | `(cls, data: dict) -> Self` |

### 2.2 具体方法（基类提供）

| 方法 | 说明 |
|------|------|
| is_valid() | validate() is None |
| ensure_valid() | 失败抛 ModelValidationError |
| to_json_ready() | ensure_valid + to_dict |
| from_dict_safe() | 返回 (obj, err) 不抛异常 |
| model_type | 属性，类名 |

## 3. 子类清单

| 类 | 文件 | 说明 |
|----|------|------|
| ChatMessage | models/message.py | 重构继承 BaseModel |
| Contact | models/contact.py | 自 day08 迁入 |
| ModelConfig | models/model_config.py | LLM 参数 |

## 4. ModelConfig 字段

| 字段 | 默认 | 校验 |
|------|------|------|
| model | deepseek-chat | 非空 |
| temperature | 0.7 | 0.0 - 2.0 |
| max_tokens | 1024 | > 0 |

## 5. 异常

`ModelValidationError(ValueError)` — 含 model_type 前缀消息。

## 6. 测试
