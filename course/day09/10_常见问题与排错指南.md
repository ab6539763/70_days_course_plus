# Day 9 常见问题与排错指南

## Q1：TypeError: Can't instantiate abstract class

子类未实现全部 `@abstractmethod`。检查 validate / to_dict / from_dict。

## Q2：ChatMessage 还能用吗？

能。仅增加 `BaseModel` 父类，对外 API 不变。

## Q3：from day08.contact_class import Contact 失败

确保 `PYTHONPATH=src`，且 Day 9 已更新 contact_class 为 re-export。

## Q4：ModelValidationError 与 ValueError

ModelValidationError 是 ValueError 子类，`except ValueError` 可捕获。

## Q5：能否实例化 BaseModel？

不能。`BaseModel()` 直接 TypeError。

## Q6：抽象类能有 __init__ 吗？

能。BaseModel 未定义 __init__，子类各自定义。

## Q7：多重继承

今日不涉及。Python 支持 `class X(A, B)`，MRO 按 C3 线性化。

## Q8：ModelConfig 的 model 字段与 self.model 冲突？

Python 允许属性名 `model`，注意不与类变量混淆。

## Q9：pytest 报 isinstance 失败

确认 `from models import ChatMessage, BaseModel`，非旧缓存模块。

## Q10：与 Pydantic 冲突？

包名不同：`models.llm_base.BaseModel` vs `pydantic.BaseModel`。Day 23 并存时注意 import 路径。
