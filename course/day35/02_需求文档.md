# ZL-NA-REQ-035 产品需求文档（PRD）

**需求名称**：多查询扩展（Query Expansion / HyDE）
**优先级**：P0
**平台版本**：v0.35.0

---

## 1. 背景

质检发现「理财安全吗」这类模糊问句，单条 query 召回经常漏掉真正相关的 chunk，Recall 不够宽。 引入 QueryExpander：把一条问句用模板/HyDE mock 拓展成多条候选 query，ExpandingRetriever 多路并发召回后按 chunk_id 去重合并，再进入既有的 rerank → citations 管线。

## 2. 目标

- `rag/query_expander.py` — QueryExpander — Template / HyDE mock 扩展
- `rag/expanding_retriever.py` — ExpandingRetriever — 多路 search + merge
- `rag/expansion_config.py` — ExpansionConfig — enabled / max_queries / per_query_top_k
- `rag/result_merger.py` — merge_retrieval_results — chunk_id 去重合并
- `GET/PUT /api/knowledge/expansion-config` 配置读写
- `POST /api/knowledge/expansion-preview` 无状态预览
- `POST /api/chat` 端到端集成

## 3. 功能需求

### FR-001 QueryExpander — Template / HyDE mock 扩展

- 实现位置：`rag/query_expander.py`

### FR-002 ExpandingRetriever — 多路 search + merge

- 实现位置：`rag/expanding_retriever.py`

### FR-003 ExpansionConfig — enabled / max_queries / per_query_top_k

- 实现位置：`rag/expansion_config.py`

### FR-004 merge_retrieval_results — chunk_id 去重合并

- 实现位置：`rag/result_merger.py`

### FR-005 持久化与 status

- `store.json` 新增 `expansion_config` 字段
- `GET /api/knowledge/status` 含 `expansion_config`
- `platform_version` 为 `v0.35.0`

### FR-006 Chat 集成

- `api/chat.py` 在管线中调用本日模块
- `ChatResponse` 相应字段附带本日审计信息

### FR-007 演示与测试

- `day35/expansion_demo.py` 打印对比结果
- `day35/expansion_api_demo.py` 演示 REST API
- `tests/day35/` 20 项覆盖单元 + API + chat

## 4. 非功能需求

### NFR-001 可观测性

status / preview 接口可读当前 `expansion_config`。

### NFR-002 兼容性

`ExpansionConfig.enabled=false` 时行为回退到 Day 34 逻辑，不影响既有回归。

### NFR-003 可测试性

`ExpandingRetriever` 可脱离 FastAPI 直接单测。

## 5. 非目标

- 接入真实模型替换当前 mock 规则实现
- 跨会话的长期缓存
