### 1.2 变量与数据类型

| 类型 | 示例 | 可变？ |
|------|------|--------|
| int | `42` | 不可变 |
| float | `3.14` | 不可变 |
| str | `"Nexus"` | 不可变 |
| bool | `True` | 不可变 |
| list | `[1, 2, 3]` | **可变** |
| dict | `{"a": 1}` | **可变** |
| None | `None` | — |

### 1.3 字符串核心操作

```python
s = "  Nexus Agent  "
s.strip()           # 去首尾空白
s.lower() / upper()
s.split(",")        # 分割
",".join(["a", "b"]) # 拼接
f"{name} v{version}" # f-string 格式化
"内部" in s          # 子串判断
```

Day 2 `text_cleaner` 本质是对字符串的**管道式处理**：strip → 合并空白 → 敏感词替换。

## 第四节：Day 5 dict 与 JSON（10:50 - 11:30）

### 4.1 dict 操作

```python
contact = {
    "id": 1,
    "name": "陈默",
    "phone": "13800001001",
    "email": "chenmo@zhilian-tech.com",
    "group": "研发部",
}

contact["name"]              # 访问
contact.get("fax", "无")     # 安全访问
contact["group"] = "架构组"  # 修改
del contact["fax"]           # 删除

for key, value in contact.items():
    print(key, value)
```

### 4.2 JSON 持久化

```python
import json
with open(path, "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open(path, "r", encoding="utf-8") as f:
    data = json.load(f)
```

Day 5 核心认知：**内存中的 dict/list ↔ 磁盘上的 JSON 文件**。
