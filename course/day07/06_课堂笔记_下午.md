## 第七节：从需求到数据模型（14:00 - 14:30）

### 7.1 字段设计

通讯录比待办多了 **phone**、**email**、**group**，少了 **done**、**priority**。

```python
{
    "id": 1,
    "name": "陈默",
    "phone": "13800001001",
    "email": "chenmo@zhilian-tech.com",
    "group": "平台研发部",
    "created_at": "2026-07-12T01:00:00Z",
}
```

### 7.2 store 结构

与待办一致的模式：

```python
{
    "version": "1.0",
    "next_id": 4,       # 下一个可用 id
    "contacts": [...],    # 列表存多条 dict
    "updated_at": "...",
}
```

**设计原则**：顶层 dict 是「容器」，列表元素是「实体」。

### 8.1 加载与保存

```python
def load_store(path: Path) -> dict:
    data = load_json(path, default=empty_store())
    ensure_dict_keys(data, {"version": "1.0", "next_id": 1, "contacts": []})
    return data

def save_store(path: Path, data: dict) -> None:
    data["updated_at"] = now_iso()
    save_json(path, data)
```

与 Day 6 `todo_manager_v3` 相同模式，换字段名即可——这就是**可迁移性**。

### 8.2 校验聚合

```python
def validate_contact_fields(name, phone, email) -> str | None:
    for check in (
        require_non_empty(name, "姓名"),
        validate_phone(phone),
        validate_email(email),
    ):
        if check:
            return check
    return None
```

**模式**：多个校验函数返回 `错误消息 | None`，遇到第一个错误即返回。

### 8.3 添加联系人

```python
def add_contact(store, name, phone, email, group="未分组"):
    err = validate_contact_fields(name, phone, email)
    if err:
        return None, err
    contact = create_contact(store["next_id"], name, phone, email, group)
    store["contacts"].append(contact)
    store["next_id"] += 1
    return contact, None
```

返回 `(结果, 错误)` 元组，CLI 层根据错误决定是否 print。

### 8.4 搜索函数

```python
def search_by_name(contacts, keyword):
    kw = keyword.strip().lower()
    return [c for c in contacts if kw in c.get("name", "").lower()]

def search_by_group(contacts, group):
    return [c for c in contacts if c.get("group", "") == group.strip()]
```

列表推导 + 字符串方法，Day 4-5 技能的直接应用。

### 8.5 分组统计

```python
def group_stats(contacts) -> dict[str, int]:
    stats = {}
    for c in contacts:
        g = c.get("group", "未分组")
        stats[g] = stats.get(g, 0) + 1
    return stats
```

`dict.get(g, 0) + 1` 是计数器的经典写法。

## 第十节：validate_phone 实现（16:30 - 16:50）

```python
def validate_phone(phone: str) -> str | None:
    phone = (phone or "").strip()
    if not phone:
        return "手机号不能为空"
    if not re.match(r"^1\d{10}$", phone):
        return "手机号格式不正确（需 11 位且以 1 开头）"
    return None
```

正则 `^1\d{10}$`：以 1 开头 + 10 位数字。企业版可扩展运营商号段表。
