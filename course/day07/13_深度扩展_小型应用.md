## 1. 贫血模型 vs 当前 dict 模式

今日联系人用 dict 存储，逻辑在 `contact_service` 函数中——称为**贫血模型**（数据与行为分离）。Day 8 将用类把数据和行为绑在一起（**充血模型**雏形）。

## 4. 日志而非 print

```python
import logging
log = logging.getLogger(__name__)
log.info("已添加联系人 id=%s", contact["id"])
```

企业代码逐步用 logging 替代 print，CLI 可保留 print 给用户。

## 5. 数据迁移

若 JSON `version` 从 1.0 升到 2.0（新增 `department` 字段），在 `load_store` 中：

```python
if data.get("version") == "1.0":
    for c in data["contacts"]:
        c.setdefault("department", c.pop("group", "未分组"))
    data["version"] = "2.0"
```
