## 二、流程控制

```python
if cond:
    ...
elif other:
    ...
else:
    ...

while cond:
    ...
    break / continue

for x in iterable:
    ...
```

## 八、易错点 TOP 10

1. 缩进混用 Tab 与空格  
2. `dict` 访问用 `[]` 键不存在报 KeyError  
3. 默认参数 `def f(a=[])`  
4. 忘记 `encoding="utf-8"` 读写中文  
5. JSON 中 `true/false` vs Python `True/False`  
6. `import utils` 未设置 PYTHONPATH  
7. 修改 list 遍历时删除元素  
8. `input` 返回 str，比较数字需 `int()`  
9. 文件未 `save` 就退出  
10. 复制粘贴校验逻辑而非用 validators
