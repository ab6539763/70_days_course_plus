## 2. 添加联系人时序

```mermaid
sequenceDiagram
    participant U as 用户
    participant CLI as contacts_manager
    participant S as contact_service
    participant V as validators
    participant J as json_utils

    U->>CLI: "输入姓名/手机/邮箱/分组"
    CLI->>S: "add_contact(store, ...)"
    S->>V: validate_contact_fields
    alt 校验失败
        V-->>S: 错误消息
        S-->>CLI: None, err
        CLI-->>U: 显示错误
    else 校验通过
        S->>S: create_contact + append
        S-->>CLI: contact, None
        CLI-->>U: 添加成功
    end
    U->>CLI: 选择 0 退出
    CLI->>S: save_store
    S->>J: save_json
```
