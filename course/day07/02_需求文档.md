## 2. 数据模型

### 2.1 存储文件

路径：`src/day07/data/contacts.json`

### 2.2 JSON Schema

```json
{
  "version": "1.0",
  "next_id": 4,
  "updated_at": "ISO8601",
  "contacts": [
    {
      "id": 1,
      "name": "陈默",
      "phone": "13800001001",
      "email": "chenmo@zhilian-tech.com",
      "group": "平台研发部",
      "created_at": "ISO8601",
      "updated_at": "ISO8601（可选，编辑后）"
    }
  ]
}
```

### 2.3 字段约束

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| name | string | 是 | require_non_empty |
| phone | string | 是 | validate_phone（11 位，1 开头） |
| email | string | 是 | validate_email |
| group | string | 否 | 默认「未分组」 |
