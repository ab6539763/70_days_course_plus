## 1. Unicode 与 Python 字符串

Python 3 的 `str` 是 Unicode 字符串。中文、emoji 各算一个字符：

```python
print(len("智链"))   # 2
print(len("🎉"))     # 1
```

终端显示宽度可能与 `len()` 不一致——Day 1 卡片对齐问题的根源。
