# Day 2 常见问题与排错指南

---

## Q1: `TypeError: unsupported operand type(s) for +: 'int' and 'str'`

**原因**：`+` 两侧类型不一致。

```python
# 错误
print("年龄：" + 25)
# 正确
print(f"年龄：{25}")
print("年龄：" + str(25))
```

---

## Q2: 切片越界 `IndexError`？

**好消息**：切片**不会**越界报错。

```python
s = "hi"
print(s[100])   # IndexError（单索引会）
print(s[100:])  # '' 空字符串（切片不会）
```

---

## Q3: 敏感词替换后 `"内部内部"` 只替换一次？

检查循环逻辑，应使用 `while find` 而非单次 `replace`（大小写不敏感时更复杂）。

---

## Q4: `argparse` 报错 `the following arguments are required`

必须提供 `--input` 或 `--text` 之一。检查 `parse_args` 互斥逻辑。

---

## Q5: f-string 里不能用反斜杠？

```python
# 错误
# f"{\'hi\'}"
# 正确
name = "hi"
print(f"{name}")
```

---

## Q6: 清洗后中文乱码？

确保文件 `encoding="utf-8"` 读写。

```python
path.read_text(encoding="utf-8")
```
