## 第七节：字符串基础（14:00 - 14:40）

### 7.1 字符串的本质

Python 中字符串是**不可变（immutable）**的字符序列：

```python
s = "Hello"
# s[0] = "h"  # ❌ TypeError: str does not support item assignment
```

不可变意味着：所有「修改」操作都**返回新字符串**，原字符串不变。

```python
s = "  hello  "
t = s.strip()   # t = "hello"，s 仍是 "  hello  "
```

### 7.2 索引与切片

#### 索引

```python
text = "NexusAgent"
#       0123456789
#      -10......-1

print(text[0])    # 'N'
print(text[5])    # 'A'
print(text[-1])   # 't'（最后一个）
print(text[-2])   # 'n'
```

#### 切片 `[start:end:step]`

```python
text = "NexusAgent"

print(text[0:5])    # 'Nexus'   含头不含尾
print(text[5:])     # 'Agent'   从索引5到末尾
print(text[:5])     # 'Nexus'   从头到索引5
print(text[:])      # 'NexusAgent' 完整复制
print(text[::2])    # 'Nxsget'  步长2
print(text[::-1])   # 'tnegAxuseN' 反转
```

**企业应用**：截取 API Key 用于日志脱敏

```python
api_key = "sk-1234567890abcdef"
masked = api_key[:7] + "..." + api_key[-4:]
print(masked)  # sk-1234...cdef
```

### 7.3 常用字符串方法

| 方法 | 作用 | 示例 | 返回值 |
|------|------|------|--------|
| `strip()` | 去首尾空白 | `"  hi  ".strip()` | `"hi"` |
| `lstrip()` | 去左侧空白 | | |
| `rstrip()` | 去右侧空白 | | |
| `lower()` | 转小写 | `"API".lower()` | `"api"` |
| `upper()` | 转大写 | | |
| `replace(old, new)` | 替换 | `"a-b".replace("-","_")` | `"a_b"` |
| `split(sep)` | 分割为列表 | `"a,b".split(",")` | `['a','b']` |
| `join(iter)` | 连接 | `",".join(['a','b'])` | `"a,b"` |
| `find(sub)` | 查找位置 | `"hello".find("ll")` | `2`（无则-1） |
| `count(sub)` | 计数 | `"aaa".count("a")` | `3` |
| `startswith(p)` | 前缀判断 | | bool |
| `endswith(s)` | 后缀判断 | | bool |
| `isdigit()` | 是否全数字 | `"123".isdigit()` | `True` |

## 第八节：f-string 格式化（14:40 - 15:20）

### 8.1 为什么 f-string 是核心技能？

Prompt 工程 = 字符串模板 + 变量填充。f-string 是 Python 里最清晰的写法。

```python
# 三种格式化方式对比
name = "张三"
age = 25

# 方式 1：% 格式化（老派，不推荐）
msg = "我是%s，今年%d岁" % (name, age)

# 方式 2：str.format()（可用）
msg = "我是{}，今年{}岁".format(name, age)

# 方式 3：f-string（推荐，Python 3.6+）
msg = f"我是{name}，今年{age}岁"
```

### 8.2 f-string 基础

```python
name = "NexusAgent"
version = 0.1
count = 3

# 直接嵌入变量
print(f"项目: {name}")

# 嵌入表达式
print(f"明年版本: {version + 1}")
print(f"敏感词替换: {count} 次")
print(f"是否为空: {len(name) == 0}")

# 调用方法
text = "  hello  "
print(f"清洗后: '{text.strip()}'")
```

### 8.3 格式说明符

```python
# 浮点数精度

# 千分位

# 宽度与对齐

# 整数补零

```

#### 核心清洗函数

```python
def collapse_whitespace(text: str) -> str:
    """将连续空白字符合并为单个空格"""
    result = []
    prev_space = False
    for char in text:
        if char in " \t":
            if not prev_space:
                result.append(" ")
                prev_space = True
        else:
            result.append(char)
            prev_space = False
    return "".join(result)


def collapse_duplicate_punctuation(text: str) -> str:
    """合并连续相同标点为一个"""
    if not text:
        return text
    result = [text[0]]
    for char in text[1:]:
        if char == result[-1] and not char.isalnum():
            continue
        result.append(char)
    return "".join(result)


def mask_sensitive_words(text: str, words: list) -> tuple[str, int]:
    """
    敏感词替换（不区分大小写）
    
    Returns:
        (替换后文本, 替换次数)
    """
    count = 0
    result = text
    for word in words:
        lower_result = result.lower()
        lower_word = word.lower()
        start = 0
        while True:
            idx = lower_result.find(lower_word, start)
            if idx == -1:
                break
            result = result[:idx] + "***" + result[idx + len(word):]
            lower_result = result.lower()
            count += 1
            start = idx + 3
    return result, count
```

#### 主管道 clean_text

```python
def clean_text(raw: str, to_lower: bool = False) -> tuple[str, dict]:
    """
    执行完整清洗管道
    
    Returns:
        (清洗后文本, 统计信息字典)
    """
    stats = {
        "raw_len": len(raw),
        "replace_count": 0,
        "empty_dropped": 0,
    }
    
    lines = raw.split("\n")
    cleaned_lines = []
    
    for line in lines:
        line = line.strip()
        if not line:
            stats["empty_dropped"] += 1
            continue
        line = collapse_whitespace(line)
        line = collapse_duplicate_punctuation(line)
        line, n = mask_sensitive_words(line, SENSITIVE_WORDS)
        stats["replace_count"] += n
        if to_lower:
            line = line.lower()
        cleaned_lines.append(line)
    
    result = "\n".join(cleaned_lines)
    stats["clean_len"] = len(result)
    return result, stats
```
