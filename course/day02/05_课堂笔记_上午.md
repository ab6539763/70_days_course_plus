## 第二节：算术运算符（9:20 - 9:50）

### 2.1 七种算术运算符

| 运算符 | 名称 | 示例 | 结果 | 备注 |
|--------|------|------|------|------|
| `+` | 加法 | `3 + 2` | `5` | 字符串可拼接 |
| `-` | 减法 | `5 - 2` | `3` | |
| `*` | 乘法 | `4 * 3` | `12` | 字符串可重复 |
| `/` | 除法 | `7 / 2` | `3.5` | 结果总是 float |
| `//` | 整除 | `7 // 2` | `3` | 向下取整 |
| `%` | 取模 | `7 % 2` | `1` | 余数 |
| `**` | 幂运算 | `2 ** 3` | `8` | |

### 2.2 详细示例

```python
# 加法
a = 10 + 5        # 15

# 字符串拼接（两个 str 才能用 +）
greeting = "Hello" + " " + "World"  # "Hello World"
# greeting = "年龄" + 25  # ❌ TypeError

# 字符串重复（Day 1 用过 "=" * 50）
line = "-" * 40   # "----------------------------------------"
banner = "★" * 5  # "★★★★★"

# 除法永远返回浮点
print(10 / 2)     # 5.0（是 float，不是 int）
print(type(10/2)) # <class 'float'>

# 整除：丢弃小数部分
print(7 // 2)     # 3
print(-7 // 2)    # -4（向下取整，不是向零）

# 取模：判断奇偶
print(25 % 2)     # 1（奇数）
print(24 % 2)     # 0（偶数）

# 幂运算
print(2 ** 10)    # 1024
print(9 ** 0.5)   # 3.0（平方根）
```

## 第三节：比较运算符（9:50 - 10:30）

### 3.1 六种比较运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `5 != 3` | `True` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于等于 | `5 >= 5` | `True` |
| `<=` | 小于等于 | `3 <= 5` | `True` |

**重要**：`==` 是比较，`=` 是赋值，不要混淆！

```python
x = 5      # 赋值
x == 5     # 比较，结果是 True
```

### 3.2 字符串比较

字符串按**字典序（lexicographic）**逐字符比较：

```python
print("apple" < "banana")   # True（a < b）
print("Apple" < "apple")    # True（大写字母 ASCII 码更小）
print("10" < "2")           # True！字符串比较，"1" < "2"
```

**这就是为什么文本清洗需要统一大小写**——`"API" == "api"` 是 `False`，检索时会漏掉。

### 3.3 链式比较

Python 支持数学风格的链式比较：

```python
age = 25
print(18 <= age <= 65)   # True
# 等价于：18 <= age and age <= 65

score = 85
print(60 <= score < 90)  # True（及格且未优秀）
```

### 3.4 企业场景

```python

if similarity >= 0.85:
    print("高相关，采用此文档块")
```

## 第四节：逻辑运算符（10:30 - 11:10）

### 4.1 三个逻辑运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `and` | 与（都真才真） | `True and False` → `False` |
| `or` | 或（有真即真） | `True or False` → `True` |
| `not` | 非（取反） | `not True` → `False` |

### 4.2 真值表

**and**：

| A | B | A and B |
|---|---|---------|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

**or**：

| A | B | A or B |
|---|---|--------|
| T | T | T |
| T | F | T |
| F | T | T |
| F | F | F |

### 4.3 短路求值

```python
# and：左边 False，右边不再计算
False and print("不会执行")

# or：左边 True，右边不再计算
True or print("不会执行")
```

企业应用：避免空指针式错误

```python
text = ""
# 只有 text 非空时才处理
should_process = text and len(text) > 0
```

### 4.4 成员运算符（补充）

|--------|------|------|
| `in` | 包含 | `"ell" in "hello"` → `True` |
| `not in` | 不包含 | `"xyz" not in "hello"` → `True` |

## 第五节：运算符优先级（11:10 - 11:45）

### 5.1 优先级表（从高到低）

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1 | `()` | 括号 |
| 2 | `**` | 幂 |
| 3 | `*`, `/`, `//`, `%` | 乘除 |
| 4 | `+`, `-` | 加减 |
| 5 | `<`, `<=`, `>`, `>=`, `==`, `!=` | 比较 |
| 6 | `not` | 逻辑非 |
| 7 | `and` | 逻辑与 |
| 8 | `or` | 逻辑或 |

### 5.2 例题演练

```python
# 例题 1
result = 3 + 4 * 2
# 先乘后加：4*2=8, 3+8=11
print(result)  # 11

# 例题 2
result = (3 + 4) * 2
# 括号优先：7*2=14
print(result)  # 14

# 例题 3
result = 10 > 5 and 3 < 7
# 先比较：True and True = True
print(result)  # True

# 例题 4
result = not False or True and False
# not False = True
# True and False = False
# True or False = True
print(result)  # True

# 例题 5：压缩率
raw, clean = 1284, 1102
rate = (raw - clean) / raw * 100
# 先减、后除、后乘
print(f"{rate:.1f}%")  # 14.2%
```

**企业建议**：复杂表达式加括号，不要依赖记忆优先级。

```python
# 不好
ok = age >= 18 and age <= 65 and name != ""

# 更好
ok = (18 <= age <= 65) and (name != "")
```
