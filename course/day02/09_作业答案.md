## 题目四（思路）

```python
import re

def mask_phone(text: str) -> tuple[str, int]:
    pattern = r"1\d{10}"
    count = len(re.findall(pattern, text))
    result = re.sub(pattern, "[手机号已脱敏]", text)
    return result, count
```

## 题目五（参考答案）

### 1. 字符串不可变的好处

不可变意味着每次清洗返回新对象，原始数据可保留用于对比和审计。企业场景中需要「清洗前后 diff」时，immutable 更安全。

### 2. split() vs split("\n")

`splitlines()` / `split()` 能处理 `\r\n`；`split("\n")` 在 Windows 文本可能留下 `\r`。

### 3. 大小写统一

用户问「api 接口」而文档写「API 接口」，不统一小写会导致 Embedding 距离变大、召回失败。

### 4. f-string 与 Prompt

Prompt 模板本质是带占位符的字符串；f-string 的 `{}` 就是占位符，Day 17 会封装为模板类。

### 5. 影响最大的规则

通常 **空白规范化 + 空行删除** 对 chunk 质量影响最大，因直接影响分词和 Embedding 输入。
