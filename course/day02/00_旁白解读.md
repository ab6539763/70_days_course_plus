## 为什么先学运算符，再学字符串？

上午学运算符，下午学字符串——这个顺序是刻意的。

昨天你写了 `age = int(input(...))`，背后发生了隐式类型转换。今天你会写：

```python
score = 85
passed = score >= 60   # 比较运算符，结果是 bool
```

大模型开发中，比较运算符无处不在：

```python
# Day 16：根据 temperature 决定采样策略
if temperature > 1.0:
    print("警告：temperature 过高，输出可能不稳定")

# Day 34：RAG 评估，相似度是否过阈值
if cosine_similarity > 0.85:
    use_this_chunk = True

# Day 46：Agent 输出长度校验
if len(response) > max_tokens * 4:
    truncate_response()
```

**运算符是「判断」的基础，字符串是「处理」的基础。** Day 3 会把两者结合起来写 `if` 和循环。

## f-string：今天最重要的一项技能

下午会重点讲 **f-string**。请把它当作 Day 17「Prompt 模板」的预习：

```python
# Day 2：格式化清洗报告
print(f"原始长度: {raw_len} → 清洗后: {clean_len}，压缩率: {ratio:.1%}")

# Day 17：Prompt 模板（本质相同）
prompt = f"""你是一个专业的客服助手。
用户问题：{user_question}
参考文档：
{context}
请基于文档回答，不要编造。"""
```

**花括号 `{}` 里可以放任何 Python 表达式。** 这是 Prompt 工程最核心的技术手段。
