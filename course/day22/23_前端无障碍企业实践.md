# Day 22 前端无障碍企业实践

**专题**：智链科技 a11y 基线  
**需求**：ZL-NA-REQ-022

---

## 1. 法规与品牌背景

智链科技对外产品须满足基础无障碍要求。聊天页虽为内训 Demo，仍按生产标准实现，培养习惯。

## 2. 已实现项

| 技术 | 位置 | 作用 |
|------|------|------|
| aria-live="polite" | #messages | 动态消息播报 |
| visually-hidden label | user-input | 读屏标签 |
| aria-hidden on 装饰 | avatar, loading dots | 减少噪音 |
| 文字按钮 | 发送 | 非纯图标 |
| role="main" | chat-container | 地标 |

## 3. 键盘路径

Tab → 聚焦输入框 → 输入 → Enter 发送。无需鼠标即可完成对话。

## 4. 对比度

`--brand #1a56db` 上白字约 8:1。`--text-muted` 仅用于次要 meta，非正文。
