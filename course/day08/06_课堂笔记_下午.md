## 第六节：ChatMessage 完整实现 walkthrough（14:00 - 15:00）

### 6.1 文件位置

`src/models/message.py` — 全项目唯一 `ChatMessage` 定义处。

### 6.2 构造与规范化

```python
def __init__(self, role: str, content: str, *, created_at: str | None = None):
    self.role = (role or "").strip().lower()
    self.content = (content or "").strip()
    self.created_at = created_at or _now_iso()
```

**设计决策**：

- role 统一小写，避免 `"User"` vs `"user"` 比较失败
- content strip，与 Day 6 `require_non_empty` 语义一致
- `created_at` 用仅关键字参数，强制调用方显式命名

### 6.3 校验

```python
def validate(self) -> str | None:
    if self.role not in VALID_ROLES:
        return f"角色必须是 {', '.join(VALID_ROLES)} 之一"
    if not self.content:
        return "消息内容不能为空"
    return None
```

返回错误消息而非 `raise` — 与 utils validators 风格一致，CLI 友好。

### 6.4 两种 dict 导出

```python
def to_dict(self) -> dict:
    return {"role": self.role, "content": self.content, "created_at": self.created_at}

def to_api_message(self) -> dict:
    return {"role": self.role, "content": self.content}
```

| 方法 | 含 created_at | 用途 |
|------|---------------|------|
| to_dict | 是 | 本地 JSON 存档 |
| to_api_message | 否 | 发给 LLM API |

**常见错误**：把 `created_at` 发给 API，部分接口会忽略，但浪费 token 且不规范。

### 6.5 与 Day 5 衔接

```python
@classmethod
def from_api_response(cls, parsed: dict) -> ChatMessage:
    return cls(
        role=parsed.get("role") or "assistant",
        content=parsed.get("content", ""),
    )
```

`parsed` 来自 `api_response_parser.parse_chat_completion()`。

## 第七节：MessageHistory（15:00 - 15:45）

### 7.1 职责

管理 `list[ChatMessage]`，提供：

- 追加（带校验）
- 按角色筛选
- 导出 API 数组
- JSON 持久化

### 7.2 封装内部列表

```python
@property
def messages(self) -> list[ChatMessage]:
    return list(self._messages)  # 返回副本
```

防止外部 `history.messages.append(...)` 绕过 `add()` 的校验。

### 7.3 便捷方法

```python
def add_user(self, content: str) -> str | None:
    return self.add(ChatMessage("user", content))
```

减少 CLI 层重复构造。

### 7.4 持久化格式

```json
{
  "messages": [
    {"role": "system", "content": "...", "created_at": "..."},
    {"role": "user", "content": "...", "created_at": "..."}
  ]
}
```
