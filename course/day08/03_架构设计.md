# Day 8 架构设计

## 1. 包结构

```
src/
├── models/              # 领域模型（长期）
│   ├── __init__.py
│   └── message.py       # ChatMessage
├── day08/               # 当日实验与 CLI
│   ├── message_history.py
│   ├── message_cli.py
│   ├── oop_demos.py
│   └── contact_class.py
└── utils/               # 横切工具（不变）
```

**原则**：`models` 不依赖 `day08`；`day08` 可依赖 `models`。

## 2. 数据流

```mermaid
sequenceDiagram
    participant U as 用户
    participant CLI as message_cli
    participant H as MessageHistory
    participant M as ChatMessage
    participant J as json_utils

    U->>CLI: 输入用户消息
    CLI->>M: ChatMessage("user", text)
    CLI->>H: add(message)
    H->>M: validate()
    U->>CLI: 导出 API 格式
    CLI->>H: to_api_messages()
    U->>CLI: 退出
    CLI->>H: save_json
    H->>J: save_json
```
