# ZL-NA-REQ-008：ChatMessage 类与消息历史

**版本**：v0.1.0  
**作者**：陈默 / 赵岩  
**状态**：已批准  
**依赖**：ZL-NA-REQ-006（utils）、ZL-NA-REQ-005（API message 格式）

## 1. 概述

建立 `src/models/message.py` 中的 `ChatMessage` 类，作为 NexusAgent 全平台统一消息模型；并提供 `MessageHistory` 容器与 `message_cli` 实验工具。

## 2. ChatMessage 规格

### 2.1 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| role | str | system / user / assistant |
| content | str | 消息正文 |
| created_at | str | ISO8601 UTC |

### 2.2 方法

| 方法 | 说明 |
|------|------|
| `validate()` | 返回错误消息或 None |
| `to_dict()` | 含 created_at 的完整 dict |
| `from_dict(data)` | 类方法，反序列化 |
| `from_api_response(parsed)` | 从 Day5 解析结果构造 |
| `to_api_message()` | 仅 role+content，供 API 请求 |
| `format_line()` | 终端展示 |
| `is_system/user/assistant()` | 角色判断 |

### 2.3 校验规则

- role 必须在 VALID_ROLES 内
- content 去空白后非空

## 3. MessageHistory 规格

| 方法 | 说明 |
|------|------|
| add(message) | 校验后追加 |
| add_user/add_assistant/add_system | 便捷方法 |
| to_api_messages() | list[dict] API 格式 |
| save_json / load_json | 持久化 |

存储路径：`src/day08/data/messages.json`

## 4. 与 OpenAI Chat API 对齐

请求体 messages 数组元素：

```json
{"role": "user", "content": "你好"}
```

`to_api_message()` 必须严格只含这两键。
