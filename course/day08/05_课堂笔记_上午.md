## 第一节：为何需要类（9:00 - 9:30）

### 1.1 dict 的痛点

```python
msg = {"role": "user", "content": "你好"}
msg["rol"] = "user"   # 拼写错误，运行时不报错
msg["content"] = ""   # 空内容，没有统一校验入口
```

### 1.2 class 的直觉

**类**是「制造对象的图纸」；**对象**（实例）是按图纸生产出来的实体。

```python
class ChatMessage:
    def __init__(self, role, content):
        self.role = role
        self.content = content

msg = ChatMessage("user", "你好")  # 实例化
print(msg.role)
```

数据 `role`、`content` 和操作它们的函数 `validate` 写在同一个 class 里——**封装**。

## 第二节：class 定义语法（9:30 - 10:30）

### 2.1 基本结构

```python
class ClassName:
  """类的文档字符串"""

    def __init__(self, 参数):
        """构造方法，创建实例时自动调用"""
        self.属性 = 参数

    def 实例方法(self):
        """第一个参数必须是 self，代表当前实例"""
        return self.属性
```

### 2.2 self 是什么

`self` 指向**当前对象**。调用 `msg.validate()` 时，Python 等价于 `ChatMessage.validate(msg)`。

```python
msg = ChatMessage("user", "hi")
msg.validate()  # self 就是 msg
```

### 2.3 属性 vs 局部变量

```python
def __init__(self, role, content):
    self.role = role      # 实例属性，整个对象生命周期存在
    temp = role.upper()   # 局部变量，__init__ 结束即销毁
```

## 第三节：实例方法与类方法（10:30 - 11:30）

### 3.1 实例方法

```python
def validate(self) -> str | None:
    if self.role not in VALID_ROLES:
        return "角色非法"
    return None
```

### 3.2 @classmethod

**类方法**第一个参数是 `cls`（类本身），常用于**替代构造器**：

```python
@classmethod
def from_dict(cls, data: dict) -> ChatMessage:
    return cls(
        role=data.get("role", ""),
        content=data.get("content", ""),
    )
```

调用：`ChatMessage.from_dict({"role": "user", "content": "hi"})` — 不需要先有空实例。

**对比**：

| 类型 | 第一个参数 | 典型用途 |
|------|------------|----------|
| 实例方法 | self | 操作实例数据 |
| 类方法 | cls | from_dict、工厂方法 |
| 静态方法 | 无 | 与类逻辑相关但不访问 self/cls |

### 3.3 工厂方法模式

`from_dict`、`from_api_response` 都是**工厂方法**：把「从不同来源构造对象」的逻辑集中管理。

## 第四节：魔术方法（11:30 - 12:00）

| 方法 | 触发时机 | 用途 |
|------|----------|------|
| `__init__` | 创建对象 | 初始化属性 |
| `__str__` | `print(obj)` | 用户友好字符串 |
| `__repr__` | 交互式显示、调试 | 开发者友好，最好能 `eval` 重建 |
| `__eq__` | `obj1 == obj2` | 值相等判断 |
| `__len__` | `len(obj)` | MessageHistory 可用 |

```python
def __str__(self) -> str:
    return self.format_line()

def __repr__(self) -> str:
    return f"ChatMessage(role={self.role!r}, content=...)"

def __eq__(self, other) -> bool:
    if not isinstance(other, ChatMessage):
        return NotImplemented
    return self.role == other.role and self.content == other.content
```
