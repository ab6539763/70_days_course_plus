## 题目一：ChatMessage 核心方法

```python
class ChatMessage:
    VALID_ROLES = ("system", "user", "assistant")

    def __init__(self, role: str, content: str, *, created_at: str | None = None):
        self.role = (role or "").strip().lower()
        self.content = (content or "").strip()
        self.created_at = created_at or "2026-01-01T00:00:00Z"

    def validate(self) -> str | None:
        if self.role not in self.VALID_ROLES:
            return "角色非法"
        if not self.content:
            return "内容不能为空"
        return None

    def to_dict(self) -> dict:
        return {"role": self.role, "content": self.content, "created_at": self.created_at}
```

## 题目三：clear_non_system 参考实现

```python
def clear_non_system(self) -> int:
    before = len(self._messages)
    self._messages = [m for m in self._messages if m.is_system()]
    return before - len(self._messages)
```

## 加分题：merge 思路

```python
def merge(self, other: ChatMessage) -> list[ChatMessage]:
    if self.role == other.role:
        return [ChatMessage(self.role, self.content + "\n" + other.content)]
    return [self, other]
```
