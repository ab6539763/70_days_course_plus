# ZL-NA-REQ-008 扩展说明

## E1. models 目录规范

- 仅放**跨多日复用**的领域模型
- 文件名小写蛇形：`message.py`、`conversation.py`（未来）
- 每个 public 类必须有模块级 docstring

## E2. 序列化版本

本地 JSON 可增加顶层 `schema_version: "1.0"`（选修）。`load_json` 时根据版本迁移——Day 10 异常与迁移专题。

## E3. 角色扩展

部分 API 支持 `tool` / `function` 角色。NexusAgent v1.0 仅三种；Day 19 Function Calling 再扩展 VALID_ROLES。

## E4. 测试矩阵

| 用例 | 期望 |
|------|------|
| 合法 user 消息 | validate None |
| role=bot | validate 错误 |
| content 空格 | validate 错误 |
| to_dict 往返 | == |
| history 拒绝非法 | add 返回 err |

## E5. 性能

单会话消息 < 1000 条时 list 足够。超长上下文 Day 27 Memory 专题处理（截断、摘要）。
