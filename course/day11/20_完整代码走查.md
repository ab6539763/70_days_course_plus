## 二、read_text_file（L55-L87）

**流程**：

```
exists? → is_file? → read_bytes → for enc in encodings: decode → StorageError
```

**L69-L72**：区分「不存在」与「是目录」两种 StorageError 消息，便于日志检索。

**L77-82**：捕获 `UnicodeDecodeError` 继续循环，**不**捕获其他异常（如 MemoryError 应上浮）。

**L84-87**：`from last_error` 保留异常链。

## 四、iter_text_files（L97-L123）

**L122**：`glob_pattern = f"**/{pattern}" if recursive else pattern`

| recursive | pattern | 实际 glob |
|-----------|---------|-----------|
| False | `*.txt` | `*.txt` |
| True | `*.txt` | `**/*.txt` |

**L123**：`sorted(...)` 保证确定性。

## 五、mask_phone_numbers（L126-L137）

闭包 `_repl` 内 `nonlocal count` 计数。

**边界**：空字符串 → count=0；无匹配 → 原文不变。

## 六、read_document（L140-L174）

**顺序**：

1. `read_text_file` → content, encoding  
2. 构造 `DocumentRecord`，`size_bytes=path.stat().st_size`  
3. 若 `clean`：`clean_text` → 可选 `mask_phone_numbers` → 写 `record.cleaned` / `record.stats`  

**注意**：`mask_phone` 仅在 `clean=True` 分支生效（`if clean:` 块内）。

---

## 七、read_documents（L177-L202）

列表推导式风格 for 循环：

```python
for file_path in iter_text_files(...):
    records.append(read_document(...))
```

**无文件**时返回 `[]`，非异常。

## 八、write_cleaned_documents（L205-L233）

**L217**：`mkdir(parents=True, exist_ok=True)`  
**L221-L225**：`cleaned is None` → StorageError（业务校验）  
**L228**：写出 UTF-8  
**L229-L230**：OSError → StorageError  

返回 `written` 路径列表，供调用方日志。

## 九、batch_clean_directory（L236-L258）

三行组合：

```python
records = read_documents(..., clean=True, mask_phone=mask_phone)
write_cleaned_documents(records, output_dir)
return records
```

**默认** `mask_phone=True` — 企业批量清洗默认开启脱敏。
