# ZL-NA-REQ-011：文档批量读取工具

**版本**：v0.1.0  
**作者**：陈默 / 赵岩  
**状态**：已批准

## 1. 概述

在 `tools/` 包实现 `doc_reader.py`，支持目录批量读取 `.txt` 文档，可选调用 `utils.text_utils.clean_text` 清洗并写出。

## 2. 核心 API

| 函数/类 | 职责 |
|---------|------|
| `DocumentRecord` | 单文档读取结果（path, content, encoding, stats） |
| `read_text_file` | 单文件读取 + 编码回退 |
| `iter_text_files` | glob 遍历目录 |
| `read_documents` | 批量读取 |
| `batch_clean_directory` | 读→洗→写一条龙 |

## 3. 编码策略

默认尝试顺序：`utf-8` → `gbk` → `gb2312` → `latin-1`。全部失败抛 `StorageError`。

## 4. 清洗集成

- 调用 `utils.text_utils.clean_text`（非 day02 CLI）
- 可选 `mask_phone_numbers` 正则脱敏 `1\d{10}`

## 5. 路径注册

`core/paths.py` 新增：

- `sample_docs` → `day02/sample_docs`
- `doc_output` → `day11/output`

## 6. 异常

所有 IO 错误统一 `StorageError`，带 `path` 字段。

## 7. 测试

`tests/day11/test_doc_reader.py` ≥ 10 用例；全量 pytest 回归。
