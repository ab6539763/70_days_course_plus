## 四、glob 家庭作业（晚自习专项）

**任务 ZL-NA-051**：在 `src/day11/` 下新建脚本 `evening_glob.py`：

1. 遍历 `get_path("sample_docs")` 下所有 `.txt`  
2. 打印 `文件名 | 字节数 | 编码（用 read_text_file 检测）`  
3. 统计总字节数  

**验收**：运行无异常，至少 3 行输出。

```python
# 骨架（勿直接提交，需补全）
from core.paths import get_path
from tools.doc_reader import iter_text_files, read_text_file

def main():
    directory = get_path("sample_docs")
    total = 0
    for path in iter_text_files(directory):
        _, enc = read_text_file(path)
        size = path.stat().st_size
        total += size
        print(f"{path.name} | {size} | {enc}")
    print(f"合计: {total} bytes")

if __name__ == "__main__":
    main()
```
