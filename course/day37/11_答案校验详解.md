# 答案校验详解（Day 37 专题）

## 1. 校验时机

```
LLM 生成 reply → fetch citations → validate → 返回用户
```

## 2. 评分

- citation_coverage：引用被 reply 支撑的比例  
- support_score：reply token 与 citation 重叠度  
- strict 模式额外要求 coverage ≥ 50%

## 3. 拒答

`refuse_on_fail=true` → `[校验未通过]` + 安全话术

## 4. 与 route 正交

route 在检索前；validate 在 LLM 后。
