## 边界：空库

`chunks` 为空时 `search` 返回 `[]`；`_build_rag_service` 返回空 `RAGContextService`。

## 与 Elasticsearch 类比

ES `bool` query 的 `should` 组合 BM25 与 kNN；本实现用 Python 层融合两路 `RetrievalResult` 列表，教学更清晰。
