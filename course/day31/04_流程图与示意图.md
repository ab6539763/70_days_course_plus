# Day 31 流程图与示意图

## hybrid search 时序

```mermaid
sequenceDiagram
    participant U as Client
    participant H as HybridRetriever
    participant K as KeywordRetriever
    participant V as ChromaEmbeddingRetriever
    U->>H: search(q, top_k=3)
    H->>H: pool = max(12, 8)
    par 双路召回
        H->>K: search(q, top_k=pool)
        H->>V: search(q, top_k=pool)
    end
    K-->>H: kw_hits
    V-->>H: vec_hits
    H->>H: _rrf_merge or _weighted_merge
    H-->>U: top 3 RetrievalResult
```

## weighted 融合数据流

```mermaid
sequenceDiagram
    participant W as _weighted_merge
    participant N as _normalize_scores
    W->>N: kw_hits
    W->>N: vec_hits
    N-->>W: kw_norm, vec_norm
    W->>W: combined = kw_w*ks + vec_w*vs
    W->>W: sort by score desc
```

## ASCII：模式选择

```
query ──► mode?
            ├─ vector  ──► vector.search ──► return
            ├─ keyword ──► keyword.search ──► return
            └─ hybrid  ──► dual pool ──► fuse ──► top_k
```
