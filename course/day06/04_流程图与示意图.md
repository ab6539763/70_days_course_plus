# Day 6 流程图与示意图

## 1. 函数调用栈示意

```
main()
  └── show_menu()

        ├── validators.require_non_empty()
        ├── validators.parse_priority()
        ├── create_todo_dict()

  └── handle_save()
        └── json_utils.save_json()
```

## 2. 参数传递

```
位置参数:  func(a, b)       按顺序匹配
关键字参数: func(b=2, a=1)  按名称匹配
默认参数:  func(a, b=10)    b 可省略
*args:     func(1,2,3)      多余位置参数 → 元组
**kwargs:  func(x=1,y=2)     多余关键字参数 → 字典
```

## 3. 作用域 LEGB 规则

```
L Local      函数内部
E Enclosing  外层函数
G Global     模块全局
B Built-in   len/print 等
```
