## 练习 1：函数签名

写出下列函数的参数类型注解（Python 3.10+）：

```python
def merge_configs(base, override, *, strict=False):
    ...
```

**答案要点**：`base: dict`, `override: dict`, `strict: bool = False` → 返回 `dict`。

## 练习 2：作用域

```python
x = 1
def f():
    x = 2
    return x
print(f(), x)
```

输出？**2 1** — 函数内 `x=2` 是局部变量。

## 练习 3：默认参数陷阱

```python
def append_item(item, lst=[]):
    lst.append(item)
    return lst
```

调用 `append_item(1)` 两次返回什么？**[1] 和 [1,1]** — 默认列表只创建一次。
