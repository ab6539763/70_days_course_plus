# ZL-NA-REQ-006：utils 工具库与函数化重构

**版本**：v0.1.0  
**作者**：陈默 / 赵岩  
**状态**：已批准

## 1. 概述

建立 `src/utils/` 公共工具包，将 Day 1-5 重复逻辑函数化，并交付基于 utils 的 `todo_manager_v3.py`。

## 2. utils 模块规格

### 2.1 text_utils.py（来自 Day 2）

| 函数 | 签名 | 说明 |
|------|------|------|
| collapse_whitespace | `(text: str) -> str` | 合并空白 |
| collapse_duplicate_punctuation | `(text: str) -> str` | 合并标点 |
| mask_sensitive_words | `(text, words) -> tuple[str,int]` | 敏感词替换 |
| clean_text | `(raw, *, to_lower=False) -> tuple[str, dict]` | 主管道 |

### 2.2 json_utils.py（来自 Day 5）

| 函数 | 说明 |
|------|------|
| load_json(path, default=None) | 安全加载，失败返回 default |
| save_json(path, data) | 美化写入 UTF-8 |
| ensure_dict(data, keys) | 补全缺失键 |

### 2.3 validators.py

| 函数 | 说明 |
|------|------|
| require_non_empty(value, field_name) | 非空校验 |
| parse_priority(s, default=2) | 解析 1/2/3 |
| parse_positive_int(s) | 正整数或 None |

### 2.4 formatters.py

| 函数 | 说明 |
|------|------|
| format_box_report(title, lines) | ASCII 边框报告 |
| format_todo_line(todo) | 单条待办格式化 |

## 3. todo_manager_v3

- 业务逻辑保留在 day06
- 所有 IO、校验、格式化调用 utils
- 数据仍用 `day05/data/todos.json`

## 4. 测试

- `tests/test_utils.py` 覆盖 utils 各函数
- `tests/day06/test_todo_manager_v3.py` 集成测试
