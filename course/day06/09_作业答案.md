### 1. 定义函数 `celsius_to_fahrenheit(c)`

```python
def celsius_to_fahrenheit(c: float) -> float:
    """摄氏转华氏"""
    return c * 9 / 5 + 32

# 测试
assert abs(celsius_to_fahrenheit(0) - 32) < 0.01
assert abs(celsius_to_fahrenheit(100) - 212) < 0.01
```

def repeat_char(s: str, n: int) -> str:

### 7. `merge_dicts(base, override)`

```python
def merge_dicts(base: dict, override: dict) -> dict:
    result = dict(base)
    result.update(override)
    return result
```

注意：返回新 dict，不修改 `base`（纯函数风格）。

### 10. 手写 `format_stats_line(total, done)`

```python
def format_stats_line(total: int, done: int) -> str:
    pending = total - done
    pct = (done / total * 100) if total else 0.0
    return f"总计 {total}，已完成 {done}，待办 {pending}，完成率 {pct:.1f}%"
```

可并入 `formatters.py` 供 v3 的 `handle_stats` 调用（扩展练习）。

### 11. 实现 `safe_div(a, b) -> float | None`

```python
def safe_div(a: float, b: float) -> float | None:
    if b == 0:
        return None
    return a / b
```
