# Day 6 常见问题与排错指南

## Q1：`ModuleNotFoundError: No module named 'utils'`

**原因**：Python 找不到 `src/utils`。

**解决**：

```bash
cd nexus-agent-platform
export PYTHONPATH=src
python3 src/day06/todo_manager_v3.py
```

或确认脚本开头有 `sys.path.insert(0, str(_SRC_ROOT))`。

## Q2：v3 读不到 Day 5 的待办

**检查**：`day05/data/todos.json` 是否存在；`day06/constants.py` 中 `TODOS_FILE_REL` 是否指向 `day05/data/todos.json`。

## Q3：`parse_priority` 总返回 2

用户输入必须是 `"1"`、`"2"`、`"3"` 字符串；空回车使用默认 2（中等优先级）。

## Q4：pytest 报 `constants` 模块冲突

与 Day 3 相同，用 `importlib` 加载 day 模块，见 `tests/day06/test_todo_manager_v3.py`。

## Q5：lambda 里不能赋值？

```python
# 错误
sorted(todos, key=lambda t: t["priority"]=1)

# 正确：key 只能是表达式
sorted(todos, key=lambda t: t.get("priority", 2))
```

## Q6：递归 RecursionError

阶乘 `n` 过大或忘记 base case。练习时 `n` 控制在 1000 以内；生产用循环更稳妥。

## Q7：`ensure_dict_keys` 不递归嵌套

只补顶层键；嵌套 `todos` 内每条 dict 的结构由 `create_todo` 保证。

## Q8：修改 utils 后 v2 行为变了吗？

不会。Day 5 文件未改；仅 v3 使用 utils。若需统一，Day 10 再做全量迁移。

## Q9：`format_box_report` 中文对齐不齐？

ASCII 边框不计算全角宽度；企业终端足够。Web UI 用 CSS。

## Q10：作业 `repeat_char` 放哪？

练习可放 `day06/homework.py`；若确认复用再 PR 进 `text_utils`。
