## E3. 错误处理约定

| 场景 | utils 行为 | 调用方行为 |
|------|------------|------------|
| JSON 文件不存在 | `load_json` 返回 default | 使用 empty_store |
| JSON 损坏 | 返回 default | 打印警告（可选） |
| 标题为空 | `require_non_empty` 返回 str | print 并 return |
| 非法优先级 | `parse_priority` 返回 default=2 | 静默使用中等优先级 |
