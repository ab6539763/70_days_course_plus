## 第六节：作用域 LEGB（14:00 - 14:40）

Python 查找变量名的顺序：

1. **L**ocal — 当前函数内部
2. **E**nclosing — 外层嵌套函数
3. **G**lobal — 模块顶层
4. **B**uilt-in — `len`, `print` 等

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)  # local — 赋值创建了新的局部变量
    inner()

outer()
print(x)  # global — 未被 inner 修改
```

### global 与 nonlocal

```python
count = 0

def increment() -> None:
    global count
    count += 1

def make_counter():
    n = 0
    def inner():
        nonlocal n
        n += 1
        return n
    return inner
```

**企业建议**：

- 尽量少用 `global`，状态通过参数和返回值传递。
- CLI 的 `main()` 里用局部 `store` dict 管理待办，比全局列表更清晰。
- Day 39 Agent 的状态机会用显式 `state` dict，而非散落的全局变量。

## 第七节：lambda 匿名函数（14:40 - 15:20）

```python
# 具名函数 — 推荐用于复杂逻辑
def double(x: int) -> int:
    return x * 2

# lambda — 适合一行、只用一次的简单表达式
double = lambda x: x * 2

# 常用于 sorted 的 key
todos = [{"id": 1, "priority": 3, "done": False}, {"id": 2, "priority": 1, "done": True}]
sorted_todos = sorted(todos, key=lambda t: (t["done"], t["priority"]))
```

`todo_manager_v3.display_todos` 在按优先级排序时：

```python
items = sorted(todos, key=lambda t: t.get("priority", 2))
```

### map / filter

```python
nums = [1, 2, 3, 4, 5]
squares = list(map(lambda x: x**2, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))
```

Python 3 中更常见**列表推导**：

```python
squares = [x**2 for x in nums]
evens = [x for x in nums if x % 2 == 0]
```

lambda 适合传给 `sorted`、`map` 等接受回调的高阶函数；多行逻辑请用 `def`。

## 第八节：递归入门（15:20 - 15:50）

```python
def factorial(n: int) -> int:
    """n! 递归定义"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

```python
def sum_list(nums: list[int]) -> int:
    if not nums:
        return 0
    return nums[0] + sum_list(nums[1:])
```

**三要素**：

1. **基准情况**（base case）— 不再递归
2. **递归情况** — 问题规模缩小
3. **终止保证** — 否则 `RecursionError: maximum recursion depth exceeded`

Agent 主循环更像 `while`：思考 → 行动 → 观察，直到任务完成；但目录树遍历、分块合并等场景会用到递归。

运行 `function_demos.py` 可看到阶乘与作用域演示。

### 9.1 json_utils 抽取

Day 5 的 `todo_storage.py` 读写逻辑泛化为：

```python
def load_json(path: Path, default: Any = None) -> Any:
    if not path.exists():
        return default
    try:
        with path.open("r", encoding="utf-8") as f:
            return json.load(f)
    except json.JSONDecodeError:
        return default

def save_json(path: Path, data: Any, *, indent: int = 2) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=indent)
```

`ensure_dict_keys` 保证旧版 JSON 缺字段时自动补全 `next_id`、`todos` 等。
