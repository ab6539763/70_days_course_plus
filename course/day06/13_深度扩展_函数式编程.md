# Day 6 深度扩展：函数式编程初探

## map / filter / reduce

```python
nums = [1, 2, 3, 4]
squares = list(map(lambda x: x * x, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))
```

reduce（需 `from functools import reduce`）：

```python
from functools import reduce
total = reduce(lambda a, b: a + b, nums, 0)
```

## 纯函数

**纯函数**：相同输入永远相同输出，无副作用。`clean_text(s)` 是纯的；`add_todo` 写文件不是纯的。

测试策略：纯函数单元测试简单；有副作用的函数用临时目录 mock。

## 高阶函数

接受函数作为参数的函数叫**高阶函数**。`sorted(..., key=...)` 是标准库高阶函数。

## 装饰器预告（Day 8+）

```python
def log_calls(fn):
    def wrapper(*args, **kwargs):
        print(f"calling {fn.__name__}")
        return fn(*args, **kwargs)
    return wrapper
```

灵犀 API 层的 `@app.get` 本质是装饰器注册路由。

## 企业实践

- 工具函数保持**短小、可测、无隐藏 IO**（除非模块名就叫 `json_utils` 且文档写明 IO）。
- 业务模块编排 IO + 领域规则。
- 避免「上帝函数」超过 50 行不拆分。
