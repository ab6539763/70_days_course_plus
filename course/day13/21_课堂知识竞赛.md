## 第二轮：代码找茬（每题 10 分 × 3）

### 题 A

```python
@with_timeout(30)
@retry(max_attempts=3)
def f(): pass
```

错在哪？

<details><summary>答案</summary>装饰顺序反了；应 retry 在外。</details>

### 题 B

```python
def retry_bad(func):
    def wrapper(*a, **k):
        return func(*a, **k)
    return wrapper
```

演示时 `help(greet)` 显示什么异常？

<details><summary>答案</summary>__name__ 为 wrapper，文档是 wrapper 的（通常 None）。</details>

### 题 C

```python
@retry(max_attempts=3)
def always_401():
    raise APIError("x", status_code=401)
```

`always_401` 内部 raise 几次？

<details><summary>答案</summary>1 次，401 不可重试。</details>

## 第三轮：白板推演（20 分）

画出 `max_attempts=3`、`base_delay=1`、`backoff_factor=2` 下，连续 3 次 503 最后失败的时间线（标注每次 sleep）。

<details><summary>答案要点</summary>
t0 试1 fail → sleep 1s → t1 试2 fail → sleep 2s → t2 试3 fail → 抛异常
</details>

## 第四轮：情景题（20 分）

赵岩说：「用户 Key 过期返回 401，希望自动重试 3 次。」  
作为工程师你如何回应？写出技术理由（不少于 3 点）。

<details><summary>参考</summary>
1. 401 永久性认证失败，重试不改变结果  
2. 浪费 API 配额与延迟  
3. 可能触发风控；应提示用户更新 Key  
4. is_retryable_error 明确排除 401
</details>
