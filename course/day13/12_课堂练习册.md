## 练习 1：装饰器填空（基础）

补全无参装饰器：

```python
import functools

def trace(func):
    @functools.____(func)
    def wrapper(*args, **kwargs):
        print("enter", func.__name__)
        result = func(*args, **kwargs)
        print("leave", func.__name__)
        return result
    return wrapper
```

<details><summary>答案</summary>wraps</details>

## 练习 2：执行顺序（基础）

```python
def deco_a(func):
    print("A factory")
    def wrapper(*a, **k):
        print("A call")
        return func(*a, **k)
    return wrapper

def deco_b(func):
    print("B factory")
    def wrapper(*a, **k):
        print("B call")
        return func(*a, **k)
    return wrapper

@deco_a
@deco_b
def foo():
    print("foo body")
```

问：定义 `foo` 时打印顺序？调用 `foo()` 时打印顺序？

<details><summary>答案</summary>
定义：B factory → A factory  
调用：A call → B call → foo body
</details>

## 练习 5：代码改错（中等）

学员提交：

```python
@with_timeout(30)
@retry(max_attempts=3)
def call_api():
    ...
```

陈默说顺序反了。应如何写？为什么？

<details><summary>答案</summary>

```python
@retry(max_attempts=3)
@with_timeout(30)
def call_api():
    ...
```

retry 在外，每次 attempt 重新进入 timeout 包装。
</details>

## 练习 6：阅读 resilient_client（进阶）

`_build_resilient_complete` 为何用 `super(ResilientLLMClient, self)` 而非 `super().complete`？

<details><summary>答案</summary>闭包内 `super()` 无参形式在嵌套函数中绑定易混淆；显式类+实例更安全。</details>

## 练习 7：设计题（进阶）

产品要求：**仅重试 503，不重试 429**。如何配置现有 `retry`？

<details><summary>参考答案</summary>

```python
def only_503(exc):
    return isinstance(exc, APIError) and exc.status_code == 503

@retry(max_attempts=3, retryable=only_503)
def f(): ...
```

</details>
