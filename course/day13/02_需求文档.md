**版本**：v0.1.0  
**作者**：陈默 / 周航

## 1. 概述

在 `llm/retry.py` 实现通用重试与超时装饰器，在 `llm/resilient_client.py` 为 `LLMClient.complete` 应用 `RetryPolicy`，处理 429 限流与 5xx 瞬时故障。配置错误与客户端 4xx（除 429）**立即失败**，不浪费重试配额。

| `llm/retry.py` | `retry`、`with_timeout`、`RetryPolicy`、`is_retryable_error`、`api_retry`、`apply_resilience` |

## 3. RetryPolicy 默认值

| 字段 | 默认 | 说明 |
|------|------|------|
| `max_attempts` | 3 | 含首次，共最多 3 次调用 |
| `base_delay` | 1.0 | 首次重试前等待（秒） |
| `backoff_factor` | 2.0 | 指数退避倍数 |
| `max_delay` | 30.0 | 单次 sleep 上限 |
| `timeout_seconds` | 60.0 | 单次 complete 超时 |

## 4. 可重试异常矩阵

| 异常 / 状态码 | 重试？ |
|---------------|--------|
| `ConfigError` | ❌ |
| `ModelValidationError` | ❌ |
| `APIError` + 401 / 403 / 404 等 4xx（除 429） | ❌ |
| `APIError` + 429 | ✅ |
| `APIError` + 500 / 502 / 503 / 504 | ✅ |
| `APIError` + `status_code=None`（网络层） | ✅ |

## 5. 核心 API

### 5.1 retry（装饰器工厂）

```python
def retry(
    max_attempts: int = 3,
    *,
    base_delay: float = 1.0,
    backoff_factor: float = 2.0,
    max_delay: float = 30.0,
    retryable: Callable[[BaseException], bool] | None = None,
    on_retry: Callable[[int, BaseException, float], None] | None = None,
) -> Callable[[Callable[P, R]], Callable[P, R]]
```

- 使用 `functools.wraps` 保留元数据  
- `on_retry(attempt, exc, sleep_for)` 可选回调  
- 不可重试或已达 `max_attempts` 时 **re-raise 原异常**

### 5.2 with_timeout

```python
def with_timeout(seconds: float) -> Callable[[Callable[P, R]], Callable[P, R]]
```

- `ThreadPoolExecutor(max_workers=1)` + `future.result(timeout=seconds)`  
- 超时抛 `APIError(f"调用超时（>{seconds}s）")`

### 5.3 ResilientLLMClient

```python
class ResilientLLMClient(LLMClient):
    def __init__(self, config=None, *, policy=None, on_retry_log=False, ...)
    def complete(self, messages: list[ChatMessage]) -> ChatCompletionResult
```

装饰器组合（由内到外）：

```
retry( api_retry ) → with_timeout → super().complete
```
