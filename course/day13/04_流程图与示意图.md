# Day 13 流程图与示意图

## 1. retry 装饰器执行流程

```mermaid
flowchart TD
    START([进入 wrapper]) --> LOOP{attempt <= max_attempts?}
    LOOP -->|是| TRY[执行 func]
    TRY -->|成功| RETURN([返回结果])
    TRY -->|异常 exc| CHECK{retryable exc?}
    CHECK -->|否| RAISE1([立即 raise exc])
    CHECK -->|是| LAST{attempt >= max_attempts?}
    LAST -->|是| RAISE2([raise exc])
    LAST -->|否| SLEEP[sleep min delay, max_delay]
    SLEEP --> CB{on_retry?}
    CB -->|有| LOG[回调 attempt, exc, sleep]
    CB -->|无| INC
    LOG --> INC[delay *= backoff_factor]
    INC --> NEXT[attempt += 1]
    NEXT --> LOOP
    LOOP -->|否| RAISE3([raise last_exc])
```

## 2. is_retryable_error 判定树

```
exc 类型？
├─ ConfigError / ModelValidationError → False
├─ APIError
│   ├─ status_code is None → True（网络层）
│   ├─ code in {429,500,502,503,504} → True
│   └─ 其他（含 401, 403, 404）→ False
└─ 其他 BaseException → False
```

## 3. with_timeout 线程模型

```mermaid
sequenceDiagram
    participant Main as 主线程
    participant Pool as ThreadPoolExecutor
    participant Worker as 工作线程
    participant Func as func()

    Main->>Pool: submit(func, args)
    Pool->>Worker: 执行
    alt 在 timeout 内完成
        Worker-->>Main: result
    else TimeoutError
        Main->>Main: raise APIError 调用超时
    end
```

**注意**：`urllib` 阻塞在工作线程；主线程 `future.result(timeout)` 超时后，工作线程可能仍在运行直到 HTTP 完成（MVP 限制，Day 16 异步改进）。

## 4. 指数退避时间线（默认策略）

```

t=3s    sleep 2.0
t=3s    第3次调用 ──成功──► 返回
```
