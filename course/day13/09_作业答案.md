## 作业一：概念题

### 1. 语法糖等价

`@decorator` 等价于：`func = decorator(func)`。  
若带参：`@retry(3)` 等价于 `func = retry(3)(func)`。

### 2. functools.wraps

将 `wrapper` 的 `__name__`、`__doc__`、`__module__` 等复制自被装饰函数。  
不用时 `greet.__name__` 通常为 `"wrapper"`，调试栈与 `help()` 失真。

### 3. 状态码

| 码 | 含义 |
|----|------|
| 429 | Too Many Requests，限流，稍后重试 |
| 500 | Internal Server Error，服务端内部错误 |
| 502 | Bad Gateway，网关上游无效响应 |
| 503 | Service Unavailable，服务暂时不可用 |
| 504 | Gateway Timeout，网关等待上游超时 |

### 4. 不重试原因

- **ConfigError**：本地配置缺失（如 Key），重试不会改变结果，只会刷屏日志  
- **401**：认证失败，重试不会 magically 修好 Key，且可能触发安全审计

### 5. 调用顺序

```
用户调用 complete
  → retry.wrapper (attempt 循环)
    → with_timeout.wrapper
      → super().complete() / HTTP
```

## 作业二：代码阅读

### 1. delay 变化

初始 `delay = base_delay`。每次可重试失败后 `sleep min(delay, max_delay)`，然后 `delay *= backoff_factor`。  
第 k 次 sleep（k 从 1 起）：`min(base_delay * backoff_factor^(k-1), max_delay)`。

### 2. 超时异常

`APIError(f"调用超时（>{seconds}s）")`，由 `TimeoutError` chain。

### 3. api_retry

预设 `retryable=is_retryable_error`，参数来自 `RetryPolicy` 或 kwargs；省去手动传 `retryable`。

### 4. apply_resilience

先 `with_timeout`，再 `api_retry`（retry 在外）。保证每次重试重新计时。

### 5. status_code=None

返回 `True`。表示网络层等无 HTTP 码的错误，视为瞬时故障。

## 作业三：参考实现

```python
"""homework/day13/my_retry_demo.py"""
from __future__ import annotations

import sys
from pathlib import Path

_ROOT = Path(__file__).resolve().parents[2] / "nexus-agent-platform" / "src"
sys.path.insert(0, str(_ROOT))

from core.exceptions import APIError
from llm.retry import retry

def main() -> None:
    state = {"n": 0}

    @retry(max_attempts=5, base_delay=0.01, backoff_factor=2)
    def unstable_fetch() -> str:
        state["n"] += 1
        print(f"  attempt #{state['n']}")
        if state["n"] < 3:
            raise APIError("busy", status_code=503)
        return "ok"

    print("503 case:", unstable_fetch())

    auth_calls = {"n": 0}

    @retry(max_attempts=5, base_delay=0.01)
    def auth_fail() -> None:
        auth_calls["n"] += 1
        raise APIError("unauthorized", status_code=401)

    try:
        auth_fail()
    except APIError:
        print(f"401 case: calls={auth_calls['n']}")  # 应为 1

if __name__ == "__main__":
    main()
```

## 作业四：实验

### 2. fail_times=5, max_attempts=4

transport 至少调用 4 次均 503，第 4 次后 `retry` 用尽，向调用方抛 `APIError 503`，无成功回复。

### 3. on_retry_log=False

无 `⏳ 重试` 行，仅 `transport 调用 #N` 与最终异常或成功。

### 4. 继承关系

`ResilientLLMClient(LLMClient)`：复用构造、transport、解析。  
`complete` 被替换为调用预构建的 `_complete_resilient`（带 retry+timeout），而非直接 `super().complete`。

## 加分项参考

```python
import functools
from llm.retry import retry

def log_call(func):
    @functools.wraps(func)
    def wrapper(*a, **k):
        print("call", func.__name__)
        return func(*a, **k)
    return wrapper

@retry(max_attempts=2, base_delay=0.01)
@log_call
def timed_greet():
    """问候函数"""
    return "hi"
```

`timed_greet.__doc__` 应为 `问候函数`（`log_call` 贴近函数，外层 `retry` 也会 wraps）。
