## 09:30 装饰器本质

函数是一等公民 → 函数可作参数、返回值。

```python
def log_call(func):
    @functools.wraps(func)  # 保留 __name__, __doc__
    def wrapper(*args, **kwargs):
        print(f"→ 调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def greet(name): ...
```

等价于：`greet = log_call(greet)`。

**三层结构**（板书）：

1. 外层：接收**装饰器参数**（若有）  
2. 中层：`decorator(func)` 接收被装饰函数  
3. 内层：`wrapper` 真正执行逻辑

运行 `decorator_demos.py` 验证 `greet.__name__ == "greet"`。

## 10:15 装饰器工厂 `@repeat(3)`

```python
def repeat(times):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            ...
        return wrapper
    return decorator
```

调用链：`repeat(3)(count)` → 先 `repeat(3)` 返回 `decorator`，再 `@decorator` 装饰 `count`。

## 10:45 retry 源码走读

核心循环（`llm/retry.py`）：

```python
for attempt in range(1, max_attempts + 1):
    try:
        return func(*args, **kwargs)
    except BaseException as exc:
        if attempt >= max_attempts or not predicate(exc):
            raise
        sleep_for = min(delay, max_delay)
        ...
        time.sleep(sleep_for)
        delay *= backoff_factor
```

**讨论**：为何捕获 `BaseException` 而非仅 `Exception`？

> 课程选择宽捕获以便 `APIError` 传播；`KeyboardInterrupt` 理论上也会进入——生产可加 `except Exception`。

## 11:30 is_retryable_error

```python
DEFAULT_RETRYABLE_STATUS = frozenset({429, 500, 502, 503, 504})
```

- `ConfigError` → False（缺 Key 重试无意义）  
- `APIError` + `status_code=None` → True（`URLError` 转来的网络错误）  
- 401 Unauthorized → False

**课堂练习**：503 应返回 True 还是 False？（全班：True）
