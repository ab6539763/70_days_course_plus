# Day 5 知识点深度扩展

## 第一章：JSON 为何成为 API 标准

- 轻量、人类可读
- JavaScript 原生支持，Web 时代产物
- Python `json` 标准库成熟
- OpenAI 格式成为事实标准，DeepSeek/Qwen 兼容

## 第二章：dict 性能直觉

- 按键查找平均 O(1)
- list 按 id 查找 O(n)
- 待办 <1000 条差异不大；百万用户配置用 dict/数据库

## 第三章：常见 API 响应字段

| 字段 | 含义 |
|------|------|
| id | 请求唯一标识 |
| model | 使用的模型 |
| choices | 生成结果数组 |
| message.content | 助手回复文本 |
| usage.total_tokens | 计费依据 |
| finish_reason | stop/length/tool_calls |
