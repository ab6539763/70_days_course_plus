## 1. 子需求 A：待办 JSON 持久化（ZL-NA-020）

### 数据格式（list of dict）

```json
{
  "version": "1.0",
  "next_id": 4,
  "todos": [
    {
      "id": 1,
      "title": "完成文本清洗",
      "description": "Day 2",
      "priority": 1,
      "done": true,
      "created_at": "2026-07-10T09:00:00"
    }
  ]
}
```

### 功能

- 启动时 `json.load` 读取 `data/todos.json`
- 文件不存在则初始化空数据
- 退出菜单 0 时 `json.dump` 保存
- 每次增删改后可选自动保存
