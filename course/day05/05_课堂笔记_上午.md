## 第一节：dict 基础（9:00 - 9:40）

### 1.1 创建字典

```python
# 字面量
user = {"name": "张三", "age": 25, "role": "developer"}

# dict 构造
user = dict(name="张三", age=25)
user = dict([("name", "张三"), ("age", 25)])

# 空字典
config = {}
```

### 1.2 访问与修改

```python
user = {"name": "张三", "age": 25}

print(user["name"])      # 张三
print(user.get("email")) # None（键不存在不报错）
print(user.get("email", "无"))  # 默认值

user["age"] = 26         # 修改
user["email"] = "a@b.c"  # 新增
```

**`[]` vs `get`**：

- `user["key"]` 键不存在 → `KeyError`
- `user.get("key")` 键不存在 → `None`

企业代码优先用 `get`，除非键必须存在。

### 1.3 删除

```python
del user["email"]
email = user.pop("email", None)  # 弹出并返回值
user.clear()
```

## 第二节：嵌套 dict（9:40 - 10:20）

### 2.1 API 响应结构

```python
response = {
    "id": "chatcmpl-abc",
    "model": "deepseek-chat",
    "choices": [
        {
            "index": 0,
            "message": {
                "role": "assistant",
                "content": "你好！"
            },
            "finish_reason": "stop"
        }
    ],
    "usage": {
        "prompt_tokens": 10,
        "completion_tokens": 5,
        "total_tokens": 15
    }
}
```

### 2.2 安全访问嵌套

```python
# 链式访问（任何一层不存在会 KeyError）
content = response["choices"][0]["message"]["content"]

# 安全写法
choices = response.get("choices", [])
if choices:
    content = choices[0].get("message", {}).get("content", "")
```

**`{}` 默认 dict**：`response.get("message", {})` 确保 `.get` 链不中断。

## 第三节：遍历 dict（10:20 - 11:00）

```python
user = {"name": "张三", "age": 25, "role": "dev"}

# 遍历键
for key in user:
    print(key, user[key])

# 遍历键值对
for key, value in user.items():
    print(f"{key}: {value}")

# 只要键 / 只要值
for k in user.keys():
    ...
for v in user.values():
    ...
```

### 3.1 待办 dict 遍历

todos = [

for todo in todos:

## 第四节：dict 方法与合并（11:00 - 11:40）

| 方法 | 作用 |
|------|------|
| keys() | 所有键 |
| values() | 所有值 |
| items() | 键值对 |
| update(other) | 合并 |
| setdefault(k, v) | 键不存在则设置 |

```python
defaults = {"temperature": 0.7, "max_tokens": 1024}
user_params = {"temperature": 0.9}
defaults.update(user_params)  # temperature 被覆盖
```

### 4.1 字典推导式

pending = {t["id"]: t["title"] for t in todos if not t["done"]}

## 第五节：list vs dict 选型（11:40 - 12:00）

| 场景 | 选型 |
|------|------|
| 有序列表、按索引 | list |
| 按名称/ID 快速查找 | dict |
| JSON 序列化 | 两者皆可，dict 可读性好 |
| 待办记录 | Day 4 list → Day 5 dict |

```python
# Day 4
[1, "标题", "描述", 1, False]

# Day 5（更清晰）
{"id": 1, "title": "标题", "description": "描述", "priority": 1, "done": False}
```

## 附录：嵌套访问模式大全

```python
# 模式 1：直接（快但不安全）
x = data["a"]["b"]["c"]

# 模式 2：get 链（推荐）
x = data.get("a", {}).get("b", {}).get("c", default)

# 模式 3：try/except（键必须存在时）
try:
    x = data["a"]["b"]["c"]
except KeyError:
    x = default

# 模式 4：walrus + 分步（复杂逻辑）
if (choices := data.get("choices")) and len(choices) > 0:
    msg = choices[0].get("message", {})
```
