# ZL-NA-REQ-005 扩展：API 响应解析器字段规范

## 1. Chat Completion 响应

### 必提取字段

| 字段路径 | 类型 | 说明 |
|----------|------|------|
| model | string | 模型名称 |
| choices[0].message.content | string | 助手回复 |
| choices[0].message.role | string | 通常 assistant |
| choices[0].finish_reason | string | stop/length/tool_calls |
| usage.prompt_tokens | int | 输入 token |
| usage.completion_tokens | int | 输出 token |
| usage.total_tokens | int | 合计 |

### 可选字段

| 字段 | 说明 |
|------|------|
| id | 请求 ID，日志用 |
| created | Unix 时间戳 |
| system_fingerprint | 系统指纹 |

## 2. Error 响应

| 字段路径 | 说明 |
|----------|------|
| error.message | 人类可读错误 |
| error.type | 错误类型 |
| error.code | 机器可读码 |

## 3. Stream Chunk 响应

| 字段路径 | 说明 |
|----------|------|
| choices[0].delta.content | 增量文本 |
| choices[0].finish_reason | 结束时为 stop |

## 4. 解析器输出统一格式

成功：

```python
{
  "type": "chat.completion",
  "model": "...",
  "content": "...",
  "total_tokens": 184,
  ...
}
```

错误：

```python
{
  "type": "error",
  "message": "...",
  "code": "...",
}
```

## 5. 边界情况

| 情况 | 处理 |
|------|------|
| choices 为空 | content 空字符串 |
| usage 缺失 | token 记 0 |
| content 为 null | 转为 "" |
| 非法 JSON 文件 | 退出码 1，打印错误 |
