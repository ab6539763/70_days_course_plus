## 题目二：嵌套安全访问

```python
def safe_get_email(response: dict) -> str:
    """
    三层嵌套安全提取 email
    任一层缺失返回 N/A
    """
    data = response.get("data")
    if not isinstance(data, dict):
        return "N/A"
    user = data.get("user")
    if not isinstance(user, dict):
        return "N/A"
    return user.get("email", "N/A")


# 测试
resp1 = {"data": {"user": {"email": "a@b.c"}}}
resp2 = {"data": {}}
print(safe_get_email(resp1))  # a@b.c
print(safe_get_email(resp2))  # N/A
```

## 题目五详解

### 1. dict vs JSON object

dict 是 Python 运行时类型；JSON 是文本序列化格式。dict 键可以是任意不可变类型（通常 str）；JSON 键必须是字符串。

### 2. 为何 API 用 JSON

REST 时代 HTTP+JSON 成为标准；比 XML 简洁；与 JavaScript 生态一致；OpenAI 引领 LLM API 格式。

### 3. list of list → list of dict

| 维度 | list of list | list of dict |
|------|--------------|--------------|
| 可读性 | 需记住索引 | 字段有名 |
| 扩展 | 加字段破坏索引 | 加键即可 |
| JSON | 可以 | 更自然 |
| 调试 | 难 | 易 |

## 加分题：合并 todos

```python
import json

def merge_todo_files(path_a, path_b, out_path):
    with open(path_a) as f:
        a = json.load(f)
    with open(path_b) as f:
        b = json.load(f)
    seen = {t["id"] for t in a["todos"]}
    for t in b["todos"]:
        if t["id"] not in seen:
            a["todos"].append(t)
            seen.add(t["id"])
    a["next_id"] = max(seen) + 1
    with open(out_path, "w", encoding="utf-8") as f:
        json.dump(a, f, ensure_ascii=False, indent=2)
```
