## 上午第一节：从 Day 4 的 list 到 dict

赵岩：

> 「昨天你们的待办是 `[1, "标题", "描述", 1, False]`。我问你：索引 3 是什么？你得背下来。今天改成 `{"id": 1, "title": "标题", "priority": 1, "done": false}`，代码即文档。」

黑板写下：

```python
# Day 4
todo[1]   # 标题？描述？容易忘

# Day 5
todo["title"]  # 一目了然
```

学员问：那还用 list 吗？

> 「用。`todos` 整体仍是 list，存很多个 dict。这叫 **list of dict**，是 API 和数据库最常见的模式。」

## 上午第二节：嵌套 dict 现场调试

周航投屏一段真实 API 响应，故意删掉 `choices` 字段：

```python
response = {"model": "deepseek-chat"}
content = response["choices"][0]["message"]["content"]
```

全班看着 Traceback：


周航：

> 「这就是不设防的代码。上线后 API 抽风、限流、返回错误体，你的 Agent 就崩了。正确姿势：`response.get("choices", [])`，先判断再取。」

## 下午第一节：JSON 不是 Python

林薇：

> 「JSON 看起来像 Python dict，但它是**字符串协议**。你不能把 JSON 文件当 Python 执行。不能写注释。不能用单引号。」

展示常见作业错误：

```python
# 学生提交的配置文件 config.json
{
    'name': 'test',  # 项目名称
}
```

> 「三处错误：单引号、注释、尾随。用 jsonlint 或 VS Code JSON 插件检查。」

---

## 下午第二节：四种 json 方法怎么记

赵岩口诀：

> 「**loads**：Load String，字符串进来。  
> **dumps**：Dump String，字符串出去。  
> **load**：Load file，文件进来。  
> **dump**：Dump file，文件出去。  
> 带 s 的跟字符串玩，不带 s 的跟文件玩。」

全场跟念三遍。

## 下午第三节：api_response_parser 现场编码

周航从零写 `parse_chat_completion`，故意每一步都 `.get()`：

```python
usage = response.get("usage") or {}
total = usage.get("total_tokens", 0)
```

解释：

> 「`usage` 有时是 null，`.get("usage", {})` 不够，因为 null 不是缺失。用 `or {}` 更稳。」

学员问 token 有什么用？

> 「Day 15 算钱。1M token 输入 1 元，你一次请求 184 token 看似很少，日活 10 万次就可观了。所以 usage 字段必须解析。」

## 答疑精选

**问**：dict 键的顺序重要吗？  
**答**：Python 3.7+ dict 保持插入顺序。JSON 对象理论上无序，实际按 dumps 顺序。

**问**：能否用 YAML 代替 JSON？  
**答**：配置文件可以；API 几乎全是 JSON。YAML 人类友好，JSON 机器友好。

**问**：`json.dump` 要 `with open` 吗？  
**答**：强烈推荐。`with` 自动关闭文件，防止数据未写完。

**问**：todos 存文件还是数据库？  
**答**：MVP 用文件；用户多了用 SQLite（Day 24）；企业用 PostgreSQL。
