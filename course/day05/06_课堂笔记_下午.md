## 第六节：JSON 格式（14:00 - 14:40）

### 6.1 什么是 JSON

**J**ava**S**cript **O**bject **N**otation，轻量级数据交换格式。大模型 API 的请求和响应几乎都是 JSON。

```json
{
  "name": "NexusAgent",
  "version": 0.5,
  "features": ["RAG", "Agent"],
  "enabled": true,
  "meta": null
}
```

### 6.2 语法规则

- 键必须用**双引号**
- 不能有尾随逗号
- 不支持注释
- 字符串用双引号

```python
# 非法 JSON
# {'name': 'x'}     单引号
# {"a": 1,}         尾随逗号
```

## 第七节：json 模块四种方法（14:40 - 15:30）

```python
import json
```

### 7.1 loads / dumps（字符串）

```python
# Python → JSON 字符串
data = {"name": "张三", "scores": [90, 85]}
json_str = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str)
# {
#   "name": "张三",
#   "scores": [90, 85]
# }

# JSON 字符串 → Python
parsed = json.loads(json_str)
print(parsed["name"])  # 张三
```

**参数**：

| 参数 | 作用 |
|------|------|
| ensure_ascii=False | 中文不转 \uXXXX |
| indent=2 | 美化缩进 |
| sort_keys=True | 键排序 |

### 7.2 load / dump（文件）

```python
from pathlib import Path

# 写入文件
data = {"todos": [], "next_id": 1}
path = Path("data/todos.json")
path.parent.mkdir(parents=True, exist_ok=True)
with path.open("w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读取文件
with path.open("r", encoding="utf-8") as f:
    loaded = json.load(f)
```

**务必指定 `encoding="utf-8"`**。

### 7.3 异常处理

```python
try:
    data = json.loads(text)
except json.JSONDecodeError as e:
    print(f"JSON 解析失败：{e}")
```

## 第八节：实操 todo_storage（15:30 - 16:15）

```python
def load_todos(path: Path) -> dict:
    if not path.exists():
        return {"version": "1.0", "next_id": 1, "todos": []}
    with path.open("r", encoding="utf-8") as f:
        return json.load(f)

def save_todos(path: Path, data: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
```

## 第九节：实操 api_response_parser（16:15 - 17:00）

```python
def parse_chat_completion(response: dict) -> dict:
    """从 Chat Completion 响应提取关键字段"""
    result = {
        "model": response.get("model", "unknown"),
        "content": "",
        "finish_reason": "",
        "prompt_tokens": 0,
        "completion_tokens": 0,
        "total_tokens": 0,
    }
    choices = response.get("choices", [])
    if choices:
        msg = choices[0].get("message", {})
        result["content"] = msg.get("content", "")
        result["finish_reason"] = choices[0].get("finish_reason", "")
    usage = response.get("usage", {})
    result["prompt_tokens"] = usage.get("prompt_tokens", 0)
    result["completion_tokens"] = usage.get("completion_tokens", 0)
    result["total_tokens"] = usage.get("total_tokens", 0)
    return result
```

## 附录：常见 JSON 错误与修复

| 错误文本 | 原因 | 修复 |
|----------|------|------|
| Expecting property name | 单引号 | 改双引号 |
| Extra data | 多个 JSON 对象拼接 | 只解析第一个 |
| Unterminated string | 字符串未闭合 | 检查引号 |
| Expecting value | 空文件 | 判空 |
