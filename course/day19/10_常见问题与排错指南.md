# Day 19 常见问题与排错指南

**维护**：智链科技实训助教组  
**关联需求**：ZL-NA-REQ-019

---

## 1. 环境与导入

### 症状：`ModuleNotFoundError: No module named 'rag'`

**原因**：未设置 `PYTHONPATH=src`。

**解决**：

```bash
cd nexus-agent-platform
export PYTHONPATH=src
```

### 症状：`sample_docs` 找不到

**原因**：工作目录不在 `nexus-agent-platform` 根目录。

**解决**：使用 `get_path("sample_docs")`，勿硬编码绝对路径。

---

## 2. 分块 chunker

### 症状：`ValueError: overlap 必须满足 0 <= overlap < chunk_size`

**原因**：`overlap >= chunk_size` 或 `overlap < 0`。

**解决**：检查参数，典型合法组合 `(200, 40)`、`(120, 20)`。

### 症状：分块数量为 0

**原因**：传入空文本或仅空白。

**解决**：`chunk_text("")` 设计为返回 `[]`，属正常行为（见 `test_chunk_text_empty`）。

### 症状：块太多、检索噪音大

**原因**：`chunk_size` 过小。

**解决**：增大至 150–250，观察 `chunk_demos.py` 块数变化。

---

## 3. 检索 retriever

### 症状：明明文档有「收益」却检索不到

**排查清单**：

1. 查询是否为空？  
2. 是否已 `index(chunks)`？`from_sample_docs` 会自动建立  
3. 查询词是否被 tokenize？纯标点可能 `tokens` 为空  
4. 是否大小写问题？实现已 `lower()` 处理英文  

### 症状：同义词查不到（如「回报率」vs「收益率」）

**原因**：关键词 MVP 无语义理解。

**说明**：Day 20 Embedding 解决；今日可用 `/retrieve` 换关键词验证。

### 症状：score 理解困惑

**公式**：`命中 token 数 / 查询 token 数`，非 BM25。67% 表示约三分之二查询词在块中出现。

---

## 4. RAGContextService

### 症状：context 总是「未检索到相关片段」

**排查**：

```bash
python3 src/day19/retriever_demos.py
```

若 demo 也无命中，检查知识库文件是否被 `read_documents` 正确加载。

### 症状：context 超长导致 token 爆炸

**解决**：调低 `max_chars`（默认 800）或 `top_k`（默认 3）。

### 症状：header 乱码或格式不对

**格式**：`[片段{i}·{source}·{score:.0%}]` — 百分号为整数显示。

---

## 5. IntentRouter 集成

### 症状：auto_route 到 rag_qa 但 context 是占位

**原因**：未传 `query_context_provider`，且未设 `context_provider`。

**解决**：

```python
service = RAGContextService.from_sample_docs()
router = IntentRouter(query_context_provider=service.retrieve_context)
```

### 症状：query_context_provider 与 context_provider 同时存在

**行为**：**query 优先**。仅当 `query_context_provider` 为 `None` 时才用静态 provider。

---

## 6. ChatAssistant /retrieve

### 症状：`RAG 检索未启用。请传入 rag_service。`

**解决**：构造时传入 `rag_service=service`。

### 症状：`/retrieve` 与对话 context 不一致

**说明**：两者应共用同一 `RAGContextService` 实例；若各建各的，索引相同但配置可能不同。
