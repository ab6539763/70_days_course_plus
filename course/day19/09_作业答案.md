## 作业 A 参考答案

`homework/day19/chunk_lab.py` 核心逻辑：

```python
from core.paths import get_path
from rag import chunk_text
from tools.doc_reader import read_document

doc = read_document(get_path("sample_docs") / "raw_notice.txt", clean=True)
text = doc.cleaned or doc.content

for size, ov in [(120, 20), (200, 40), (100, 30)]:
    chunks = chunk_text(text, chunk_size=size, overlap=ov, source=doc.name)
    print(f"size={size} overlap={ov} → {len(chunks)} 块")
    if chunks:
        c = chunks[0]
        print(f"  {c.chunk_id}: {c.text[:50]}...")
```

**预期**：块数随 `chunk_size` 增大而减少；`(100, 30)` 通常块数最多。

## 作业 C 参考答案

### 对比摘要

| 路由器 | context 前 100 字特征 |
|--------|----------------------|
| 静态 provider | 固定「静态A」 |
| query_context_provider | 含 `[片段1·` 与资料正文 |

### 生产选型

应使用 **`query_context_provider=service.retrieve_context`**：

1. context 与用户问题相关，降低幻觉  
2. 与 `auto_route` + `rag_qa` 设计一致  
3. 静态 provider 仅用于单测回退（见 `test_intent_router_static_context_fallback`）

## 作业 D 参考答案

## 作业 E 参考答案

```python
service = RAGContextService.from_sample_docs()
for mc in [50, 120, 500]:
    ctx = service.retrieve_context("收益率 风险 客服", top_k=5, max_chars=mc)
    print(mc, len(ctx), "..." in ctx)
```

| max_chars | 典型现象 |
|-----------|----------|
| 50 | 极短，几乎必有 `...` |
| 120 | 与测试用例一致，len ≤ 130 |
| 500 | 可含多块完整正文 |

测试容差 130 因 header 与截断逻辑可能略超 `max_chars`。
