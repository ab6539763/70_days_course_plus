## 常见问题（晚自习版）

### Q1：`test_chunk_text_invalid_overlap` 为什么 overlap=10 且 chunk_size=10 会抛错？

`overlap >= chunk_size` 时滑动步长 `step = chunk_size - overlap <= 0`，逻辑非法。源码：

```python
if overlap < 0 or overlap >= chunk_size:
    raise ValueError("overlap 必须满足 0 <= overlap < chunk_size")
```

### Q2：`/retrieve` 无参数会怎样？

`args.strip()` 为空时，`retrieve_summary` 收到空 query，`search` 返回 `[]`，输出「未命中任何片段」。

### Q3：能否只用 `rag_service` 不用 `query_context_provider`？

可以，但 `auto_route` 到 `rag_qa` 时 context 仍走静态 `context_provider` 或占位；完整 RAG 须两者配合。
