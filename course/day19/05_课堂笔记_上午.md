## 10:45 KeywordRetriever

### 打分公式

```
score = |matched_tokens| / |query_tokens|
```

赵岩问：「为什么不用 TF-IDF？」  
陈默：「MVP 要可测、零依赖；TF-IDF 放扩展阅读。」

### search 排序键

```python
scored.sort(key=lambda r: (-r.score, -len(r.matched_tokens), r.chunk.index))
```

同分先看命中词数量，再看块序号（稳定排序）。
