## 1. 控制流与 Agent 状态机

LangGraph 的 StateGraph 本质是：

```
while not done:
    node = router(state)
    state = execute(node, state)
```

今天的 `while` + `if/elif` 是状态机的雏形。Day 41 你会用图节点代替 if-elif 链。

## 3. 循环性能（企业级预习）

| 模式 | 复杂度 | 场景 |
|------|--------|------|
| `for f in files` | O(n) | 批量清洗 n 个文件 |
| 嵌套 for 猜数字+历史 | O(n²) 最坏 | 小规模可接受 |
| while 读流 | O(∞) 直到 EOF | Day 11 大文件 |

Day 28 分块时，会对百万字文档做线性扫描，避免嵌套循环。
