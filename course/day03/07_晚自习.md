## 1. LeetCode 简单题推荐（2 道）

### 题 1：[1. 两数之和](https://leetcode.cn/problems/two-sum/)（理解循环与条件）

```python
# 暴力法（Day 3 水平可写）
def two_sum(nums, target):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
```

### 题 2：[9. 回文数](https://leetcode.cn/problems/palindrome-number/)（复习 Day 2 字符串）

```python
def is_palindrome(x):
    if x < 0:
        return False
    s = str(x)
    return s == s[::-1]
```
