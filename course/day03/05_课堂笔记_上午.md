## 第一节：为什么需要条件判断（9:00 - 9:20）

Day 1 你写了 `age = int(input(...))`，用户输入「二十五」程序就崩了。今天学 `if` 之后：

```python
user_input = input("请输入年龄：")
if user_input.isdigit():
    age = int(user_input)
else:
    print("请输入有效的数字")
```

**条件判断让程序能根据情况走不同分支。**

## 第二节：if 语句基础（9:20 - 9:50）

### 2.1 语法

```python
if 条件:
    # 条件为 True 时执行（注意缩进 4 空格）
    语句块
```

```python
score = 85
if score >= 60:
    print("及格了！")
```

### 2.2 if-else

```python
age = int(input("年龄："))
if age >= 18:
    print("成年人")
else:
    print("未成年人")
```

### 2.3 if-elif-else

```python
score = int(input("成绩："))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"等级：{grade}")
```

**执行规则**：从上到下，第一个为 True 的分支执行后，其余跳过。

### 2.4 嵌套 if

```python
username = input("用户名：")
password = input("密码：")

if username == "admin":
    if password == "123456":
        print("登录成功")
    else:
        print("密码错误")
else:
    print("用户不存在")
```

企业建议：嵌套不超过 3 层，过深用函数拆分（Day 6）。

## 第三节：条件表达式（9:50 - 10:20）

### 3.1 比较运算（复习 Day 2）

```python
x == y   # 等于
x != y   # 不等于
x > y    # 大于
x < y
x >= y
x <= y
```

### 3.2 逻辑组合

```python
age = 25
has_id = True

# and：都真才真
if age >= 18 and has_id:
    print("可以入场")

# or：有真即真
role = "admin"
if role == "admin" or role == "moderator":
    print("有管理权限")

# not：取反
is_banned = False
if not is_banned:
    print("账号正常")
```

### 3.3 成员判断

```python
choice = input("请选择：")
if choice in ("0", "1", "2", "3"):
    print("合法选项")
else:
    print("无效选项")

# 菜单校验（今日直接用）
VALID_CHOICES = "0123456"
if choice in VALID_CHOICES:
    ...
```

### 3.4 真值判断

```python
name = ""
if name:          # 空字符串为 False
    print("有名字")
else:
    print("名字为空")

items = []
if items:         # 空列表为 False（Day 4 学 list）
    print("有数据")
```

choice = input("请选择：").strip()

### 4.2 重试循环（预告下午 while）

```python
while True:
    age_str = input("请输入年龄（18-65）：")
    if not age_str.isdigit():
        print("请输入数字")
        continue
    age = int(age_str)
    if 18 <= age <= 65:
        break
    print("年龄超出范围")
```

### 4.3 三元表达式（简洁写法）

```python
# 传统
if score >= 60:
    result = "及格"
else:
    result = "不及格"

# 三元表达式
result = "及格" if score >= 60 else "不及格"
```

## 附录：条件判断常见错误集锦

### 错误 1：用 `=` 代替 `==`

```python
if choice = "1":  # ❌ SyntaxError
if choice == "1":  # ✅
```

### 错误 2：判断空字符串

```python
s = ""
if s == None:   # 不好
if not s:       # ✅ Pythonic
```

### 错误 3：多个条件漏写 and

```python
if age >= 18 and age <= 65:  # ✅
if age >= 18 or age <= 65:   # ❌ 永远 True！
```

### 错误 4：elif 顺序错误

```python
# 错误：先判断 >=60，90 分也会进第一分支
if score >= 60:
    grade = "D"
elif score >= 90:
    grade = "A"

# 正确：从高到低
if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "D"
```

### 错误 5：缩进不一致

```python
if x > 0:
print("正数")  # ❌ IndentationError
```
