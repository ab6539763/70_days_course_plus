**版本**：v0.1.0  
**作者**：赵岩 / 林薇  
**状态**：已批准  
**前置依赖**：ZL-NA-REQ-001、ZL-NA-REQ-002

## 1. 需求概述

将 Day 1、Day 2 的独立脚本整合为统一的交互式 CLI 菜单，作为 NexusAgent 平台命令行工具链的骨架。

## 2. 用户故事

```
作为 智链科技开发/运营人员，
我希望 通过一个交互式菜单选择平台功能，
以便 无需记忆复杂的命令行参数即可完成日常操作。
```

## 3. 菜单规格

```
╔══════════════════════════════════════╗
║     NexusAgent 平台工具箱 v0.3        ║
╠══════════════════════════════════════╣
║  1. 开发者入职登记                    ║
║  2. 单文件文本清洗                    ║
║  3. 批量清洗 sample_docs              ║
║  4. 猜数字游戏（练习）                 ║
║  5. 九九乘法表（练习）                 ║
║  6. 查看敏感词表                      ║
║  0. 退出                              ║
╚══════════════════════════════════════╝
请选择：
```

## 4. 功能需求

### 4.1 菜单 1：开发者入职登记

- 复用 Day 1 `personal_info_card` 的采集与展示逻辑
- 可通过 importlib 加载 day01 模块，避免路径问题

### 4.2 菜单 2：单文件文本清洗

- 提示输入文件路径
- 调用 Day 2 `clean_text`
- 打印清洗结果 + 报告

### 4.3 菜单 3：批量清洗

- 遍历 `src/day02/sample_docs/*.txt`
- 用 `for` 循环逐个清洗
- 输出到 `src/day03/output/` 目录
- 打印每个文件的处理摘要

### 4.4 输入校验

| 场景 | 处理 |
|------|------|
| 菜单输入非数字 | 提示「请输入 0-6 的数字」 |
| 文件路径不存在 | 提示错误，返回菜单 |
| 空路径 | 提示重新输入 |

### 4.5 猜数字游戏（ZL-NA-013）

- 系统随机 1-100 整数
- 用户反复猜测，提示「大了」「小了」
- 猜对后显示次数，`break` 退出循环
- 最多 10 次机会

### 4.6 九九乘法表（ZL-NA-014）

- 双重 `for` 循环打印 9x9 表
- 格式对齐：`1x1=1   1x2=2   ...`

## 5. 技术约束

- 文件：`src/day03/platform_cli.py`
- 仅标准库 + 引用 day01/day02 模块（importlib）
- 输出目录：`src/day03/output/`

- 成功：`✅`

- 庆祝：`🎉`

## 9. 与前后 Day 集成验收

| 集成点 | 验收方式 |
|--------|----------|
| Day 1 入职登记 | 菜单 1 等效于运行 personal_info_card.py |
| Day 2 单文件清洗 | 菜单 2 输出与 text_cleaner --report 一致 |
| Day 2 批量 | 菜单 3 生成 3 个 cleaned_*.txt |
| Day 4 预告 | 菜单将扩展「待办事项」 |

## 10. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 模块加载失败 | module_loader 统一封装，FileNotFoundError 友好提示 |
| 用户误操作 | 非法输入 continue 回菜单，不 exit |
| output 目录膨胀 | .gitignore 忽略输出文件 |
