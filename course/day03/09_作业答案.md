## 题目一：成绩等级判断

```python
"""
练习：成绩等级判断

知识点：while 循环 + if-elif-else + 输入校验
"""

while True:
    raw = input("请输入成绩（0-100）：").strip()

    # 第一层校验：是否为数字
    if not raw.isdigit():
        print("⚠️  请输入有效数字")
        continue

    score = int(raw)

    # 第二层校验：范围
    if not 0 <= score <= 100:
        print("⚠️  成绩必须在 0-100 之间")
        continue

    # 多分支等级判断（从高到低）
    if score >= 90:
        grade = "A"
        comment = "优秀"
    elif score >= 80:
        grade = "B"
        comment = "良好"
    elif score >= 70:
        grade = "C"
        comment = "中等"
    elif score >= 60:
        grade = "D"
        comment = "及格"
    else:
        grade = "F"
        comment = "不及格"

    print(f"成绩 {score} 分，等级 {grade}（{comment}）")
    break
```

**讲解**：

- `while True` 实现「直到输入合法才退出」
- `continue` 跳过本次，重新 input
- `elif` 链必须从高分到低调，否则逻辑错误

## 题目二：星号三角形

```python
"""
嵌套 for 循环：
  外层 i 控制行数（1-5）
  内层 j 控制每行星号数（0 到 i-1）
"""

for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()  # 换行
```

变体：倒三角

```python
for i in range(5, 0, -1):
    print("*" * i)
```

## 题目四：猜数字增强

```python
import random

print("选择难度：1-简单(1-50) 2-困难(1-200)")
diff = input("难度：").strip()

if diff == "1":
    lo, hi, max_try = 1, 50, 8
elif diff == "2":
    lo, hi, max_try = 1, 200, 12
else:
    print("默认简单模式")
    lo, hi, max_try = 1, 50, 8

target = random.randint(lo, hi)
history = []
attempts = 0

while attempts < max_try:
    g = input(f"猜测 {lo}-{hi}：").strip()
    if not g.isdigit():
        continue
    guess = int(g)
    attempts += 1
    history.append(guess)

    if guess == target:
        print(f"猜对！历史：{history}")
        break
    print("大了" if guess > target else "小了")
else:
    print(f"答案 {target}，历史：{history}")
```

## 题目五：思考题参考答案

### 1. while True 会死循环吗？

会，除非循环体内有 `break`、`return` 或 `raise` 退出。`platform_cli` 在 `choice == "0"` 时 `break`，是标准安全写法。

### 2. 批量清洗为什么用 for？

文件列表长度在遍历前已确定（`glob` 结果），`for path in txt_files` 语义清晰。`while` 更适合「直到某条件满足」如猜数字、菜单循环。

### 3. platform_cli 与 Web API 的相似性

| CLI | Web API |
|-----|---------|
| 菜单选项 1-7 | URL 路由 /api/v1/... |
| input 读选择 | HTTP 请求方法+路径 |
| handler 函数 | 视图函数/Controller |
| while 主循环 | 服务器常驻进程 |
| break 退出 | 连接关闭 |

Day 23 FastAPI 本质是把菜单路由换成 HTTP 路由。

### 4. continue 与 attempts 顺序

非法输入不应消耗机会。因此：

```python
if not valid:
    continue   # 先 continue
attempts += 1  # 合法后才计数
```

若顺序反了，乱输入也会耗尽次数。
