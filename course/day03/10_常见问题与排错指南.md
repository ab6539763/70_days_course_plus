# Day 3 常见问题

## Q1: 菜单死循环无法退出

确保 `choice == "0"` 时有 `break`，且没有写在 `if` 块外被跳过。

## Q2: `for` 循环里修改循环变量无效

```python
for i in range(5):
    i = 10  # 不影响循环
```

## Q3: import day02 失败

用 `module_loader.load_day_module("day02", "text_cleaner")`，不要直接 `import text_cleaner`。

## Q4: output 目录 Permission denied

```python
output_dir.mkdir(parents=True, exist_ok=True)
```

## Q5: 猜数字 `attempts` 计数不准

非法输入用 `continue` 在 `attempts += 1` **之前**。

---

## Q6: platform_cli 菜单 1 报模块错误

确认从 `nexus-agent-platform` 目录运行：

```bash
python src/day03/platform_cli.py
```

`module_loader` 基于 `src/` 相对路径加载 day01/day02。

## Q7: 批量清洗 output 为空

1. 确认 `src/day02/sample_docs/` 有 txt 文件
2. 先运行菜单 3，再运行菜单 7 统计
3. 检查 `src/day03/output/.gitignore` 不影响本地写入

## Q8: 嵌套循环看不懂

九九乘法表记忆法：**外层管行，内层管列**。第 i 行打印 i 个乘法式。
