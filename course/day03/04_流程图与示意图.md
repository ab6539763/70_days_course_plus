## 1. 平台 CLI 主循环

```mermaid
flowchart TD
    A[启动 platform_cli.py] --> B[显示菜单]
    B --> C[读取用户输入]
    C --> D{"choice?"}
    D -->|0| E[打印再见并退出]
    D -->|1| F[入职登记]
    D -->|2| G[单文件清洗]
    D -->|3| H[批量清洗 for 循环]
    D -->|4| I[猜数字游戏]
    D -->|5| J[九九乘法表]

    F --> B

    H --> B

    K --> B
```

## 2. 猜数字游戏流程

```mermaid
flowchart TD
    A[随机生成 1-100] --> B["attempts = 0"]
    B --> C{"attempts < 10?"}
    C -->|否| D[公布答案]
    C -->|是| E[用户输入猜测]
    E --> F{"合法数字?"}
    F -->|否| G[提示重新输入]
    G --> C
    F -->|是| H{guess vs target}
    H -->|相等| I[恭喜猜对 break]
    H -->|大了| J[提示大了]
    H -->|小了| K[提示小了]
    J --> L["attempts += 1"]
    K --> L
    L --> C
```

## 4. break vs continue

```
break:    跳出整个循环（猜对后结束游戏）
continue: 跳过本次迭代，进入下一次（打印乘法表时跳过某行）
```

## 6. for-else 与 while-else

```python
# for-else：循环完整执行完（未 break）时执行 else
for x in items:
    if x == target:
        print("found")
        break
else:
    print("not found")

# while-else：条件变 False 且未 break 时执行
# 猜数字次数用尽即此类
```
