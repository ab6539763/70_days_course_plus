### 7.4 猜数字游戏（完整逻辑）

```python
import random

target = random.randint(1, 100)
attempts = 0
max_attempts = 10

print("猜数字：1-100，你有 10 次机会")

while attempts < max_attempts:
    guess_str = input(f"第 {attempts + 1} 次猜测：").strip()

    if not guess_str.isdigit():
        print("请输入整数")
        continue  # 不计入次数，重新输入

    guess = int(guess_str)
    attempts += 1

    if guess == target:
        print(f"🎉 猜对了！用了 {attempts} 次")
        break
    elif guess > target:
        print("大了")
    else:
        print("小了")
else:
    # while 的 else：循环正常结束（未 break）时执行
    print(f"次数用尽，答案是 {target}")
```

## 第九节：break 与 continue（15:30 - 15:50）

| 关键字 | 作用 | 类比 |
|--------|------|------|
| `break` | 立即跳出**整个**循环 | 猜对了，游戏结束 |
| `continue` | 跳过**本次**迭代，进入下一次 | 输入非法，重新猜 |

```python
for i in range(10):
    if i == 3:
        continue  # 跳过 3
    if i == 7:
        break     # 7 及以后不执行
    print(i)
# 输出：0 1 2 4 5 6
```

### 10.1 module_loader.py

跨 day 加载避免 sys.modules 冲突：

```python
def load_day_module(day: str, module_name: str):
    src_root = Path(__file__).resolve().parent.parent
    module_path = src_root / day / f"{module_name}.py"
    spec = importlib.util.spec_from_file_location(
        f"{day}_{module_name}", module_path
    )
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module
```

### A.1 range 的边界问题

```python
list(range(5))      # [0, 1, 2, 3, 4]  不含 5
list(range(1, 5))   # [1, 2, 3, 4]      不含 5
```

### A.3 字典映射代替长 elif（进阶）

```python
# 长 elif 链（Day 3 可用）
if choice == "1":
    fn1()
elif choice == "2":
    fn2()

handler = HANDLERS.get(choice)
```

### A.4 无限循环与安全退出

```python
while True:
    cmd = input(">>> ")
    if cmd in ("quit", "exit", "0"):
        break
```

永远要有 `break` 或 `return` 条件，否则只能 Ctrl+C。

### A.5 猜数字完整状态机

| 状态 | 条件 | 动作 |
|------|------|------|
| 等待输入 | 循环中 | input() |

| 猜小 | guess < target | 提示小了 |
