## 1. Python 在设计上的哲学

Python 的设计者 Guido van Rossum 追求「优雅」「明确」「简单」。你可以在 Python 解释器中输入：

```python
import this
```

会打印 《The Zen of Python》（Python 之禅），其中几条与大模型开发密切相关：

- **Explicit is better than implicit**（明确优于隐晦）→ 类型注解、清晰的变量名
- **Readability counts**（可读性很重要）→ 代码是写给人看的
- **Simple is better than complex**（简单优于复杂）→ MVP 先跑通再优化

## 4. 终端（Terminal）是什么？

终端是一个文本界面，让你通过输入命令与操作系统交互。

```
你输入命令 → Shell 解释器解析 → 操作系统执行 → 返回结果
```

常用命令速查：

| 命令 | 作用 | 示例 |
|------|------|------|
| `cd` | 切换目录 | `cd nexus-agent-platform` |
| `ls` / `dir` | 列出文件 | `ls -la` |
| `pwd` | 显示当前路径 | `pwd` |
| `mkdir` | 创建目录 | `mkdir src/day02` |
| `cat` | 查看文件内容 | `cat README.md` |
| `cp` | 复制文件 | `cp hello.py hello_backup.py` |
| `rm` | 删除文件 | `rm temp.txt` |

**不要害怕终端**。AI 开发者每天都在终端里工作——运行脚本、启动服务、查看日志、Git 操作。
