## 题目一：基础语法练习（20 分）

**难度**：⭐

编写一个程序 `src/day01/exercise_01_types.py`，完成以下要求：

1. 定义 4 个变量，分别存储你的名字（str）、年龄（int）、身高米（float）、是否在职（bool）
2. 用 `type()` 打印每个变量的类型
3. 用 f-string 打印一句话：`我是XXX，今年XX岁，身高X.XX米，在职状态：True/False`

**期望输出示例**：

```
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
我是张三，今年25岁，身高1.75米，在职状态：True
```

## 题目二：温度转换器（20 分）

**难度**：⭐⭐

编写 `src/day01/exercise_02_temperature.py`：

1. 提示用户输入摄氏温度（浮点数）
2. 转换为华氏温度，公式：`F = C × 9/5 + 32`
3. 输出：`摄氏 XX.X°C = 华氏 XX.X°F`

**测试用例**：

- 输入 0 → 输出 32.0°F
- 输入 100 → 输出 212.0°F
- 输入 37 → 输出 98.6°F
