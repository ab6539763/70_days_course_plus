## 环境安装类

### Q1: macOS 提示 `command not found: python3`

**原因**：未安装 Python 或 PATH 未配置。

**解决**：
```bash
# 检查是否安装
ls /usr/local/bin/python3
ls /opt/homebrew/bin/python3

# 安装
brew install python@3.11

# 如果已安装但找不到，添加到 PATH
echo 'export PATH="/opt/homebrew/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### Q2: Windows 安装 Python 后终端找不到

**原因**：安装时未勾选 "Add Python to PATH"。

**解决**：
1. 重新运行安装程序 → Modify → 勾选 "Add Python to environment variables"
2. 或手动添加：`设置 → 系统 → 关于 → 高级系统设置 → 环境变量 → Path → 添加 Python 安装目录`

### Q3: pip 安装极慢或超时

**原因**：默认从国外 PyPI 下载。

**解决**：配置清华镜像（见 05_课堂笔记_上午.md 第 2.3 节）

## 代码运行类

### Q4: ModuleNotFoundError: No module named 'constants'

**原因**：运行目录不正确，Python 找不到同目录的 constants.py。

**解决**：
```bash
# 确保在 nexus-agent-platform 目录下运行
cd nexus-agent-platform
python src/day01/personal_info_card.py

# 不要这样运行：
# python personal_info_card.py  （错误）
# python /path/to/personal_info_card.py  （可能错误）
```

### Q5: ValueError: invalid literal for int() with base 10: '二十五'

**原因**：用户输入了非数字字符，int() 无法转换。

**解决**（Day 1 接受崩溃，Day 6 正式修复）：
```python
# Day 6 之后的写法
try:
    age = int(input("  年龄："))
except ValueError:
    print("请输入有效的数字年龄")
    age = 0
```

### Q6: SyntaxError: invalid character '：' (U+FF1A)

**原因**：代码中使用了中文冒号或中文引号。

**解决**：检查报错行，将所有中文标点替换为英文标点：
- `：` → `:`
- `，` → `,`（在代码中）
- `""` → `""`（中文引号 → 英文引号）

### Q7: IndentationError: unexpected indent

**原因**：缩进不一致。Python 用缩进表示代码块。

**解决**：
- 统一使用 **4 个空格**缩进，不要用 Tab
- VS Code 设置：`"editor.tabSize": 4`, `"editor.insertSpaces": true`
- 选中代码 → 右键 → "格式化文档"

### Q8: 终端中文显示乱码

**Windows PowerShell**：
```powershell
chcp 65001
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

**建议**：使用 VS Code 内置终端（默认 UTF-8）。

## Git 操作类

### Q9: git push 被拒绝 (rejected)

**原因**：远程分支有新的 commit，本地落后。

**解决**：
```bash
git pull origin feature/day01-personal-info-card --rebase
git push
```

### Q10: 不小心把 .venv 提交了

**解决**：
```bash
git rm -r --cached .venv
git commit -m "chore: 移除误提交的 .venv"
```

确保 `.gitignore` 包含 `.venv/`。

## 概念理解类

### Q11: 变量和常量有什么区别？

**变量**：值可以改变的「标签」，如 `name = "张三"` 后来可以 `name = "李四"`。

**常量**：约定不改变的值，用全大写命名，如 `COMPANY_NAME = "智链科技"`。Python 不强制不可变，靠团队规范约束。

### Q12: print 和 input 的本质是什么？

- `print()`：把数据**发送**到标准输出（终端屏幕）
- `input()`：从标准输入（键盘）**读取**一行文本

在大模型开发中，这两个函数分别对应：
- `print` → 流式输出给用户（Day 16 stream=True）
- `input` → 接收用户消息（Day 14 多轮对话）

### Q13: 为什么企业项目要分这么多文件？

今天你可能觉得「一个文件写完更简单」。但当项目增长到 20 万行时：

- 单文件 5000 行 → 找不到代码、合并冲突频繁
- 分模块 → 每人负责不同文件，并行开发
- constants 分离 → 修改配置不影响业务逻辑

**今天的习惯，决定 60 天后的代码质量。**
