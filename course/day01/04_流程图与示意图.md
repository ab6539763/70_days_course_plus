## 4. 变量与内存示意图

当你执行 `name = "张三"` 时，计算机内存中发生：

```
  变量名 (标签)          内存地址              值
  ┌──────────┐         ┌──────────┐
  │   name   │ ──────> │ 0x7f8a3c │ ──> "张三"
  └──────────┘         └──────────┘
  
  当你执行 name = "李四" 时：
  
  ┌──────────┐         ┌──────────┐
  │   name   │ ──────> │ 0x7f8b4d │ ──> "李四"  (原 "张三" 被替换)
  └──────────┘         └──────────┘
```

**关键理解**：变量名是「标签」，不是「盒子」。标签可以撕下来贴到别的值上。
