## 第五节：input() 与用户交互（14:00 - 14:45）

### 5.1 input() 函数

上午我们学了 `print()`——计算机向用户输出信息。下午学它的搭档 `input()`——获取用户输入。

```python
name = input("请输入你的姓名：")
print("你好，" + name + "！")
```

运行后，程序会暂停，等待你在终端打字，按回车确认：

```
请输入你的姓名：张三
你好，张三！
```

**执行流程**：

1. 程序执行到 `input()`，在终端显示提示文字 `请输入你的姓名：`
2. 程序**暂停**，等待用户输入
3. 用户打字后按回车
4. `input()` 返回用户输入的内容（字符串类型），赋值给 `name`
5. 程序继续执行下一行

### 5.2 input() 的重要特性

#### 特性 1：返回值永远是字符串

这是新手最容易踩的坑：

```python
age = input("请输入年龄：")
# 假设用户输入 25
print(type(age))  # <class 'str'>  ← 不是 int！
print(age + 1)    # ❌ 报错！不能 str + int
```

**正确做法**：用 `int()` 转换

```python
age = input("请输入年龄：")
age = int(age)    # 转换为整数
print(type(age))  # <class 'int'>
print(age + 1)    # 26 ✅
```

或者一行写法：

```python
age = int(input("请输入年龄："))
```

#### 特性 2：提示文字是可选的

```python
name = input()               # 无提示，直接等待输入
name = input("请输入姓名：")  # 有提示（推荐）
```

#### 特性 3：输入的内容包含换行符会被去除

用户按回车时，回车符 `\n` 不会包含在返回值中。

### 5.3 综合示例：简易问答

```python
print("=== NexusAgent 入职登记 ===")
print()

name = input("1. 请输入姓名：")
age = int(input("2. 请输入年龄："))
role = input("3. 请输入职位：")

print()
print("--- 登记信息确认 ---")
print("姓名：" + name)
print("年龄：" + str(age))    # int 转 str 才能拼接
print("职位：" + role)
print()
print("登记完成，欢迎加入！")
```

**注意** `print("年龄：" + str(age))` 这行：`+` 拼接要求两边都是字符串，所以 age 需要 `str()` 转换。

**更好的方式**（f-string，Day 2 深入学）：

```python
print(f"年龄：{age}")  # f-string 自动处理类型
```

```python
"""

from constants import (
    COMPANY_NAME,
    PROJECT_DISPLAY_NAME,
    VERSION,
    EMPLOYEE_ID_PREFIX,
    EMPLOYEE_ID_SEQ,
)


def main():
  """程序主入口"""
  pass


if __name__ == "__main__":
    main()
```

**代码解读**：

- 第一组三引号：模块文档字符串（docstring），说明文件用途
- `from datetime import date`：导入日期模块，用于获取今天日期
- `from constants import ...`：从同目录的 constants.py 导入常量
- `def main()`：定义主函数（Day 6 会详细学，今天先照抄）
- `if __name__ == "__main__"`：只有直接运行此文件时才执行 main()
  - 如果被其他文件 import，不会自动执行 main()
  - 这是 Python 的标准入口写法

#### Step 5：生成工号

```python
def generate_employee_id():
    """
    生成员工工号
    
    格式：ZL-YYYYMMDD-001
    
    Returns:
        str: 工号字符串
    """
    today = date.today()
    date_str = today.strftime("%Y%m%d")
    return f"{EMPLOYEE_ID_PREFIX}-{date_str}-{EMPLOYEE_ID_SEQ}"
```

**新知识点**：

- `date.today()` 返回今天的日期对象
- `strftime("%Y%m%d")` 格式化为 `20260706` 这样的字符串
  - `%Y` = 四位年份
  - `%m` = 两位月份
  - `%d` = 两位日期

#### Step 6：格式化输出卡片（核心）

```python
def display_card(info, employee_id):
    """
    显示格式化的入职信息卡片
    
    Args:
        info: 包含成员信息的字典
        employee_id: 工号字符串
    """
    today = date.today().strftime("%Y-%m-%d")
    
    # 使用 f-string 构建卡片
    # 注意：中文字符在终端中占 2 个显示宽度，对齐可能不完美
    # Day 2 会学习更精确的字符串对齐方法
  card = f"""
╔══════════════════════════════════════════╗
║     智链科技 · NexusAgent 项目组          ║
║         开发者入职信息卡 v{VERSION}          ║
╠══════════════════════════════════════════╣
║  姓名：{info['name']:<34}║
║  年龄：{info['age']:<34}║
║  职位：{info['role']:<34}║
║  邮箱：{info['email']:<34}║
╠══════════════════════════════════════════╣
║  工号：{employee_id:<34}║
║  入职日期：{today:<30}║
╚══════════════════════════════════════════╝
"""
    print(card)
```

**新知识点**：`{info['name']:<34}` 是 f-string 的格式说明符：

- `<` 表示左对齐
- `34` 表示占 34 个字符宽度
- Day 2 会系统学习字符串格式化

## 第七节：代码评审（16:30 - 17:30）

### 7.1 评审会流程

每天下午的代码评审是企业开发的标准环节。今天的评审清单：

| 检查项 | 标准 | 常见问题和修复 |
|--------|------|----------------|
| 能否运行 | 无语法错误，无运行时崩溃 | 检查缩进、拼写 |
| 需求覆盖 | 4 个字段都采集了 | 漏了邮箱 |
| 输出格式 | 有卡片边框 | 只 print 了纯文本 |
| 工号格式 | ZL-YYYYMMDD-001 | 日期格式不对 |
| 代码可读性 | 变量名有意义 | `a`, `b`, `c` 命名 |
| 常量提取 | 公司名不在主逻辑里 | 硬编码「智链科技」 |
| 文件结构 | constants.py 分离 | 所有代码写一个文件 |

### 7.2 典型问题点评

**问题 1：年龄输入非数字**

```python
age = int(input("  年龄："))
# 用户输入 "二十五" → ValueError: invalid literal for int()
```

Day 1 接受崩溃。Day 6 学 try/except 后修复。

**问题 2：路径问题导致 import 失败**

```bash
# 错误：在项目根目录外运行
python personal_info_card.py
# ModuleNotFoundError: No module named 'constants'

# 正确：在 nexus-agent-platform 目录下运行
cd nexus-agent-platform
python src/day01/personal_info_card.py
```

**问题 3：中文编码问题（Windows）**

如果 Windows 终端显示乱码：

```powershell
# 设置终端编码为 UTF-8
chcp 65001
```

或在 VS Code 终端中运行（VS Code 终端默认 UTF-8）。
