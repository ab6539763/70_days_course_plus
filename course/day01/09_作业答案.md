## 题目一参考答案

```python
"""
练习 1：基本数据类型

演示 int、float、str、bool 四种基本类型的定义与使用。
"""

# 定义四个不同类型的变量
name = "张三"           # str：字符串，用引号包裹
age = 25                # int：整数，没有小数点
height = 1.75           # float：浮点数，有小数点
is_employed = True      # bool：布尔值，只有 True 和 False

# 打印每个变量的类型
# type() 函数返回变量的数据类型
print(type(name))        # <class 'str'>
print(type(age))         # <class 'int'>
print(type(height))      # <class 'float'>
print(type(is_employed)) # <class 'bool'>

# 使用 f-string 格式化输出
# f-string 是 Python 3.6+ 引入的字符串格式化方式
# 花括号 {} 内的变量会被替换为实际值
print(f"我是{name}，今年{age}岁，身高{height}米，在职状态：{is_employed}")
```

**讲解**：

- `type()` 返回的是 `<class 'xxx'>` 格式，表示这个值属于哪个类
- f-string 前缀 `f` 不能忘，花括号内可以是变量、表达式：`{age + 1}`
- 布尔值首字母大写：`True` / `False`，不是 `true` / `false`

## 题目二参考答案

```python
"""
练习 2：摄氏-华氏温度转换器

公式：华氏温度 = 摄氏温度 × 9/5 + 32
华氏度 = (摄氏度 × 9/5) + 32

这是物理课的基础公式，在气象数据处理中经常使用。
NexusAgent 平台的天气查询 Agent（Day 40）会用到类似的单位转换逻辑。
"""

# 获取用户输入的摄氏温度
# input() 返回字符串，float() 将其转换为浮点数
# 为什么用 float 而不是 int？因为温度可以是小数，如 36.5°C
celsius = float(input("请输入摄氏温度："))

# 转换公式
# 注意：9/5 在 Python 3 中是浮点除法，结果是 1.8
fahrenheit = celsius * 9 / 5 + 32

# 输出结果，:.1f 表示保留 1 位小数
print(f"摄氏 {celsius:.1f}°C = 华氏 {fahrenheit:.1f}°F")
```

**讲解**：

- `float(input(...))` 是常见的输入模式，适用于需要小数的场景
- `:.1f` 是 f-string 的格式说明符：保留 1 位小数
- 如果用户输入「abc」，`float("abc")` 会报 ValueError（Day 6 学异常处理）

## 题目五参考答案

### 1. 为什么 input() 返回字符串？

**参考答案**：因为用户输入的内容在程序看来是「原始文本」，程序无法自动判断用户想输入的是数字还是文字。例如用户输入 `007`，是字符串 "007" 还是数字 7？需要开发者根据业务场景用 `int()` 或 `float()` 显式转换。这种设计给了开发者最大的灵活性。

### 2. if __name__ == "__main__" 的作用？

**参考答案**：这行代码确保 `main()` 只在「直接运行此文件」时执行。如果其他文件 `import` 了这个模块，不会自动运行 `main()`。这是 Python 的标准入口模式，让模块既可以被导入复用，又可以独立运行。不用它也能跑，但不符合企业规范，且被 import 时会产生副作用。

### 3. 个人信息卡片与成员注册 API 的关系？

**参考答案**：个人信息卡片是成员注册功能的 CLI 原型（MVP）。它们采集相同的字段（姓名、年龄、职位、邮箱），输出相同格式的信息。Day 23 会将这个逻辑封装为 `POST /api/v1/members` REST API，Day 56 会 Docker 化部署。今天的 CLI 程序验证了业务逻辑的正确性，后续只是换了一种「交互方式」（从命令行变为 HTTP 请求）。

### 4. 为什么常量要放在 constants.py？

**参考答案**：第一，避免魔法字符串——「智链科技」在 10 个文件里各写一遍，改公司名时要改 10 处。第二，便于 Code Review——审查者一眼就能看到所有配置项。第三，为后续环境配置打基础——Day 13 学 dotenv 后，constants.py 会改为从环境变量读取。第四，这是 Python 项目的通用惯例（Django 的 settings.py、FastAPI 的 config.py 都是同理）。

### 5. 70 天后的 NexusAgent 平台？

**参考答案**（示例）：70 天后，NexusAgent 平台将具备完整的前后端：React 管理控制台支持可视化配置 Agent 工作流；后端 FastAPI 提供 REST API 和 SSE 流式接口；RAG 模块支持 PDF/Word 文档上传、混合检索和 Rerank 重排序；Agent 模块基于 LangGraph 实现多 Agent 协作，支持人工审批节点；平台通过 Docker Compose 一键部署，接入自微调的 Qwen2.5-7B 模型。企业客户可以零代码配置自己的智能客服、知识问答和办公自动化 Agent。

## 加分题参考答案

```python
"""
加分题：命令行四则运算计算器

注意：本题用到了 if 判断（Day 3 内容），如果你还没学 if，
可以先跳过，Day 3 再回来完成。
"""

# 获取输入
num1 = float(input("请输入第一个数字："))
operator = input("请输入运算符（+、-、*、/）：")
num2 = float(input("请输入第二个数字："))

# 根据运算符计算
# Day 3 会学 if/elif/else，这里提前使用
if operator == "+":
    result = num1 + num2
    print(f"{num1} + {num2} = {result}")
elif operator == "-":
    result = num1 - num2
    print(f"{num1} - {num2} = {result}")
elif operator == "*":
    result = num1 * num2
    print(f"{num1} × {num2} = {result}")
elif operator == "/":
    if num2 == 0:
        print("错误：除数不能为零！")
    else:
        result = num1 / num2
        print(f"{num1} ÷ {num2} = {result}")
else:
    print(f"错误：不支持的运算符 '{operator}'")
```

## 常见错误汇总

| 错误信息 | 原因 | 修复 |
|----------|------|------|
| `SyntaxError: invalid syntax` | 语法错误，如中文标点、漏冒号 | 检查报错行 |
| `IndentationError` | 缩进不一致 | Python 用 4 空格缩进 |
| `ValueError: invalid literal for int()` | input 输入了非数字 | 确保输入数字 |
| `ModuleNotFoundError: No module named 'constants'` | 运行目录不对 | cd 到 nexus-agent-platform |
| `TypeError: can only concatenate str` | str 和 int 用 + 拼接 | 用 str() 转换或 f-string |
