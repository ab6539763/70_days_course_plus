### 林薇补充产品背景

>NexusAgent 要解决的核心问题是：企业想用 AI Agent，但不知道怎么编排、怎么接入知识库、怎么管理工具。我们要做一个**一站式平台**，让企业的业务人员也能配置自己的 Agent，而不需要写代码。
>
> 今天你们写的「个人信息卡片」，在平台里对应的是「**工作空间成员注册**」功能的最初原型。别小看它——Slack、飞书、Notion 的第一版，都是从这种小功能开始的。

## NexusAgent 平台业务场景（客户视角）

### 场景 1：某银行智能客服

**客户**：华东某城商行  
**需求**：将 500 页产品手册导入知识库，客服 Agent 能准确回答理财产品相关问题  
**平台能力**：RAG 知识库 + 对话 Agent（Day 25-38 建设）

### 场景 2：某制造企业设备运维

**客户**：苏州某精密制造公司  
**需求**：维修工程师用自然语言查询设备手册、提交工单  
**平台能力**：多 Agent 协作（搜索 Agent + 工单 Agent）（Day 39-50 建设）

### 场景 3：某电商企业运营助手

**客户**：杭州某跨境电商  
**需求**：运营人员用 Agent 分析销售数据、生成日报  
**平台能力**：Text-to-SQL Agent + 报告生成（Day 47 建设）

**今天**，你们建设的是这一切的地基。
