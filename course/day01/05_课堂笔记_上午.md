### 1.2 大模型行业全景

#### 1.2.1 什么是大模型？

大语言模型（Large Language Model, LLM）是一种经过海量文本训练的深度学习模型，能够理解和生成人类语言。

通俗理解：你给一个模型一段文字，它能「续写」下去。这个能力看起来简单，但当你把「续写」扩展到足够大的规模（数千亿参数、数万亿 Token 训练数据），模型就涌现出了令人惊讶的能力：

- **翻译**：中译英、英译中
- **摘要**：把长文章压缩成几句话
- **问答**：根据问题给出回答
- **代码生成**：根据描述写出程序
- **推理**：解决数学问题、逻辑推理
- **工具使用**：调用 API、查数据库、执行代码

这些能力不是人工编程进去的，而是从数据中「学」出来的。这就是大模型革命性的地方。

## 第二节：开发环境搭建（9:45 - 10:45）

### 2.1 安装 Python 3.11

#### 2.1.1 为什么选 3.11？

- 3.10 也可以，但 3.11 比 3.10 快 10-25%（官方数据）
- 3.12 部分第三方库兼容性问题仍存在
- 团队已统一 3.11，避免「我电脑上能跑」问题

#### 2.1.2 macOS 安装

```bash
# 方法 1：官网下载（推荐新手）
# 访问 https://www.python.org/downloads/
# 下载 macOS 64-bit installer，双击安装

# 方法 2：Homebrew
brew install python@3.11

# 验证
python3 --version
# 期望输出：Python 3.11.x
```

**常见坑**：

- macOS 自带 Python 2.7（在 `/usr/bin/python`），不要用！始终用 `python3`
- 安装后如果 `python3` 找不到，检查 PATH：`echo $PATH`

#### 2.1.3 Windows 安装

```powershell
# 方法 1：官网下载
# https://www.python.org/downloads/
# ⚠️ 安装时务必勾选 "Add Python to PATH"

# 方法 2：winget
winget install Python.Python.3.11

# 验证（Windows 上可能是 python 而不是 python3）
python --version
```

**常见坑**：

- 忘记勾选 "Add Python to PATH" → 需要手动添加环境变量
- Microsoft Store 版 Python 有时有权限问题 → 用官网版

#### 2.1.4 Linux (Ubuntu/Debian) 安装

```bash
sudo apt update
sudo apt install python3.11 python3.11-venv python3.11-dev

python3.11 --version
```

### 2.4 创建虚拟环境

**为什么需要虚拟环境？**

想象你同时参与两个项目：NexusAgent 用 Python 3.11 + FastAPI 0.100，另一个老项目用 Python 3.8 + FastAPI 0.68。如果所有包装在系统全局，版本会冲突。

虚拟环境就像给每个项目一个独立的「房间」，互不影响。

```bash
cd nexus-agent-platform

# 创建虚拟环境
python3 -m venv .venv

# 激活
# macOS / Linux:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate

# 激活后，命令行前面会出现 (.venv) 标识
# (.venv) user@machine:~/nexus-agent-platform$

# 退出虚拟环境（需要时）
deactivate
```

```bash
python3 --version        # Python 3.11.x
pip --version            # pip 23.x.x
which python3            # 应指向 .venv 内的 python
```

### 3.2 print() 函数详解

`print()` 是 Python 中最常用的函数，作用是将内容输出到控制台（终端）。

```python
# 基本用法
print("Hello")           # 输出字符串
print(42)                # 输出整数
print(3.14)              # 输出浮点数
print(True)              # 输出布尔值

# 一次打印多个值，用逗号分隔
print("姓名", "张三", "年龄", 25)
# 输出：姓名 张三 年龄 25
# 默认用空格分隔

# 自定义分隔符
print("2026", "07", "06", sep="-")
# 输出：2026-07-06

# 自定义结尾（默认是换行 \n）
print("第一行", end=" | ")
print("第二行")
# 输出：第一行 | 第二行
```

### 3.3 注释

代码中不被执行的说明文字，给人看的。

```python
# 这是单行注释

"""
这是多行注释（文档字符串）
可以写很多行
通常用在文件开头或函数说明
"""

print("这行会执行")  # 注释也可以写在代码后面
```

**企业规范**：关键业务逻辑必须写注释，但不要把注释当作「解释糟糕的代码」。好的代码应该自解释，注释解释「为什么」而不是「做了什么」。

## 第四节：变量与数据类型（11:15 - 12:00）

### 4.1 什么是变量？

变量是存储数据的「标签」。在 Python 中，创建变量不需要声明类型，直接赋值即可。

```python
name = "张三"       # 字符串变量
age = 25            # 整数变量
salary = 15000.50   # 浮点数变量
is_employed = True  # 布尔变量
```

**命名规范**（企业级，从 Day 1 养成习惯）：

| 规则 | 正确示例 | 错误示例 |
|------|----------|----------|
| 小写字母 + 下划线 | `user_name` | `userName`（这是 Java 风格） |
| 见名知意 | `employee_age` | `a`, `x1`, `temp` |
| 不用中文（团队规范） | `name` | `姓名`（个人学习可以，但不提交） |
| 不用关键字 | `user_name` | `class`, `for`, `if` |

### 4.2 四种基本数据类型

#### 4.2.1 整数 (int)

```python
age = 25
year = 2026
negative = -10
big_number = 1_000_000  # 可用下划线分隔，提高可读性

print(type(age))  # <class 'int'>
```

#### 4.2.2 浮点数 (float)

```python
price = 19.99
pi = 3.14159
temperature = -5.5

print(type(price))  # <class 'float'>

# 注意：浮点数精度问题
print(0.1 + 0.2)  # 0.30000000000000004（不是 bug，是 IEEE 754 标准）
```

#### 4.2.3 字符串 (str)

```python
name = "张三"          # 双引号
name2 = '李四'         # 单引号，效果一样
message = "他说：'你好'"  # 混合使用

# 三引号：多行字符串
intro = """
大家好，我是张三，
来自智链科技 NexusAgent 项目组。
"""

print(type(name))  # <class 'str'>
```

**字符串预告**（Day 2 重点学）：

```python
# f-string 格式化（今天先了解，明天深入）
name = "张三"
age = 25
print(f"我叫{name}，今年{age}岁")
# 输出：我叫张三，今年25岁
```

#### 4.2.4 布尔值 (bool)

```python
is_student = True
is_admin = False

print(type(is_student))  # <class 'bool'>

# 布尔值来自比较运算
print(5 > 3)    # True
print(5 == 3)   # False
print(5 != 3)   # True（不等于）
```

### 4.3 type() 函数

查看变量的类型：

```python
name = "张三"
age = 25
print(type(name))  # <class 'str'>
print(type(age))   # <class 'int'>
```

### 4.4 类型转换

```python
# str → int
age_str = "25"
age_int = int(age_str)  # 25（整数）
print(type(age_int))    # <class 'int'>

# int → str
age = 25
age_str = str(age)  # "25"（字符串）

# ⚠️ 注意：input() 返回的永远是字符串！
# 这是下午实操的关键知识点
```

### 4.5 常量（Convention）

Python 没有真正的常量（不能强制不可变），但约定**全大写变量名**表示常量：

```python
COMPANY_NAME = "智链科技有限公司"
PROJECT_NAME = "NexusAgent"
VERSION = "0.1.0"
MAX_AGE = 65
MIN_AGE = 18
```

我们把这些放在 `constants.py` 中统一管理。
