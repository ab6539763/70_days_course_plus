# Day 4 FAQ

## Q1: list.remove 找不到元素

`ValueError` — 先 `if x in lst` 再 remove。

## Q2: 遍历时删除 list 元素

```python
# 错误：边遍历边删
for t in todos:
    if t[4]:
        todos.remove(t)  # 可能跳元素

# 正确：倒序或重建
todos = [t for t in todos if not t[4]]
```

## Q3: sorted 和 sort 区别

`sort()` 原地改；`sorted()` 返回新 list。

## Q4: 单元素 tuple

必须 `(1,)` 不能 `(1)`。
