## 案例 5：混合检索融合（Day 33）

```python
vector_hits = ["doc_a", "doc_b", "doc_c"]
bm25_hits = ["doc_b", "doc_d"]
# 并集去重保序
seen = set()
merged = []
for doc in vector_hits + bm25_hits:
    if doc not in seen:
        seen.add(doc)
        merged.append(doc)
```

## 附录：讲师课堂话术参考

**讲解 list 时**：

> 「大家把 list 想象成一排带编号的储物柜。append 是往末尾加一个柜子；pop 是拆掉某个柜子；切片是取出连续几个柜子里的东西。」

**讲解推导式时**：

> 「推导式是 for 循环的语法糖。能读懂推导式，就能读懂一半开源 AI 项目里的数据处理代码。」

**讲解 todo_manager 时**：

> 「今天不要用 dict 存待办，因为明天林薇要教 JSON，dict 和 JSON 是天生一对。今天用 list 是为了让你们感受索引和结构。」

**Code Review 时常说**：

> 「删除用 pop 还是列表推导？如果删除条件复杂，推导式更清晰。如果按 id 删一个，pop 配合 find_index 更直接。」

## 学员常见问题现场答疑实录

**问**：能否用 `todos = todos + [new_item]` 代替 append？  
**答**：可以，但会创建新 list，效率略低。append 原地修改更好。

**问**：priority 用 1/2/3 还是 "高"/"中"/"低"？  
**答**：存储用数字便于排序；显示用 PRIORITY_LABELS 映射中文。

**问**：退出时如何保存？  
**答**：Day 4 不保存。Day 5 学 `json.dump(todos, f)`。
