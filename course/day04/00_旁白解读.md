> **前置要求**：完成 Day 1-3，`platform_cli.py` 能运行

---

## 旁白

2026 年 7 月 9 日，星期四。

林薇在周会上展示了一张 NexusAgent 产品 backlog 白板：

```
□ 完成 RAG 文档清洗工具
□ 接入 DeepSeek API
□ 设计多租户权限模型
☑ 完成开发者入职登记
☑ 文本清洗 CLI
```

她转向你们：

> 「这就是一个 **Todo List**。产品经理每天与它打交道。今天你们要用 Python 的 **list** 实现一个命令行版待办管理器——增删改查、标记完成、按优先级排序。
>
> 为什么重要？因为大模型开发里，**到处都是列表**：
> - API 返回的 `messages` 是列表
> - RAG 检索的 `chunks` 是列表
> - Agent 的 `tools` 是列表
> - 批量文档路径 `files` 是列表
>
> 把 list 学透，后面 60 天会顺很多。」

## 导师寄语

林薇：

> 「待办管理器看起来简单，但你们在做的是**结构化数据管理**的启蒙。list 里每一项是一个记录，append 是创建，索引访问是读取，赋值是更新，pop 是删除——这就是 CRUD 的本质。Day 24 换成 PostgreSQL，Day 30 换成 Milvus，思想一模一样。」
