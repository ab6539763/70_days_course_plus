## 第一节：list 基础（9:00 - 9:40）

### 1.1 创建列表

```python

todos = []
```

```python

print(todos[0])    # 任务A
print(todos[-1])   # 任务C
todos[1] = "任务B-改"  # 修改
```

### 1.3 切片（复习 Day 2）


## 第二节：list 增删操作（9:40 - 10:30）

### 2.1 添加

```python
todos = []

# append：末尾添加（最常用）
todos.append("新任务")

# insert：指定位置
todos.insert(0, "紧急任务")  # 插到最前

# extend：合并另一个列表
todos.extend(["任务B", "任务C"])
# 等价 todos += ["任务B", "任务C"]
```

### 2.2 删除

```python
todos = ["A", "B", "C", "B"]

# pop：按索引删除并返回
item = todos.pop(1)   # 删除 "B"，返回 "B"
last = todos.pop()    # 删除最后一个

# remove：按值删除（第一个匹配）
todos.remove("B")

# del 语句
del todos[0]

# clear：清空
todos.clear()
```

### 2.3 查找与计数

```python
todos = ["写代码", "开会", "写代码"]

todos.index("开会")   # 1
todos.count("写代码") # 2
"开会" in todos       # True
```

## 第三节：list 排序（10:30 - 11:10）

### 3.1 sort 原地排序

```python
scores = [85, 92, 78, 96]
scores.sort()           # 升序，修改原列表
scores.sort(reverse=True)  # 降序
```

### 3.2 sorted 返回新列表

```python
scores = [85, 92, 78]
sorted_scores = sorted(scores)  # 原列表不变
```

### 3.3 自定义 key（待办优先级）

```python
todos = [
    [1, "任务A", "", 3, False],  # 优先级 3 低
    [2, "任务B", "", 1, False],  # 优先级 1 高
]

# 按 priority（索引 3）升序
sorted_todos = sorted(todos, key=lambda t: t[3])
```

**lambda 预告**：`lambda t: t[3]` 表示「取每个元素的第 4 项作为排序键」。Day 6 会详细讲。

### 3.4 多键排序

```python
# 先按完成状态，再按优先级
sorted(todos, key=lambda t: (t[4], t[3]))
```

## 第四节：列表推导式（11:10 - 12:00）

### 4.1 基本语法

```python
[表达式 for 变量 in 可迭代对象]
```

```python
# 传统
squares = []
for i in range(10):
    squares.append(i ** 2)

# 推导式
squares = [i ** 2 for i in range(10)]
```

### 4.2 带条件

```python
# 偶数的平方
evens = [i**2 for i in range(10) if i % 2 == 0]

# 未完成的待办标题
pending_titles = [t[1] for t in todos if not t[4]]
```

### 4.3 企业场景

```python
# RAG：过滤低分 chunk（Day 33）
good_chunks = [c for c in chunks if c.score >= 0.7]

# Agent：提取工具名称
tool_names = [t.name for t in tools]

# Token 估算：统计非空消息
non_empty = [m for m in messages if m.strip()]
```

### 4.4 注意事项

- 推导式适合**简单**转换；复杂逻辑用 for 循环更清晰
- 不要嵌套超过 2 层

## 附录 B：深浅拷贝（预习）

```python
import copy
a = [[1, 2], [3, 4]]
b = a.copy()       # 浅拷贝
c = copy.deepcopy(a)  # 深拷贝
a[0][0] = 99
# b[0][0] 也变成 99；c[0][0] 仍是 1
```

待办 list 存简单类型时浅拷贝足够；Day 8 嵌套对象需注意。

## 附录 C：企业案例 — 对话窗口截断

```python
MAX_HISTORY = 10

def trim_messages(messages: list) -> list:
    """保留 system 消息 + 最近 N 条"""
    if len(messages) <= MAX_HISTORY:
        return messages
    system = [m for m in messages if m.get("role") == "system"]
    rest = [m for m in messages if m.get("role") != "system"]
    return system + rest[-MAX_HISTORY:]
```

这是 Day 27 Memory 模块的简化原型。
