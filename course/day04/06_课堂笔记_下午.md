## 第五节：元组 tuple（14:00 - 14:40）

### 5.1 不可变序列

```python
point = (10, 20)
rgb = (255, 128, 0)
single = (42,)   # 单元素必须加逗号
not_tuple = (42) # 这是 int！

# 访问同 list
print(point[0])  # 10
# point[0] = 5   # ❌ TypeError
```

### 5.2 何时用 tuple

| 场景 | 原因 |
|------|------|
| 坐标、RGB | 固定结构，不应被改 |
| 函数返回多值 | `return x, y` 实际是 tuple |
| dict 的 key | list 不能作 key，tuple 可以 |
| 配置常量 | `ALLOWED = ("GET", "POST")` |

```python
def get_stats(todos):
    total = len(todos)
    done = sum(1 for t in todos if t[4])
    return total, done  # 返回 tuple

total, done = get_stats(todos)  # 解包
```

def add_todo(todos, next_id, title, desc, priority):

    todos.append(item)

### 7.3 按 id 查找

```python
def find_by_id(todos, todo_id):
    for t in todos:
        if t[0] == todo_id:
            return t
    return None
```

### 7.4 删除

```python
def delete_todo(todos, todo_id):
  for i, t in enumerate(todos):
        if t[0] == todo_id:
            todos.pop(i)
            return True
    return False
```

### 7.5 显示列表

```python
def display_todos(todos, sorted_by_priority=False):
    items = sorted(todos, key=lambda t: t[3]) if sorted_by_priority else todos
    for t in items:
        mark = "x" if t[4] else " "
        pri = {1: "高", 2: "中", 3: "低"}[t[3]]
        print(f"[{mark}] #{t[0]} [{pri}] {t[1]}")
```

### 7.6 统计（列表推导式）

```python
def stats(todos):
    total = len(todos)
    done = len([t for t in todos if t[4]])
    pending = total - done
    return total, done, pending
```

## 附录：todo_manager 完整数据流

### 添加流程

```
用户输入 title/desc/priority
    → 校验 title 非空
    → create_todo(id, ...)
    → todos.append(item)
    → next_id += 1
```

### 删除流程

```
用户输入 id
    → find_index_by_id
    → 确认 y/n
    → todos.pop(idx)
```

### enumerate 在删除中的用法

```python
for i, t in enumerate(todos):
    if t[0] == target_id:
        todos.pop(i)
        break
```

找到后立即 `break`，避免继续遍历。

### 列表推导式性能说明

待办数量 < 1000 时，推导式与 for 循环差异可忽略。RAG 百万 chunk 时需注意（Day 34）。
