## 题目一：list 基础操作

```python
"""练习 1：list 操作"""

nums = [3, 1, 4, 1, 5, 9, 2, 6]

# 1. 追加 7
nums.append(7)

# 2. 删除第一个 1（remove 只删第一个匹配）
nums.remove(1)

# 3. 升序排序（原地）
nums.sort()

# 4. 最大最小
print(f"max={max(nums)}, min={min(nums)}")

# 5. 列表推导：大于 4
greater_than_4 = [n for n in nums if n > 4]
print(greater_than_4)
```

## 题目四：tuple 与 set

```python
def list_stats(nums):
    if not nums:
        return 0, 0, 0.0
    return min(nums), max(nums), sum(nums) / len(nums)

words = ["rag", "agent", "rag", "api", "agent"]
unique_sorted = sorted(set(words))
print(list_stats([1, 5, 3, 9]))
print(unique_sorted)  # ['agent', 'api', 'rag']
```

## 加分题：矩阵转置

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
# 方法 1：推导式
transposed = [[row[i] for row in matrix] for i in range(len(matrix[0]))]
# 方法 2：zip
transposed = [list(col) for col in zip(*matrix)]
```

## 错误集锦

| 错误 | 原因 | 修复 |
|------|------|------|
| `IndexError` | 下标越界 | 检查 len |
