## 1. list 在大模型栈中的无处不在

| 组件 | list 用途 |
|------|-----------|
| Chat API | messages 数组 |
| Embedding | texts 批量输入 |
| RAG | chunks、scores 并行 list |
| Agent | tools、tool_calls |
| 评估 | predictions、references |

## 2. 时间复杂度直觉

| 操作 | 平均复杂度 |
|------|------------|
| append | O(1) |
| pop() | O(1) |
| pop(0) | O(n) |
| insert(0,x) | O(n) |
| in | O(n) |
| sort | O(n log n) |

待办在尾部 append/pop 高效；不要在头部频繁 insert。

## 3. 列表 vs 其他语言

Python list 是动态数组，可混合类型（但不建议）。类似 JavaScript Array。

## 4. 不可变替代：tuple

配置项 `ROLES = ("system", "user", "assistant")` 防止被误改。

## 5. 集合去重场景

```python
# 统计文档中出现过的所有标签
all_tags = set()
for doc in documents:
    all_tags.update(doc.tags)
```
