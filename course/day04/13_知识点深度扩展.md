## 第一章：为什么 list 是 Python 最常用的数据结构

在 C 语言里，数组长度固定；在 Python 里，list 是**动态数组**，自动扩容。这使得：

1. 不需要预先知道元素个数（对话消息不断增长）
2. append 均摊 O(1) 高效
3. 与 for 循环、推导式天然配合

NexusAgent 平台中，以下全部是 list：

```python

# Day 20 Embedding 批量

# Day 29 检索结果
```

## 第二章：list 内存模型（进阶）

```python
a = [1, 2, 3]
b = a          # b 和 a 指向同一列表
b.append(4)
print(a)       # [1, 2, 3, 4]  a 也变了！

c = a.copy()   # 浅拷贝，独立列表
c.append(5)
print(a)       # [1, 2, 3, 4]  不受影响
```

待办项是「扁平 list」`[id, title, ...]`，拷贝一条用 `item.copy()` 或 `list(item)`。

## 第三章：enumerate、zip、all、any

```python
todos = [["A", 1], ["B", 2]]

# enumerate：带索引遍历
for i, t in enumerate(todos, start=1):
    print(f"{i}. {t[0]}")

# zip：并行遍历
titles = ["A", "B"]
prios = [1, 2]
for title, p in zip(titles, prios):
    print(title, p)

# all / any
all_done = all(t[4] for t in todos)
any_high = any(t[3] == 1 for t in todos)
```

## 第四章：sorted 的 key 函数深入

```python
# 多键排序：先按 done（未完成在前），再按 priority
sorted(todos, key=lambda t: (t[4], t[3]))

# 按标题长度
sorted(todos, key=lambda t: len(t[1]))

# 反向
sorted(todos, key=lambda t: t[3], reverse=True)
```

`key` 函数是 Day 6「函数作为参数」的预习。

## 第五章：列表推导式 vs 生成器（预习）

```python
# 列表推导：立即创建完整 list
squares = [x**2 for x in range(1000000)]  # 占内存

# 生成器表达式：惰性求值（Day 13 生成器）
squares_gen = (x**2 for x in range(1000000))  # 省内存
```

百万级 chunk 时用生成器；待办几百条用 list 即可。
