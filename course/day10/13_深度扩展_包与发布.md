# Day 10 深度扩展：Python 包与发布

## 包发现机制

Python 3.3+ 命名空间包可不含 `__init__.py`，但 NexusAgent **统一要求** `__init__.py` 以明确公共 API。

## 相对导入

```python
# 在 services/message_history.py 中（不推荐本项目中使用）
from ..models.message import ChatMessage
```

绝对导入更清晰：`from models.message import ChatMessage`。
