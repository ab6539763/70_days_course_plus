# Day 10 架构设计

## 1. 分层架构（Day 10 定型）

```
┌─────────────────────────────────────┐
│  dayXX / chat / llm  （应用入口）    │
├─────────────────────────────────────┤
│  services/          业务编排         │
├─────────────────────────────────────┤
│  models/            领域模型         │
├─────────────────────────────────────┤
│  utils/             工具函数         │
├─────────────────────────────────────┤
│  core/              异常/路径/引导   │
└─────────────────────────────────────┘
```

## 2. 依赖规则

- `core` 不依赖上层任何包
- `models` 可依赖 `core`、`utils`
- `services` 可依赖 `models`、`utils`、`core`
- `dayXX` 可依赖所有生产层
- **禁止反向依赖**

## 3. 迁移策略

| 组件 | 策略 |
|------|------|
| MessageHistory | 迁至 services + day08 re-export |
| ModelValidationError | 迁至 core + models re-export |
| 路径常量 | 逐步迁入 core.paths.PATHS |
