## 第一节：模块是什么（9:00 - 9:40）

**模块** = 一个 `.py` 文件。  
**包** = 含 `__init__.py` 的目录。

NexusAgent 当前 `src/` 下生产包 7 个、教学 day 目录 10 个，合计模块超过 60 个。**没有模块系统，就无法维护。**

```python
# 文件 models/message.py 是一个模块
# 目录 models/ 是一个包
```

### 1.1 模块搜索过程（了解）

`import models` 时 Python：

1. 在 `sys.path` 各目录查找 `models` 文件夹或 `models.py`  
2. 找到后执行 `models/__init__.py`  
3. 将包对象绑定到当前命名空间  

### 1.2 常见失败原因

| 现象 | 原因 |
|------|------|
| No module named 'models' | PYTHONPATH 未含 src |
| No module named 'core' | 同上 |
| circular import | 模块互相顶层 import |

### import 的几种形式

```python
import models                    # 导入包
from models import ChatMessage   # 从包导入名
from models.message import ChatMessage  # 从模块导入
import models.message as mm      # 别名
```

**团队规范**：生产代码用**绝对导入** `from models import ...`，避免 `from ..utils import` 相对导入混乱（小项目）。

## 第二节：`__name__` 与入口（9:40 - 10:20）

```python
# hello.py
print(__name__)

# 直接运行: python hello.py  → __main__
# 被 import                    → hello
```

`if __name__ == "__main__":` 块内的代码仅在直接运行时执行，被导入时不执行——CLI 脚本标准模式。

---

## 第三节：`__all__` 与公共 API（10:20 - 11:00）

```python
# models/__init__.py
__all__ = ["ChatMessage", "BaseModel"]
```

控制 `from models import *` 导出哪些名字（团队禁止 import *，但 `__all__` 仍标示公共 API）。

## 第四节：PYTHONPATH 与 bootstrap（11:00 - 12:00）

### 问题

```python
from models import ChatMessage  # ModuleNotFoundError
```

Python 只在 `sys.path` 所列目录找模块。

### 解决方案

```bash
export PYTHONPATH=src
# 或
from core.bootstrap import setup_python_path
setup_python_path()
```

`core/paths.py` 定义 `SRC_ROOT`，全项目统一。

## 上午小结

| 概念 | 要点 |
|------|------|
| 模块 | .py 文件 |
| 包 | 含 __init__.py 的目录 |
| import | 绝对导入优先 |
| __name__ | __main__ 表示直接运行 |
| sys.path | 模块搜索路径 |
