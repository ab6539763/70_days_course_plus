## 第一章：从脚本到包

Day 1 你们写单文件 `hello.py`。Day 10 仓库含 80+ 模块。**模块系统**是组织代码的语法与运行时规则。

### 1.1 模块的定义

每个 `.py` 文件是一个模块，模块名 = 文件名（不含 `.py`）。

`src/models/message.py` → 模块名 `models.message`（在 `src` 于 path 上时）。

### 1.2 包的定义

包是含 `__init__.py` 的目录（NexusAgent 强制要求）。`models/` 是包，`models.message` 是子模块。

`__init__.py` 可为空，也可导出公共 API：

```python
# models/__init__.py
from models.message import ChatMessage
__all__ = ["ChatMessage", ...]
```

## 第二章：import 语句语义

### 2.1 import module

```python
import models
msg = models.ChatMessage("user", "hi")  # 需通过包前缀
```

只导入包时，不自动导入子模块全部内容（除非 `__init__.py` 已导入）。

### 2.2 from ... import name

```python
from models import ChatMessage
```

将 `ChatMessage` 绑定到当前模块命名空间。推荐用于常用类。

### 2.3 import as 别名

```python
from models import ChatMessage as CM
```

长名或避免冲突时使用。

### 2.4 循环导入示例与修复

**错误示例**：

```python
# a.py
from b import func_b
def func_a(): ...

# b.py
from a import func_a  # 循环！
def func_b(): ...
```

**修复**：提取公共部分到 `c.py`，或延迟导入（函数内 import）。

NexusAgent 规则：**依赖单向**，从源头消除循环。

## 第三章：`__name__` 与可执行模块

```python
def main():
    ...

if __name__ == "__main__":
    main()
```

- 直接 `python script.py`：`__name__ == "__main__"`
- `import script`：`__name__ == "script"`

所有 `dayXX/*_demos.py` 均用此模式，避免被 import 时执行 demo。

## 第四章：sys.path 与 PYTHONPATH

### 4.1 搜索顺序

import 时 Python 遍历 `sys.path` 中每个目录，查找包/模块。

### 4.2 项目标准做法

```bash
cd nexus-agent-platform
export PYTHONPATH=src
python3 src/day10/module_demos.py
```

或脚本开头：

```python
from core.bootstrap import setup_python_path
setup_python_path()
```

### 4.3 为何不放 repo 根目录

若把 `import` 写在 repo 根，与 `nexus-agent-platform` 平级，协作混乱。统一以 `nexus-agent-platform` 为工作目录。

## 第六章：import 风格团队规范

1. **绝对导入优先** — `from models import X`  
2. **禁止 import *** — 污染命名空间  
3. **顶层 import 标准库 → 第三方 → 本项目** — PEP 8  
4. **生产代码不在 dayXX** — Code Review 红线
