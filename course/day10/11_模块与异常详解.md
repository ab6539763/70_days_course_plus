## 第一章：sys.path 内幕

Python 启动时 `sys.path` 包含：

1. 脚本所在目录（或空串表示当前工作目录）
2. PYTHONPATH 环境变量目录
3. 标准库目录
4. site-packages

`setup_python_path()` 将 `src/` 插入首位，使 `import models` 解析为 `src/models`。

---

## 第二章：循环导入与如何避免

**症状**：`ImportError: cannot import name 'X' from partially initialized module`

**原因**：A import B，B import A。

**NexusAgent 规范**：

- `core` 绝不 import `models`
- `models` 不 import `services`
- 延迟导入：在函数内 `import` 而非模块顶层（慎用）

## 第三章：异常层次设计原则

1. **业务异常继承 NexusError** — 上层统一处理
2. **保留标准异常兼容** — ModelValidationError 兼 ValueError
3. **异常带 code 字段** — 日志与监控友好
4. **异常带上下文** — path、model_type

## 第四章：何时抛异常 vs 返回错误

| 场景 | 方式 |
|------|------|
| CLI input | 返回 str 错误 |
| 服务层 load 严格 | raise JsonParseError |
| 模型校验 API 层 | ensure_valid → raise |
| 批量导入 | from_dict_safe |

## 第八章：import 语句完整对照表

| 写法 | 效果 |
|------|------|
| `import models` | 绑定 models 包 |
| `from models import ChatMessage` | 直接绑定 ChatMessage |
| `import models.message as mm` | 别名模块 |
| `from core.paths import get_path` | 从子模块导入函数 |
