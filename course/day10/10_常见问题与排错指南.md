# Day 10 常见问题与排错指南

## Q1：ImportError: No module named 'core'

设置 `PYTHONPATH=src` 或调用 `setup_python_path()`。

## Q2：循环导入

检查 core/models/services 是否互相顶层 import。将 import 移入函数内或调整依赖方向。

## Q3：day08 测试失败

确认 `day08/message_history.py` 为 re-export，API 与 Day 8 一致。

## Q4：ModelValidationError 找不到

`from core import ModelValidationError` 或 `from models import ModelValidationError`。

## Q5：get_path KeyError

应抛 ConfigError 而非 KeyError；若见 KeyError 说明未用 get_path。

## Q6：structure_audit 退出码 1

查看输出缺哪个包的 `__init__.py`。

## Q7：能否删除 dayXX？

**不能**。教学需要保留，仅禁止新生产代码写入。

## Q8：llm 包是空的能提交吗？

能。`__init__.py` + `__all__ = []` 为占位。

## Q9：bare except 为何禁止？

会捕获 KeyboardInterrupt/SystemExit，难以调试。

## Q10：与 logging 关系

Day 46 将把 `NexusError` 记入结构化日志；今日先 print。
