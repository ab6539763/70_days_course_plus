# ZL-NA-REQ-040 产品需求文档（PRD）

**需求名称**：AgentExecutor 框架工具链
**优先级**：P0
**平台版本**：v0.40.0

---

## 1. 背景

Day39 的 ReAct 循环里，每个工具的入参 schema 是手写字典，新增工具要改多处代码，容易漏字段。 引入 LangChain 风格 @tool 装饰器 + StructuredTool：从函数签名自动推导 OpenAI function-calling schema，AgentExecutor.invoke 统一调度并记录 intermediate_steps。

## 2. 目标

- `agent/structured_tool.py` — StructuredTool + @tool 装饰器 + OpenAI schema
- `agent/tool_adapter.py` — ToolRegistry → StructuredTool 适配
- `agent/agent_executor.py` — AgentExecutor.invoke 可观测循环
- `agent/executor_config.py` — ExecutorConfig — max_iterations
- `GET/PUT /api/agent/executor-config` 配置读写
- `POST /api/agent/executor-preview` 无状态预览

- `POST /api/chat` + `executor_mode=true` → `executor_trace`

## 3. 功能需求

### FR-001 StructuredTool + @tool 装饰器 + OpenAI schema

- 实现位置：`agent/structured_tool.py`

### FR-002 ToolRegistry → StructuredTool 适配

- 实现位置：`agent/tool_adapter.py`

### FR-003 AgentExecutor.invoke 可观测循环

- 实现位置：`agent/agent_executor.py`

### FR-004 ExecutorConfig — max_iterations

- 实现位置：`agent/executor_config.py`

### FR-005 持久化与 status

- `store.json` 新增对应 config 字段
- `GET /api/knowledge/status` 含该 config 字段
- `platform_version` 为 `v0.40.0`

### FR-006 Chat 集成

- `api/chat.py` 在 `executor_mode=true` 且配置 `enabled` 时走本日管线
- `ChatResponse` 新增 `executor_trace` 字段（及 tools_used）

### FR-007 演示与测试

- `day40/executor_demo.py` 打印决策/委派轨迹
- `day40/executor_api_demo.py` 演示 REST API
- `tests/day40/` 17 项覆盖单元 + API + chat

## 4. 非功能需求

### NFR-001 可观测性

每次调用都返回结构化 `executor_trace`，可用于审计与教学演示。

### NFR-002 兼容性

`executor_mode=false`（默认）时行为与之前完全一致，不影响既有回归。

### NFR-003 可测试性

核心类可脱离 FastAPI 直接单测（构造 `ToolExecutor` 后 `invoke`/`run`）。

## 5. 非目标

- 接入真实大模型 function-calling（当前仍为规则/mock 决策）
- 跨 session 的长期记忆持久化
