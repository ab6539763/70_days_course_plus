# ZL-NA-REQ-014 需求文档

**需求编号**：ZL-NA-REQ-014  
**需求名称**：命令行多轮对话 AI 助手  
**优先级**：P0  
**Sprint**：Sprint 1 阶段项目一  
**状态**：已交付

---

## 1. 背景

智链科技 NexusAgent 内测用户需要在终端进行**多轮**理财知识问答。单次 `LLMClient.complete` 无法保留上下文；需在 CLI 层维护 `messages` 历史，并整合 Day 13 弹性客户端以应对 API 抖动。

## 2. 目标用户

- 内测理财顾问（终端重度用户）
- 开发与测试人员（CI 脚本模式）
- 培训课程学员（Mock 模式练习）

## 3. 功能需求

### FR-001 多轮对话

| 项 | 描述 |
|----|------|
| 输入 | 用户文本一行 |
| 处理 | 追加 `user` 消息 → 调用 `ResilientLLMClient.complete(messages)` → 追加 `assistant` 回复 |
| 输出 | 助手回复文本展示在终端 |
| 约束 | 每轮发送**完整**历史（含 system） |

### FR-002 默认系统提示

- 初始化时若历史中无 `system` 消息，注入 `DEFAULT_SYSTEM_PROMPT`
- 内容：智链科技 NexusAgent 助手，专业简洁回答企业文档与产品问题

### FR-003 斜杠命令

| 命令 | 行为 |
|------|------|
| `/help` | 列出 `COMMANDS` 全部命令及说明 |
| `/exit` | 退出，输出告别语 |
| `/quit` | 同 `/exit` |
| `/clear` | 清空对话，**保留**所有 `system` 消息 |
| `/history` | 格式化展示当前 `messages` |
| `/save` | 持久化到 `history_path`（默认 `chat_session.json`） |
| `/system <文本>` | 追加新的 system 提示；无参数时提示用法 |

### FR-004 运行模式

| 模式 | 方法 | 场景 |
|------|------|------|
| 交互式 | `run_interactive` | 真人 `input()` 循环 |
| 脚本式 | `run_scripted(lines)` | pytest、CI、`cli_assistant_demo.py` |

### FR-005 异常处理

- `ConfigError`：展示「配置错误」不退出主循环
- `APIError`：展示「API 调用失败」不退出主循环
- 其他 `NexusError`：展示通用错误信息

### FR-006 会话持久化

- 交互式退出时尝试 `save_history()`
- 支持 `load_history()` 从文件恢复

## 4. 非功能需求

| 编号 | 要求 |
|------|------|
| NFR-001 | `NEXUS_LLM_MOCK=1` 下无需 API Key 可运行 |
| NFR-002 | 核心类可注入 `client`、`history` 便于单测 |
| NFR-003 | 空输入与非法消息返回友好提示，不抛未捕获异常 |
| NFR-004 | 代码位于 `src/chat/cli_assistant.py`，版本 1.0.0 |

