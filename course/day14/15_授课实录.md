## 讲 handle_command（10:10）

现场 Live Coding：只写 `/help` 分支，然后打开完整文件。

> 「注意返回值是三元组。第三个 `should_exit`，未来若加 `/restart` 也是 `False`；只有 exit/quit 是 `True`。把『是否结束』显式化，主循环就不写一堆 `if cmd == ...`。」

---

## 讲 chat_turn（10:50）

在白板写：

```
user 进来 → 进 history → 整包发给 API → assistant 回来 → 进 history
```

> 「多轮对话没有黑魔法。API 无状态，『记忆』是客户端每次把聊天记录再抄一遍寄过去。明天 Day 15，我们数抄了多少字 —— token。」

学生笑。

## 阶段项目评审（16:20）

每组 3 分钟演示 + 2 分钟问答。

**典型问答**：

- 问：为何不用 `while True` 里直接写 `if line.startswith('/')`？

- 问：`/clear` 为何不删 system？  
- 答：产品要保留智链助手人设，只清对话话题。
