## 1. 为何收官日放在周日

Sprint 1 刻意将 Day 14 放在周日：上午收尾编码，下午评审庆功，给学生完整「交付闭环」体验。周一 Day 15 进入 Sprint 2 新主题 Token，心理节奏清晰。

---

## 2. 教学难点预判

| 难点 | 对策 |
|------|------|
| 混淆 `complete` 与 imagined `chat()` | 强调项目统一 messages 列表 API |
| 以为 `/clear` 删 system | 现场 `/history` 对比 |
| `run_scripted` 返回值 | 用 demo 打印 + pytest 断言 |
| 多 system 行为 | 标注为「模型相关」，不深挖 |

---

## 3. Live Coding 建议顺序

1. 空壳 `ChatAssistant` + `DEFAULT_SYSTEM_PROMPT`  
2. `chat_turn` 三步（先不接命令）  
3. `handle_command` 从 `/help`、`/exit` 开始  
4. `_process_line` 合并  
5. `run_scripted` 先于 `run_interactive`（便于测）  
6. 最后 `run_interactive` 横幅与 save

## 8. 常见课堂问题标准答

**Q：能否自动 load_history？**  
A：可以一行扩展，但产品需定义「启动覆盖策略」；本期手动，避免误覆盖。

**Q：为何不用 LangChain？**  
A：Sprint 1 教学目标是用标准库 + 自研模块理解底层拼装；框架是后续课。
