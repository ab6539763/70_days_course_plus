# Day 14 流程图与示意图

## 1. 交互式主循环

```mermaid
flowchart TD
    Start([run_interactive 启动]) --> Banner[打印欢迎横幅]
    Banner --> Loop{while _running}
    Loop --> Input[input_fn 读取一行]
    Input -->|EOFError/KeyboardInterrupt| Bye1[打印再见并 break]
    Input --> Process[_process_line]
    Process --> Out{"有输出?"}
    Out -->|是| Print[output_fn 打印]
    Out -->|否| Done
    Print --> Done{"should_exit?"}
    Done -->|是| Break[break]
    Done -->|否| Loop
    Break --> Save[try save_history]
    Bye1 --> Save
    Save --> End([结束])
```

## 2. _process_line 决策树

```mermaid
flowchart TD
    L[读取 line.strip] --> Empty{"空行?"}
    Empty -->|是| R1[返回 '', False]
    Empty -->|否| Cmd{"is_command?"}
    Cmd -->|是| HC[handle_command]
    HC --> R2[返回 msg, should_exit]
    Cmd -->|否| Try[try chat_turn]
    Try -->|成功| R3[返回 '助手: reply', False]
    Try -->|ConfigError| R4[返回配置错误, False]
    Try -->|APIError| R5[返回 API 失败, False]
    Try -->|NexusError| R6[返回错误, False]
```

## 3. handle_command 分支

```mermaid
flowchart LR
    subgraph commands[斜杠命令]
        H["/help"]
        E["/exit /quit"]
        C["/clear"]
        HI["/history"]
        S["/save"]
        SY["/system"]
        U[未知命令]
    end
    H --> List[COMMANDS 列表]
    E --> Exit["should_exit=True"]
    C --> KeepSys[保留 system 重建 History]
    HI --> Format[format_line 枚举]
    S --> SaveFile[save_history]
    SY --> AddSys[add_system arg]
    U --> Unknown["提示 /help"]
```

## 7. 会话文件生命周期

```
启动 ChatAssistant
    → 可选 load_history()
用户对话多轮
    → /save 或退出时 save_history()
    → JSON 写入 history_path
下次启动 load_history() 恢复
```
