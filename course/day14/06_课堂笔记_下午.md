## 14:00 _process_line 统一入口

```python
def _process_line(self, line: str) -> tuple[str, bool]:
    text = line.strip()
    if not text:
        return "", False
    if self.is_command(text):
        handled, msg, should_exit = self.handle_command(text)
        if handled:
            return msg, should_exit
        return "", False
    try:
        reply = self.chat_turn(text)
        return f"助手: {reply}", False
    except ConfigError as exc:
        return f"配置错误: {exc.message}", False
    except APIError as exc:
        return f"API 调用失败: {exc.message}", False
    except NexusError as exc:
        return f"错误: {exc.message}", False
```

**设计收益**：交互与脚本行为一致；测试只 mock `_process_line` 上游即可。

## 14:30 run_scripted 课堂编码

```python
def run_scripted(self, lines: list[str]) -> list[str]:
    outputs: list[str] = []
    for line in lines:
        out, done = self._process_line(line)
        if out:
            outputs.append(out)
        if done:
            break
    return outputs
```

演示 `cli_assistant_demo.py` 脚本：

```python
script = [
    "你好，请介绍一下 NexusAgent。",
    "/history",
    "理财产品收益率是多少？",
    "/save",
    "/exit",
]
```

每行单独 `run_scripted([line])` 是为**清晰打印** `>>> 输入`；测试里通常一次传入多行。

## 15:00 run_interactive 要点

- 欢迎横幅：`NexusAgent CLI 多轮对话助手`
- `EOFError` / `KeyboardInterrupt` → 友好再见
- 循环结束 `try: save_history()`，`NexusError` 静默 —— **退出路径不能因写盘失败崩溃**

可注入 `input_fn` / `output_fn` 做自动化演示：

```python
lines = iter(["你好", "/exit"])
assistant.run_interactive(input_fn=lambda _: next(lines))
```
