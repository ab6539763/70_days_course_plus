## 10:45 handle_command 逐项演示

| 命令 | 课堂演示输入 | 观察点 |
|------|--------------|--------|
| `/help` | `/help` | 七行命令 + 提示语 |
| `/clear` | 先聊两句再 `/clear` | 只剩 system |
| `/history` | `/history` | `format_line()` 带角色 |
| `/system` | `/system 你是严谨的合规助手` | messages 多一条 system |
| `/save` | `/save` | 路径打印 |
| `/exit` | `/exit` | 再见 + 退出 |

**坑**：`/system` 无参数只提示用法，不报错。

## 11:30 chat_turn 源码走读

1. `user_text.strip()` 空则返回「请输入有效内容」
2. `history.add_user` 若返回 err 字符串则直接返回
3. `self.client.complete(self.history.messages)` — **关键：全量上下文**
4. `add_assistant(reply)` 并返回 reply

**提问**：为何不用 `chat()` 而用 `complete()`？  
**答**：本项目统一用 `complete(messages)` 列表接口，与 Day 12 一致。
