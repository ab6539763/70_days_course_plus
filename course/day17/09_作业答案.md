## 作业 A 参考实现

```python
# homework/day17/my_template.py
from __future__ import annotations

import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[2] / "src"))

from prompts import PromptTemplate

ONBOARDING = PromptTemplate(
    name="onboarding_guide",
    description="新员工入职引导",
    template=(
        "欢迎 {user_name} 加入{company}！你所在的部门是{department}。\n"
        "作为正式员工，你必须遵守数据安全规定：不得向外部泄露客户个人信息与交易数据。\n"
        "工作账号仅限本人使用，禁止共享给第三方。"
    ),
)


def render_onboarding(company: str, user_name: str, department: str) -> str:
    return ONBOARDING.render(
        company=company,
        user_name=user_name,
        department=department,
    )


if __name__ == "__main__":
    print(render_onboarding("智链科技", "林晓", "研发部"))
```

## 作业 C 参考表格（rag_lengths.md）

## 作业 D 参考答案

| 对比项 | Day 2 f-string / format | Day 17 PromptTemplate |
|--------|-------------------------|------------------------|
| 变量语法 | `{x}` 或 f"{x}" | 同 `str.format` |
| 缺变量行为 | `KeyError` | `ConfigError` 带模板名 |
| 复用方式 | 函数内字符串 | 命名模板 + 注册表 |
| 与 ChatMessage 关系 | 手动构造 | `to_system_message` |

踩坑示例：

1. 忘记 `company` 导致 `render` 失败 —— 应用 `preview` 先检查  
2. `max_points=3` int 传入 —— 类型注解为 str，宜 `"3"`

## 加分项思路

```python
if cmd == "/template" and arg.startswith("preview "):
    name = arg.split()[1]
    tmpl = self.prompt_registry.get(name)
    return True, tmpl.preview(**self.template_variables), False
```
