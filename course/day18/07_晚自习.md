## 19:30–20:00 REPL 实验

助教发布任务单：

1. 构造 `ChatAssistant(client, intent_router=IntentRouter(), auto_route=False)`  
2. 输入 `/route 你好` → 记录 summary  
3. 改 `auto_route=True`，输入同一句 → 对比 system 是否变 `default_assistant`  
4. 输入 `/template product_faq` 后再 `auto_route` 总结话术 → 观察模板被覆盖  

**讨论题**：为何 `auto_route` 每轮都 `route_and_apply`？多轮对话模板会变吗？

参考答案：每轮根据**当前 user 输入**重分类；若第二轮说「总结一下」，会从 faq 切到 doc_summary。
