## 3. classify 控制流

```mermaid
flowchart TD
    Start[classify text] --> Strip["strip 空串?"]
    Strip -->|是| Def1[_default_match 0.5]
    Strip -->|否| Loop[遍历 rules 统计命中]
    Loop --> Empty{"scores 空?"}
    Empty -->|是| Def2[_default_match 0.6]
    Empty -->|否| Max[取 max_score]
    Max --> Cand[同分 candidates]
    Cand --> Pick[_pick_by_priority]
    Pick --> Conf["confidence = min0.95, 0.55+0.1*score"]
    Conf --> Return[IntentMatch]
```

## 8. 设计原则

1. **分类与渲染分离**：Classifier 只输出 template_name，不调用 LLM  
2. **策略外置**：rules、priority、template_map 均可构造注入  
3. **可观测**：`IntentMatch.summary()` + 回复前缀 `[路由: ...]`  
4. **渐进增强**：规则 MVP → LLM 分类 → 向量 context，各层可独立替换
