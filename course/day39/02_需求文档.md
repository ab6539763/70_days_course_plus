# ZL-NA-REQ-039 产品需求文档（PRD）

**需求名称**：手写 ReAct Agent
**优先级**：P0
**平台版本**：v0.39.0

---

## 1. 背景

客服机器人遇到「查电话」「查收益」混合问句时只能走固定分支，新增场景要改分支代码，运营等不起。 引入 ReAct 循环：模型先 Thought（判断该用哪个工具），再 Action 调用 ToolExecutor，观察 Observation 后决定继续或给出 Final Answer。

## 2. 目标

- `agent/react_agent.py` — ReActAgent — Thought/Action/Observation 循环
- `agent/react_config.py` — ReactConfig — max_steps / use_session_history
- `GET/PUT /api/agent/react-config` 配置读写
- `POST /api/agent/react-preview` 无状态预览

- `POST /api/chat` + `agent_mode=true` → `agent_trace`

## 3. 功能需求

### FR-001 ReActAgent — Thought/Action/Observation 循环

- 实现位置：`agent/react_agent.py`

### FR-002 ReactConfig — max_steps / use_session_history

- 实现位置：`agent/react_config.py`

### FR-003 持久化与 status

- `store.json` 新增对应 config 字段
- `GET /api/knowledge/status` 含该 config 字段
- `platform_version` 为 `v0.39.0`

### FR-004 Chat 集成

- `api/chat.py` 在 `agent_mode=true` 且配置 `enabled` 时走本日管线
- `ChatResponse` 新增 `agent_trace` 字段（及 tools_used）

### FR-005 演示与测试

- `day39/react_demo.py` 打印决策/委派轨迹
- `day39/react_api_demo.py` 演示 REST API
- `tests/day39/` 17 项覆盖单元 + API + chat

## 4. 非功能需求

### NFR-001 可观测性

每次调用都返回结构化 `agent_trace`，可用于审计与教学演示。

### NFR-002 兼容性

`agent_mode=false`（默认）时行为与之前完全一致，不影响既有回归。

### NFR-003 可测试性

核心类可脱离 FastAPI 直接单测（构造 `ToolExecutor` 后 `invoke`/`run`）。

## 5. 非目标

- 接入真实大模型 function-calling（当前仍为规则/mock 决策）
- 跨 session 的长期记忆持久化
